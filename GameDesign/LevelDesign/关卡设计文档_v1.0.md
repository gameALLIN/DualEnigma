# 《水火筑城》关卡设计文档 v1.0

> **最后更新**: 2026-07-06  
> **状态**: 初始草案

---

## 一、关卡设计总则

### 1.1 设计原则
1. **一次只教一件事** — 每关引入不超过1个新机制
2. **安全试错** — 新机制先在无压力环境下体验，再加入挑战
3. **难度递进** — 玩家能力增长速度略快于难度增长速度
4. **双人均参与** — 每关都要求双方角色配合，不能单打独斗

### 1.2 关卡结构标准

每个关卡包含以下阶段：

```
[预览5s] → [建造90s] → [事件0~30s] → [怪物波次30s] → [结算10s]
                                                     总时长: ~3分钟
```

## 二、关卡详细设计

### 关卡 1-1：初次建造

**教学目标**：基础移动、采集、放置

**地图布局**：
```
┌────────────────────────────────────┐
│  [水源A]                [火源A]    │
│                                    │
│  水人起点     建造区      火人起点  │
│  (3×3蓝图)    8×6格      (3×3蓝图) │
│                                    │
└────────────────────────────────────┘
地形: 全草地
```

| 阶段 | 内容 | 时长 |
|------|------|------|
| 预览 | 展示3×3简单蓝图（水砖区+火砖区分开） | 5秒 |
| 建造 | 双方各自采集并放置对应材料 | 90秒 |
| 事件 | 无 | — |
| 波次 | 无 | — |
| 结算 | 评分展示 | 10秒 |

**设计要点**：
- 蓝图极简，左右分开，水人填左半，火人填右半
- 采集点紧邻出生点，往返距离≤5格
- 无任何压力，纯操作熟悉

### 关卡 1-3：合作的力量

**教学目标**：石砖合作生产

**地图布局**：
```
┌────────────────────────────────────┐
│  [水源A]                [火源A]    │
│        ╱ 水域 ╲    ╱ 岩浆 ╲       │

```

| 阶段 | 内容 | 时长 |
|------|------|------|
| 预览 | 蓝图标注"此处需石砖" | 5秒 |
| 建造 | 双方需同时到达建造区放置材料 | 90秒 |
| 事件 | 无 | — |
| 波次 | 无 | — |
| 结算 | 评分展示 | 10秒 |

**设计要点**：
- 水域和岩浆地形首次出现，形成路径分岔

- 建造区只有一条汇合路径，强调"会合"概念
- 石砖生产需要双方同时放置，引导语音沟通

|------|------|------|
| 预览 | 蓝图为4×4高塔，标注"注意承重" | 5秒 |
| 建造 | 双方合作建造高塔 | 90秒 |
| 事件 | 第45秒：小型地震(所有建筑硬度-1) | — |
| 波次 | 无 | — |

- 地震事件测试建筑稳定性
- 结算时自动执行"承重测试"动画

## 四、特殊关卡设计（挑战模式）

### 挑战关卡 C-1：速建大师
- **目标**：用最短时间完成10×8蓝图
- **限制**：无怪物，无事件
- **评分**：纯时间排名
- **材料**：无限供应基础材料

### 挑战关卡 C-2：极限生存
- **目标**：在无尽怪物波次中存活
- **限制**：建造区固定，材料有限
- **评分**：存活波次数

### 挑战关卡 C-3：材料限制
- **目标**：用限定材料完成蓝图
- **限制**：只有水砖/只有火砖/只有石砖
- **评分**：完成度 + 稳定性

## 五、关卡设计检查清单

每关提交前需确认：

- [ ] 双方角色都有明确任务，不能单方完成
- [ ] 新机制有引导提示（文字或UI）
- [ ] 采集点数量和位置合理，往返时间≤10秒
- [ ] 蓝图复杂度与时间限制匹配
- [ ] 测试：熟练玩家可在60秒内完成
- [ ] 测试：新手玩家在90秒内可完成60%以上
- [ ] 无卡死/无解的情况
- [ ] 评分系统能正确计算
