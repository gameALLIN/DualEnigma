## 一、设计原则

### 1.1 关卡设计目标

每关=1轮=90秒，包含完整的7阶段循环。关卡设计的核心变量：

| 变量 | 来源 | 说明 |
|------|------|------|
| 灾难类型 | 章节策划v2.0 §六 | 决定庇护环境、合成表、建筑接口 |
| 难度倍率 | 章节倍率×轮次倍率 | 决定灾难强度、碎片密度、蓝图复杂度 |
| 蓝图设计 | 本文档定义 | 决定建造目标和材料需求 |
| 碎片配置 | 本文档定义 | 决定碎片类型分布和掉落节奏 |

### 1.2 蓝图设计规则

1. **蓝图位置**：建筑区域内，根据灾难入侵方向布置
2. **蓝图块数**：轮次1(3-4块)→轮次2(5-6块)→轮次3(7-8块)
3. **材料需求**：根据灾难合成表决定推荐材料
4. **蓝图形状**：对应5种建筑类型（防火墙/防洪堤/加固塔/避难所/导流板）
5. **M4预言干扰特殊**：蓝图在建造过程中改变（3-4-3关）

### 1.3 碎片配置规则

1. **碎片类型比例**：根据灾难合成表决定三种碎片的掉落比例
2. **掉落位置**：建筑区域外，靠近灾害方向掉落更多对应碎片
3. **掉落节奏**：预告3-5个 + 碎片收集25-35个
4. **存续时间**：轮次1(3.5秒)→轮次2(3.0秒)→轮次3(2.5秒)
