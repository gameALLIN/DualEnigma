# 《水火筑城》美术需求文档 v1.0

> **最后更新**: 2026-07-06  
> **状态**: 初始草案

---

## 一、整体风格

### 1.1 风格定位
- **风格**：2D卡通扁平风（推荐）/ 2D像素风（备选）
- **参考游戏**：《胡闹厨房》《渎神》《泰拉瑞亚》
- **色调**：明快鲜艳，以蓝(水)和橙红(火)为主色调
- **视觉基调**：轻松、欢快、有童话感

### 1.2 分辨率与规范

| 参数 | 数值 |
|------|------|
| 游戏分辨率 | 1920×1080 |
| 网格大小 | 32×32px |
| 角色尺寸 | 24×32px (占1格高度) |
| 动画帧率 | 12fps (角色) / 24fps (特效) |
| 素材格式 | PNG (透明背景) |
| 精灵图规范 | 32的倍数为单位 |

## 二、角色美术需求

### 2.1 水人（Aqua）

**外观描述**：水滴形身体，蓝色半透明质感，有水波纹理，大眼睛，圆润可爱

**动画需求**：

| 动画 | 帧数 | 说明 |
|------|------|------|
| 待机 | 4帧 | 水波呼吸效果 |
| 行走 | 6帧 | 身体微微弹动 |
| 跳跃 | 4帧 | 起跳/滞空/下落/着地 |
| 采集 | 4帧 | 弯腰采集动作 |
| 放置材料 | 4帧 | 抬手放置 |
| 冻结技能 | 6帧 | 双手前推，冰晶特效 |
| 受伤 | 3帧 | 后仰闪白 |
| 死亡 | 4帧 | 变成水滩消散 |

**表情差分**：正常、开心、惊讶、受伤

### 2.2 火人（Ignis）

**外观描述**：火焰形身体，橙红色，底部有火焰跳动效果，头顶有小火苗，大眼睛

**动画需求**：

| 动画 | 帧数 | 说明 |
|------|------|------|
| 待机 | 4帧 | 火焰跳动 |
| 行走 | 6帧 | 火焰向后飘动 |
| 跳跃 | 4帧 | 起跳/二段跳/下落/着地 |
| 采集 | 4帧 | 弯腰采集 |
| 放置材料 | 4帧 | 抬手放置 |
| 灼烧技能 | 6帧 | 双手前推，火焰特效 |
| 受伤 | 3帧 | 后仰闪白 |
| 死亡 | 4帧 | 变成烟雾消散 |

**表情差分**：正常、开心、惊讶、受伤

## 四、地形美术需求

| 地形 | 尺寸 | 描述 | 特殊效果 |
|------|------|------|----------|
| 草地 | 32×32 | 绿色草地，有小草点缀 | 无 |
| 水域 | 32×32 | 蓝色水面，有水波动画 | 6帧循环 |
| 岩浆 | 32×32 | 红色岩浆，有气泡和火焰 | 6帧循环 |
| 冰面 | 32×32 | 浅蓝色冰面，有反光 | 2帧循环(闪烁) |
| 高台 | 32×32 | 石质高台，有侧面 | 无 |
| 陷阱区 | 32×32 | 暗色地面，有裂缝和警示纹 | 2帧循环 |

### 地形过渡
- 需要**地形过渡贴图**（草地↔水域、草地↔岩浆等）
- 过渡贴图规格：32×32，每对地形过渡4个方向（上下左右）
