# 美术需求文档

> **文档版本**: v2.0  
> **最后更新**: 2026-07-08

> **美术风格**: 矢量几何 + 迷雾废墟 + 纯特效（零外部美术资源依赖，全部程序化生成）

## 一、美术风格总则

### 1.1 核心原则

**所有美术资源100%程序化生成，零外部贴图依赖。**

- 角色：Sprite动态生成（径向渐变+描边）
- 灾害：Particle System + Shader
- 建筑：几何形状组合
- UI：uGUI + 程序化绘制
- 背景：渐变 + 粒子层
