## 一、整体结构定义

### 1.1 结构公式

```
3章 × 4节 × 3轮 = 36关
```

| 层级 | 数量 | 说明 |
|------|------|------|
| 章（Chapter） | 3 | 第一章教学、第二章进阶、第三章终极 |
| 节（Section） | 每章4节，共12节 | 每节包含3轮，主题递进 |
| 轮（Round） | 每节3轮，共36轮 | 每轮=1关，对应1种灾难 |
| 天赋选择 | 每轮1次，共36次 | 每轮结束后选择1个天赋 |

### 1.2 编号规则

```
章-节-轮

示例：2-3-1 = 第二章第三节第一轮
```

全游戏36关编号：1-1-1 至 3-4-3

## 三、节内3轮灾难递进节奏

### 3.1 递进设计原则

每节内3轮难度递进，通过以下维度调节：

| 维度 | 轮次1（简单） | 轮次2（中等） | 轮次3（困难） |
|------|--------------|--------------|--------------|
| 灾难强度 | ×1.0 | ×1.3 | ×1.6 |
| 蓝图块数 | 3-4块 | 5-6块 | 7-8块 |
| 碎片密度 | ×1.0 | ×0.85 | ×0.7 |
| 碎片存续时间 | 3.5秒 | 3.0秒 | 2.5秒 |
| 合成台数量 | 2台 | 2台 | 1台 |
| 灾难渐进入侵速度 | 慢 | 中 | 快 |

### 3.2 综合难度公式

```
最终难度 = 章节倍率 × 轮次倍率 × 灾难基础强度
```

## 四、单轮时间轴精确定义

### 4.1 七阶段时间轴

每轮总时长 **90秒**，分为7个阶段：

| 阶段 | 名称 | 时长 | 累计 | 阶段说明 |
|------|------|------|------|----------|
| ① | 预告 | 5秒 | 5秒 | 显示本轮灾难类型、庇护环境、建筑蓝图 |
| ② | 碎片收集 | 20秒 | 25秒 | 碎片在建筑区域外掉落，玩家出去捡（需庇护） |
| ③ | 灾害预告 | 5秒 | 30秒 | 灾害即将来袭的最终警告，玩家应回到建筑区域 |
| ④ | 建造 | 15秒 | 45秒 | 在建筑区域内合成材料并按蓝图建造（两人须同时在区域内） |
| ⑤ | 灾害冲击 | 20秒 | 65秒 | 灾害渐进入侵，建筑承受压力，角色可能受伤 |
| ⑥ | 修整 | 10秒 | 75秒 | 评估损伤、快速修补、恢复状态 |
| ⑦ | 升级 | 15秒 | 90秒 | 天赋选择（3选1），准备下一轮 |

**验证：5+20+5+15+20+10+15 = 90秒 ✓**

### 4.2 与GDD v5.0时间标注的对齐

| GDD v5.0阶段 | GDD v5.0时长 | v6.0拆分 | v6.0时长 |
|-------------|-------------|----------|----------|
| 灾害预告 | 5秒 | → 预告 | 5秒 |
| 建造（含碎片掉落+合成建造） | 45秒 | → 碎片收集 + 灾害预告 + 建造 | 20+5+15=40秒 |
| 灾害 | 20秒 | → 灾害冲击 | 20秒 |
| 修整 | 10秒 | → 修整 | 10秒 |
| 升级 | 15秒 | → 升级 | 15秒 |
| **合计** | **95秒** | | **90秒** |

> **差异说明**: GDD v5.0合计95秒，v6.0调整为90秒。差异来自将原45秒建造阶段拆分为"碎片收集(20s)+灾害预告(5s)+建造(15s)=40秒"，减少5秒。原因：分离碎片收集与建造阶段后，各阶段目标更明确，无需额外缓冲时间。单轮90秒更贴合GDD §1.5"单轮时长：~90秒"的原始定义。

### 4.3 多灾难预告的处理

虽然本轮结构中每轮对应1种灾难，但灾难预告阶段的展示方式因章节而异：

| 章节 | 预告方式 | 说明 |
|------|----------|------|
| 第一章 | 直接显示灾难类型和蓝图 | 教学阶段，信息透明 |
| 第二章 | 显示灾难类型+1条提示 | 中等难度，部分信息需推理 |
| 第三章 | 显示灾难类型，蓝图有延迟显示 | 高难度，考验反应速度 |

### 4.4 各阶段详细规则

**① 预告（5秒）**
- 全屏显示本轮灾难名称、图标、庇护环境
- 建筑区域内显示蓝图（绿色高亮区域+材料图标+数量）
- 碎片轨迹线预览（预告碎片将掉落的位置）
- 玩家可自由移动但灾害尚未开始

**② 碎片收集（20秒）**
- 碎片从天空掉落在建筑区域外（危险区）
- 碎片存续时间：3秒（轮次3为2.5秒）
- 接住方式：走到落点×1，跳跃接住×2，双人同时接住×3
- 玩家在建筑区域外需维持双生庇护能量
- 建筑区域内不能捡碎片

**③ 灾害预告（5秒）**
- 灾害方向指示器亮起（箭头/区域高亮）
- 倒计时3-2-1显示
- 玩家应在此阶段返回建筑区域
- 碎片停止掉落

**④ 建造（15秒）**
- 两人必须同时在建筑区域内才能建造
- 在合成台合成材料（根据灾难类型合成对应材料）
- 按蓝图放置建筑材料
- 搬运上限：3块（可升级至4块）
- 建筑区域外不需要庇护（灾害尚未开始）

**⑤ 灾害冲击（20秒）**
- 灾害渐进入侵建筑区域
- 建筑承受灾害压力，耐久下降
- 角色可能受到灾害直接影响
- 两人需保持靠近维持庇护能量
- 可使用技能辅助防御

**⑥ 修整（10秒）**
- 灾害消退
- 评估建筑损伤
- 可快速修补受损建筑
- 恢复生命值（如果有相关天赋）
- 准备天赋选择

**⑦ 升级（15秒）**
- 天赋选择界面弹出
- 系统随机发放3个天赋
- 玩家选择1个（3选1）
- 选择的天赋永久生效（本局内）
- 倒计时结束后自动进入下一轮

### 4.5 碎片掉落密度（按阶段）

| 阶段 | 碎片数量 | 说明 |
|------|----------|------|
| 预告（5秒） | 3-5个 | 预热，少量碎片掉落 |
| 碎片收集（20秒） | 25-35个 | 主要收集阶段 |
| 灾害预告（5秒） | 0 | 停止掉落 |
| 建造（15秒） | 0 | 停止掉落 |
| **每轮总计** | **28-40个** | 与地图设计§6.4对齐 |

## 七、E3元素风暴（强化版）特殊规则

第36关（3-4-3）的E3元素风暴为强化版，与普通版差异：

| 属性 | 普通版（3-4-2） | 强化版（3-4-3） |
|------|----------------|----------------|
| 爆炸频率 | 每5秒1次 | 每3秒1次 |
| 爆炸范围 | 3×3格 | 5×5格 |
| 蒸汽持续时间 | 2秒 | 4秒 |
| 碎片点燃/冻结概率 | 30% | 50% |
| 蓝图块数 | 7-8块 | 9-10块 |
| 碎片存续时间 | 2.5秒 | 2.0秒 |
| 难度倍率 | ×1.6 | ×2.0 |

> **设计意图**: 最终关作为全游戏的终极考验，E3元素风暴的"全图随机"特性配合强化参数，考验玩家36轮积累的全部Build和操作技巧。

## 八、章节间过渡设计

### 8.1 章节过渡演出

- 章节切换不重置HP和能量

| 过渡 | 难度变化 | 灾难类型变化 |

| Ch2→Ch3 | ×1.00→×1.20 (+20%) | 复合→时空/机制颠覆 |
