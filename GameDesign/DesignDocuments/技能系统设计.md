## 一、系统概述

### 1.1 核心概念

**技能不是"伤害技能"，而是"协作工具"。**

每个技能都应该：
1. 与碎片/合成/建造系统产生交互
2. 创造双人配合的时刻
3. 强化角色的定位
4. 可以通过升级获得成长

### 1.2 设计目标

1. **协作导向**：技能的价值在于配合队友，而不是独自输出
2. **环境联动**：技能与环境压迫系统深度绑定
3. **成长空间**：技能可以通过升级获得质变
4. **操作简单**：每个角色只有2个主动技能，上手容易

## 二、水人技能

### 2.1 被动技能：寒霜体质

**触发条件：** 水人接触碎片时自动触发

**触发概率：**
- 普通接住：30%概率冻结
- 跳跃接住：50%概率冻结
- 与火人同时接住：100%概率冻结

**冻结效果：**
| 效果 | 说明 |
|------|------|
| 存续时间延长 | 从3秒延长至5秒 |
| 合成加成 | 合成时材料HP+2 |
| 可被点燃 | 火人可以点燃冻结的碎片，变为"温砖" |

**设计意图：**
- 让水人的碎片收集更稳定
- 为火人创造配合机会（点燃冻结碎片）
- 强化水人"控制"的定位

---

### 2.2 主动技能：冻结（E键）

**冷却时间：** 12秒

**释放方式：** 水人释放一道寒霜波，覆盖前方3×3格区域

**技能效果：**

| 目标 | 效果 | 持续时间 |
|------|------|----------|
| 空中碎片 | 碎片原地悬停 | 3秒 |
| 地面碎片 | 碎片存续时间+10秒 | 10秒 |
| 队友 | 获得"寒霜护盾"，减伤30% | 5秒 |
| 灾害 | 山火减速50% | 3秒 |
| 环境 | 火山环境下，范围内蒸发停止 | 5秒 |

**合作用法：**
- 水人冻结空中碎片 → 火人跑去接住 → 碎片不会消失
- 水人冻结队友 → 队友在危险区域安全行动
- 水人冻结火焰 → 火人趁机通过危险区域
- 水人冻结环境 → 火人在火山环境中获得喘息时间

**设计意图：**
- 控制+保护型技能
- 创造"我帮你"的时刻
- 与环境压迫系统联动

---

### 2.3 终极技能：暴风雪（Q键）

**解锁条件：** 第3轮后可选解锁

**冷却时间：** 60秒

**释放方式：** 水人在指定区域召唤一场小型暴风雪，覆盖5×5格区域

**技能效果：**

| 效果 | 说明 | 持续时间 |
|------|------|----------|
| 区域冻结 | 区域内所有碎片冻结 | 10秒 |
| 材料强化 | 区域内己方建筑HP+20% | 持续到灾害结束 |
| 火焰压制 | 区域内山火伤害-50% | 5秒 |
| 环境安全 | 区域内火山环境蒸发停止 | 10秒 |
| 移动限制 | 区域内敌人减速（如果有的话） | 5秒 |

**合作用法：**
- 在建造区域释放 → 所有掉落的碎片都被冻结，方便收集
- 在火焰来袭方向释放 → 为建造争取时间
- 在队友身边释放 → 保护队友在火山环境中安全行动
- 在合成台释放 → 合成时材料获得强化

**设计意图：**
- 战略型大招，改变战场局势
- 与环境压迫系统深度联动
- 创造"我来保护这片区域"的时刻

## 三、火人技能

### 3.1 被动技能：烈焰体质

**触发条件：** 火人接触碎片时自动触发

**触发概率：**
- 普通接住：30%概率点燃
- 跳跃接住：50%概率点燃
- 与水人同时接住：100%概率点燃

**点燃效果：**
| 效果 | 说明 |
|------|------|
| 合成加成 | 合成时材料属性+2 |
| 首次冲击 | 放置后第一次接触灾害，伤害翻倍 |
| 可被冻结 | 水人可以冻结点燃的碎片，变为"温砖" |

**设计意图：**
- 让火人的碎片更有攻击性
- 为水人创造配合机会（冻结点燃碎片）
- 强化火人"增强"的定位

---

### 3.2 主动技能：灼烧（E键）

**冷却时间：** 12秒

**释放方式：** 火人释放一道火焰波，覆盖前方3×3格区域

**技能效果：**

| 目标 | 效果 | 持续时间 |
|------|------|----------|
| 空中碎片 | 碎片掉落速度+50%，合成属性+2 | 永久 |
| 地面碎片 | 碎片合成时属性+2 | 永久 |
| 队友 | 获得"烈焰护盾"，免疫减速 | 5秒 |
| 灾害 | 暴风雪融化区域 | 3秒 |
| 环境 | 洪水环境下，范围内熄灭停止 | 5秒 |

**合作用法：**
- 火人点燃碎片 → 水人接住 → 碎片合成属性+2
- 火人点燃队友 → 队友在暴风雪中正常移动
- 火人点燃冰雪 → 水人通过被冻结的区域
- 火人点燃环境 → 水人在洪水环境中获得喘息时间

**设计意图：**
- 增强+辅助型技能
- 创造"我强化你"的时刻
- 与环境压迫系统联动

---

|------|------|----------|

**合作用法：**

## 四、组合技：温砖

### 4.1 触发条件

**火人先点燃碎片，水人再冻结同一块碎片。**

### 4.2 获取流程

```
火人点燃碎片 → 水人冻结碎片 → 碎片变为"温砖"
```

### 4.3 温砖属性

| 属性 | 数值 | 说明 |
|------|------|------|
| HP | 20 | 比水砖火砖都高 |
| 抗性 | 全抗性+20% | 对所有灾害都有抗性 |
| 特殊效果 | 温差场 | 放置后周围产生"温差场"，对所有灾害都有一定抗性 |

### 4.4 温差场效果

**温差场范围：** 3×3格

**温差场效果：**
| 灾害 | 效果 |
|------|------|
| 山火 | 火焰减速30% |
| 洪水 | 水位上涨减速30% |
| 地震 | 冲击波伤害-20% |
| 暴风雪 | 冰雪融化，减速效果-30% |
| 陨石 | 被砸概率-20% |

### 4.5 设计意图

1. **双人配合的最高奖励**：只有两人协作才能获得最强材料
2. **创造配合时刻**：火人点燃碎片时，需要喊水人来冻结
3. **环境压迫的解药**：温砖的温差场可以抵消环境压迫效果
4. **战略价值**：温砖是唯一对所有灾害都有效的材料

## 八、设计优势总结

### 8.1 协作导向

**每个技能都有"配合队友"的用法。**

- 冻结不只是控制碎片，而是"我帮你争取时间"
- 灼烧不只是增强碎片，而是"我给你开路"
- 温砖不只是最强材料，而是"我们配合的证明"

---

### 8.2 环境联动

**每个技能都与环境压迫系统深度绑定。**

- 火山环境下，冻结技能可以停止蒸发
- 洪水环境下，灼烧技能可以停止熄灭
- 技能不只是"增强效果"，而是"救命手段"

---

### 8.3 成长空间

**技能可以通过升级获得质变。**

- 从"冻结碎片"到"冻结区域"
- 从"点燃碎片"到"点燃区域"
- 从"单人技能"到"双人共鸣"

---

### 8.4 操作简单

**每个角色只有2个主动技能，上手容易。**

- 被动技能自动触发，不需要操作
- 主动技能只有E键，冷却12秒
- 终极技能只有Q键，冷却60秒
- 温砖获取是双人配合，不需要额外操作
