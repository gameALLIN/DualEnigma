## 一、游戏概述

### 1.1 游戏名称
《水火筑城》（暂定）

### 1.2 一句话定义
双人联网2D合作建造游戏，水人与火人利用元素材料建造防御工事，保护核心水晶抵御逐轮升级的自然灾害。

### 1.3 目标平台
PC（键鼠为主），联网双人

### 1.4 核心体验
> **"灾害来了，我们的墙够不够厚？"**

三大张力点：
1. **预告决策**——看到灾害类型，决定建造策略
2. **灾害站位**——灾害中只能修身边一小片，位置选对了吗？
3. **升级博弈**——每轮选一个升级，和队友搭配出最优防线

### 1.5 核心乐趣循环

```
灾害预告(5s) → 建造阶段(45s) → 灾害冲击(20s) → 修整+回收(10s) → 升级+商店(15s)
                                                                         ↓
                                                                   下一轮(难度↑)
```

- 单轮时长：**~95秒**
- 单局总时长：**3轮 ≈ 5分钟**
- 核心HP归零 = 游戏结束；撑过3轮 = 胜利

## 二、角色设计

### 2.1 角色选择

游戏开始前，两名玩家选择水人或火人。**不允许选相同角色**（强制一水一火）。

### 2.2 水人（Aqua）

| 属性 | 数值 | 说明 |
|------|------|------|
| 移动速度 | 4.0 格/秒 | 基础值 |
| 跳跃高度 | 2格 | 标准跳跃 |
| 搬运上限 | 3块 | 可升级至4块 |
| 专属技能 | 冻结 | 配合火人激活解谜节点 / 将水砖升级为冰砖（需解锁） |
| 灾害中的角色 | 山火主防御者 | 水砖/冰砖抗火 |
| 灾害中的弱点 | 洪水、暴风雪 | 水砖会被浸泡/冻裂 |

### 2.3 火人（Ignis）

| 属性 | 数值 | 说明 |
|------|------|------|
| 移动速度 | 4.0 格/秒 | 基础值 |
| 跳跃高度 | 2格 | 可二段跳至3格 |
| 搬运上限 | 3块 | 可升级至4块 |
| 专属技能 | 灼烧 | 配合水人激活解谜节点 / 将火砖升级为岩浆砖（需解锁） |
| 灾害中的角色 | 洪水、暴风雪主防御者 | 火砖/岩浆砖抗水/冰 |
| 灾害中的弱点 | 山火 | 火砖会被火焰吞噬 |

### 2.4 设计原则

**角色防御角色会轮转**——每轮灾害切换类型，没有永远的MVP：

```
第1轮 山火 → 水人是英雄，火人是辅助
第2轮 洪水 → 火人是英雄，水人是辅助
第3轮 地震 → 双方必须合作造石砖
```

## 三、材料体系

### 3.1 材料总览（5种）

| 材料 | 谁造 | 硬度(HP) | 抗什么 | 弱什么 | 解锁条件 |
|------|------|----------|--------|--------|----------|
| 水砖 | 水人 | 10 | 山火（减伤50%） | 洪水（被浸泡-2HP/秒）、暴风雪（冻裂） | 初始可用 |
| 冰砖 | 水人 | 15 | 山火（免疫） | 暴风雪（变脆-50%HP）、热浪 | 第1轮后升级解锁 |
| 火砖 | 火人 | 10 | 洪水（蒸发挡水）、暴风雪（融冰） | 山火（被烧毁-2HP/秒） | 初始可用 |
| 岩浆砖 | 火人 | 15 | 洪水（免疫）、暴风雪（免疫） | 山火（加剧，但自身不毁） | 第1轮后升级解锁 |
| 石砖 | 双方合作 | 30 | 地震（免疫）、陨石（减伤80%） | 无弱点 | 第1轮后升级解锁 |

### 3.2 材料交互（仅1条核心规则）

> **水砖 + 岩浆砖 → 石砖**（双方各消耗1块，产出1块石砖）

其他材料之间**不交互**，放在一起各管各的。保持简单。

### 3.3 材料获取途径

材料通过**三条途径**获取，详见第六章「材料获取系统」：

```
① 合作解谜产出（主要来源）
   解谜节点(两人配合) → 产出基础材料

② 局内商店购买（补充来源）
   拾取能量晶体(EC) → 核心旁商店 → 购买材料包

③ 灾害中合作回收（应急来源）
   建筑被毁→掉落碎片 → 两人同时触碰 → 回收为材料
```

### 3.4 材料生产链

```
【合作解谜产出】              【局内商店购买】
  水火管道 → 水砖+火砖         EC → 水砖包/火砖包
  双压板宝箱 → 随机材料         EC → 石砖包(需解锁)
  元素共鸣 → 随机材料
  冰火通道 → 水砖或火砖

         ↓ 两人配合激活                ↓ 两人配合激活
       冰砖(水砖升级)              岩浆砖(火砖升级)
         ↓                           ↓
         └─── 水砖+岩浆砖 ───┘
                    ↓
                 石砖（合作产物，最坚固）
```

### 3.5 材料视觉辨识

| 材料 | 颜色 | 纹理 | 受损表现 |
|------|------|------|----------|
| 水砖 | 蓝色半透明 | 水波纹 | 裂纹+颜色变浅 |
| 冰砖 | 浅蓝不透明 | 冰晶裂纹 | 裂纹扩展 |
| 火砖 | 橙红色 | 火焰边缘 | 边缘暗淡 |
| 岩浆砖 | 深红 | 岩浆裂纹+气泡 | 裂纹+气泡减少 |
| 石砖 | 灰色 | 石质纹理 | 裂纹 |

## 四、灾害系统（游戏核心）

### 4.1 灾害类型

#### ① 山火 Wildfire
| 属性 | 说明 |
|------|------|
| 来源 | 地图边缘（左/右/上），火焰墙向核心蔓延 |
| 速度 | 1格/秒，持续20秒 |
| 对材料效果 | 烧毁火砖/岩浆砖（-2HP/秒），水砖减伤50%，冰砖免疫 |
| 对角色效果 | 接触火焰受伤（-5HP/次） |
| 对核心效果 | 火焰到达核心后核心-2HP/秒 |
| 主防御者 | **水人**——用水砖/冰砖建防火墙 |
| 辅助策略 | 火人负责搬运库存材料+在解谜节点产出石砖加固 |
| 视觉 | 橙红色火焰墙从边缘推进，烟雾粒子 |

#### ② 洪水 Flood
| 属性 | 说明 |
|------|------|
| 来源 | 地图底部，水位上涨 |
| 速度 | 0.5格/秒上涨，持续20秒 |
| 对材料效果 | 浸泡水砖（-2HP/秒），火砖蒸发挡水（消耗自身HP），岩浆砖免疫 |
| 对角色效果 | 水人可游泳不受影响，火人接触水受伤（-5HP/次） |
| 对核心效果 | 水位到达核心后核心-2HP/秒 |
| 主防御者 | **火人**——用火砖/岩浆砖建防水墙 |
| 辅助策略 | 水人可在水中自由行动，紧急修补底层 |
| 视觉 | 蓝色水位线从底部上升，水花粒子 |

#### ③ 地震 Earthquake
| 属性 | 说明 |
|------|------|
| 来源 | 全图震动 |
| 持续 | 20秒，每3秒一次冲击波 |
| 对材料效果 | 每次冲击波对所有非石砖材料造成-3HP伤害，石砖免疫 |
| 对角色效果 | 震动期间移动速度-50% |
| 对核心效果 | 每次冲击波核心-1HP |
| 主防御者 | **双方**——只有石砖能抗，必须合作生产 |
| 辅助策略 | 震动间隙快速修补非石砖区域 |
| 视觉 | 屏幕震动，碎石掉落，裂痕效果 |

#### ④ 暴风雪 Blizzard
| 属性 | 说明 |
|------|------|
| 来源 | 从地图顶部降落，冰晶向地面蔓延 |
| 速度 | 1格/秒向下蔓延，持续20秒 |
| 对材料效果 | 冻裂水砖（-50%当前HP），冰砖变脆（-3HP/秒），火砖融化冰雪（3格半径），岩浆砖免疫 |
| 对角色效果 | 水人移动-30%，火人不受影响 |
| 对核心效果 | 冰晶到达核心后核心-2HP/秒 |
| 主防御者 | **火人**——火砖/岩浆砖发热融化冰雪 |
| 辅助策略 | 水人在火人保护范围内修补 |
| 视觉 | 白色雪花/冰晶粒子从顶部下落，地面结冰效果 |

#### ⑤ 陨石雨 Meteor
| 属性 | 说明 |
|------|------|
| 来源 | 从天空随机位置坠落 |
| 频率 | 每2秒1颗，持续20秒，共10颗 |
| 对材料效果 | 砸中格子的材料-10HP（石砖减伤80%只受2HP） |
| 对角色效果 | 被砸中-10HP |
| 对核心效果 | 直接砸中核心-10HP（罕见，需要无屋顶才会被砸） |
| 主防御者 | **双方**——需要厚屋顶，石砖最抗冲击 |
| 辅助策略 | 陨石落点有1秒预警标记，可躲避 |
| 视觉 | 橙色火球从天而降，落点红色圆圈预警 |

### 4.2 灾害轮次编排

| 轮次 | 灾害 | 难度 | 说明 |
|------|------|------|------|
| 第1轮 | 山火 或 洪水（二选一） | ★ | 单一灾害，方向明确，教学性质 |
| 第2轮 | 另一种基础灾害 或 暴风雪 | ★★ | 威胁方切换，角色轮转 |
| 第3轮 | 地震 或 陨石雨 或 双灾害叠加 | ★★★ | 终局考验，需要石砖 |

**灾害预告**（5秒）：屏幕显示灾害图标+来袭方向+威胁等级，玩家据此决定建造策略。

### 4.3 灾害中的有限行动规则

灾害冲击的20秒内：
- 玩家**可以移动**，但速度降低20%
- 玩家**只能修补角色周围3×3格范围内的建筑**（放置/回收材料）
- 玩家携带的**材料库存仍可用**（所以建造阶段囤货很重要）
- 解谜节点和商店在灾害中**关闭**
- 玩家可以使用技能（冻结/灼烧）
- 建筑被毁后掉落**碎片**，两人同时触碰可回收为材料（详见6.3节）

**设计目的**：灾害前要囤够材料，灾害中要走位到关键位置修补。站对了位置=救场，站错了=干着急。

## 五、建造系统

### 5.1 建造规则（简化版）

| 规则 | 说明 |
|------|------|
| 网格大小 | 32×32 像素/格 |
| 建造区域 | 核心周围12×10格 |
| 放置条件 | 下方必须有地面或其他材料（不能悬空） |
| 放置速度 | 0.3秒/块 |
| 回收速度 | 0.2秒/块，返还材料到库存 |
| 承重 | **简化为**：横向最多延伸2格无支撑，超过会坍塌 |
| 携带上限 | 3块（可升级至4块） |

### 5.2 建造操作

| 操作 | 键鼠 | 手柄 |
|------|------|------|
| 移动 | WASD | 左摇杆 |
| 跳跃 | Space | A |
| 放置材料 | 鼠标左键（指向格子） | RB |
| 回收材料 | 鼠标右键 | LB |
| 技能(冻结/灼烧) | F | Y |
| 切换材料类型 | 鼠标滚轮 / 数字键 | 方向键上下 |

### 5.3 建造策略要点

- **方向性防御**：灾害从特定方向来，建筑要朝那个方向加固
- **层数策略**：外墙多层堆叠=更厚，但消耗更多材料
- **材料搭配**：水砖外层防火+石砖内层抗震=复合防御
- **屋顶策略**：陨石雨需要屋顶，但屋顶占材料=少了墙体

## 六、材料获取系统

材料获取是核心循环的入口，通过**三条途径**获取材料，强调双人合作与策略规划。

### 6.1 合作解谜产出（主要来源）

地图上散布**解谜节点**（3~4个），每个需要水火二人配合才能激活，产出材料。解谜完成后进入冷却（15秒），之后可再次激活。

#### 解谜节点类型

| 节点 | 玩法 | 产出 | 耗时 | 冷却 |
|------|------|------|------|------|
| 水火管道 | 水人在A端注水→水流过管道→火人在B端点燃→涡轮启动 | 2水砖+2火砖 | ~6秒 | 15秒 |
| 双压板宝箱 | 两人同时踩压力板，维持3秒→宝箱开启 | 3块随机材料 | ~4秒 | 15秒 |
| 元素共鸣 | 两人对中央水晶同时释放技能(冻结+灼烧) | 4块随机材料 | ~5秒 | 15秒 |
| 冰火通道 | 水人冻水造桥→火人过桥到对岸取材料→带回 | 3块水砖或火砖 | ~8秒 | 15秒 |

#### 设计要点
- 每个节点**强制需要两人配合**——一个人解不了
- 解谜过程是走位+操作的小挑战，不是干等
- 不同节点产出不同材料，玩家要**规划去哪个节点**
- 冷却机制防止无限刷——**时间分配是策略**：解谜 vs 建造 vs 拾取晶体
- 灾害中解谜节点**关闭**

### 6.2 局内商店（补充来源）

#### 货币：能量晶体（EC）

EC为**双方共享**，需要商量如何花费。

| 获取来源 | 数量 | 时机 |
|----------|------|------|
| 地图散落晶体 | 3~5个，每个+3 EC | 建造阶段可拾取 |
| 撑过一轮灾害 | +10 EC | 每轮修整阶段 |
| 核心无伤奖励 | +5 EC | 该轮核心未受损时 |
| 完美解谜奖励 | +2 EC | 在规定时间一半内完成解谜 |

#### 商店商品

商店位于核心水晶旁边，按交互键打开。**仅在建造阶段和修整阶段开放**。

| 商品 | 价格 | 效果 |
|------|------|------|
| 水砖包 | 8 EC | 获得3块水砖 |
| 火砖包 | 8 EC | 获得3块火砖 |
| 石砖包 | 15 EC | 获得2块石砖（需先解锁石砖） |
| 应急空投 | 12 EC | 立即空投5块随机材料到核心区 |
| 加固涂料 | 10 EC | 选1块已放置材料，硬度(HP)+10 |

#### 设计要点
- 商店是**补充手段**，不是主要来源——解谜产出更多材料
- EC共享制造"花钱要商量"的合作感
- 加固涂料让玩家有决策：买新材料还是加固旧建筑？
- 灾害阶段商店**关闭**

### 6.3 灾害中合作回收（应急来源）

灾害阶段解谜节点和商店都关闭，但可以通过回收废墟获取应急材料。

#### 废墟回收规则

| 规则 | 说明 |
|------|------|
| 碎片产生 | 建筑被灾害摧毁后，在原位掉落碎片（1块材料=1块碎片） |
| 回收方式 | 两人**同时触碰**同一块碎片→1秒后回收为原材料 |
| 单人无效 | 单人触碰碎片无效果，必须两人同时到场 |
| 材料随机 | 回收的材料类型随机（可能水砖也可能火砖） |
| 碎片存续 | 碎片在灾害阶段和修整阶段存在，修整结束未回收的消失 |

#### 设计要点
- 强制两人**一起跑向损毁区域**回收材料——制造灾害后的合作走位
- 回收材料是随机的——增加决策：冒险回收还是直接去商店买
- 灾害中碎片散落在被毁位置，玩家需要在修补和回收之间做选择

### 6.4 高级材料获取（合作激活）

高级材料不能直接获取，需要**两人配合激活**：

| 高级材料 | 获取方式 | 合作要求 | 耗时 |
|----------|----------|----------|------|
| 冰砖 | 水人放置水砖 → 两人同时站在水砖旁长按技能键 | 需火人到场配合 | 2秒 |
| 岩浆砖 | 火人放置火砖 → 两人同时站在火砖旁长按技能键 | 需水人到场配合 | 2秒 |
| 石砖(合成) | 水砖+岩浆砖相邻放置 → 两人同时长按交互键 | 双方同时操作 | 1.5秒 |
| 石砖(商店) | 核心旁商店购买石砖包 | 需先解锁石砖升级 | 即时 |

**为什么高级材料也要合作？**
- 强制两人**聚在一起**——制造"走过来帮忙"的时机
- 灾害中如果墙破了需要冰砖加固，水人放砖但还得喊火人过来一起激活——**紧张感拉满**
- 高级材料更强=合作成本更高=合理的平衡

### 6.5 建造阶段时间分配策略

45秒建造阶段内的时间分配是一个策略博弈：

| 选择 | 耗时 | 收益 |
|------|------|------|
| 解1次谜 | ~6秒 | 3~4块材料 |
| 拾取散落晶体 | ~2秒/个 | 3 EC |
| 往返建造区放置 | ~3秒/趟 | 消耗材料 |
| 商店购买 | ~3秒 | 消耗EC |
| 合成高级材料 | ~2秒/次 | 消耗基础材料 |

玩家需要自行决定：先解谜拿材料？先捡晶体存钱？还是直接建造？

## 七、升级系统（局内Roguelite）

### 7.1 升级时机

每轮灾害修整阶段后，**双方各从3个随机选项中选1个**（10秒倒计时）。

### 7.2 升级池

#### 水人专属升级

| 升级 | 效果 | 类型 |
|------|------|------|
| 解锁冰砖 | 获得冻结技能，水砖可升级为冰砖 | 解锁 |
| 水砖硬化 | 水砖HP +5 | 属性 |
| 搬运扩容 | 携带上限+1（4块） | 属性 |
| 解谜加速 | 水人参与的解谜节点耗时-30% | 属性 |
| 紧急修补 | 灾害中修补范围扩大至5×5 | 技能 |
| 防火涂层 | 水砖山火减伤提升至75% | 属性 |

#### 火人专属升级

| 升级 | 效果 | 类型 |
|------|------|------|
| 解锁岩浆砖 | 获得灼烧技能，火砖可升级为岩浆砖 | 解锁 |
| 火砖硬化 | 火砖HP +5 | 属性 |
| 搬运扩容 | 携带上限+1（4块） | 属性 |
| 解谜加速 | 火人参与的解谜节点耗时-30% | 属性 |
| 二段修补 | 灾害中修补速度+100% | 技能 |
| 蒸发力场 | 火砖洪水抗性提升至免疫 | 属性 |

#### 双方共享升级（随机出现在两人的选项中）

| 升级 | 效果 | 类型 |
|------|------|------|
| 解锁石砖 | 双方可合作生产石砖 | 解锁 |
| 核心加固 | 核心HP +30 | 属性 |
| 建造加速 | 放置速度-0.1秒 | 属性 |
| 结构强化 | 横向无支撑延伸+1格 | 属性 |
| 晶体倍增 | 散落晶体拾取量×2 | 属性 |
| 回收效率 | 废墟碎片回收时间-50%，且可单人回收 | 技能 |
| 商店折扣 | 所有商店商品降价20% | 属性 |

### 7.3 升级策略博弈

- 第1轮后是最关键的选择：先解锁高级材料（冰砖/岩浆砖/石砖）还是先强化基础属性？
- 第2轮后的选择要针对第3轮的灾害类型：地震→必选石砖；陨石→必选硬度/石砖
- 两人选了不同方向可能产生协同（水人选冰砖+火人选岩浆砖→石砖产出更快）

## 九、游戏流程

### 9.1 完整一局

```
[大厅/匹配] → [角色选择] → [进入游戏]
                                    ↓
                         ┌─── 第1轮 ───┐
                         │ 预告    5s   │
                         │ 建造   45s   │
                         │ 灾害   20s   │
                         │ 修整   10s   │
                         │ 升级+商店15s │
                         └──────────────┘
                                    ↓
                         ┌─── 第2轮 ───┐
                         │ 同上结构     │
                         │ 灾害升级     │
                         └──────────────┘
                                    ↓
                         ┌─── 第3轮 ───┐
                         │ 终局灾害     │
                         └──────────────┘
                                    ↓
                            [结算界面]
                         胜利/失败 + 统计
```

### 9.2 结算界面

| 展示内容 | 说明 |
|----------|------|
| 胜负结果 | 撑过3轮=胜利 / 核心被毁=失败 |
| 核心剩余HP | 以百分比展示 |
| 建筑存活率 | 最终建筑存活格数/总放置格数 |
| 材料使用量 | 双方各使用了多少材料 |
| 解谜完成数 | 总共完成多少次解谜节点 |
| EC使用量 | 商店消费总额 |
| 废墟回收量 | 灾害中回收的碎片总数 |
| 最佳时刻 | 回放灾害中最关键的一次修补/防御 |
| 升级路线回顾 | 展示双方选择的升级 |

### 9.3 失败容错

- 核心HP归零立即结束，不等3轮打完
- 第1轮就失败→极罕见，第一轮灾害难度刻意调低
- 失败后可"快速重开"，回到角色选择

### 10.2 地图设计要点

- **解谜节点**（3~4个）分布在地图四角外围，离建造区有距离，需要跑动
- **能量晶体**散落在地图各处（3~5个），拾取即得EC
- **商店**位于核心水晶旁边，建造区和修整阶段可交互
- 建造区在中央，核心在建造区正中
- 灾害从地图边缘（上/下/左/右）来袭
- 建造区四周都是可建造空间，玩家需根据灾害方向决定加固哪一面
- **无复杂地形**（不放水域/岩浆地形，保持简单）

## 十一、联网设计

### 11.1 联网架构

| 属性 | 说明 |
|------|------|
| 模式 | P2P 或 轻量级服务器中转 |
| 房间制 | 房主创建房间，分享代码给好友加入 |
| 匹配 | 随机匹配（可选）/ 好友房间（主要） |
| 断线处理 | 一方断线→暂停15秒等待重连→超时则判负 |
| 延迟补偿 | 建造操作本地预测+服务器校验；灾害时间轴由主机同步 |

### 11.2 联网对设计的影响

- **操作简化**：不做精确物理碰撞，只做网格判定（网络同步简单）
- **灾害同步**：灾害由主机生成时间轴，广播给客机（确定性模拟）
- **无分屏**：联网模式下双方看同一画面（全图可见）
- **建造冲突处理**：同一格子两人同时放置→先到先得，后到的返还材料
- **EC同步**：EC为共享值，由主机管理，所有消费请求经主机校验
- **解谜同步**：解谜节点状态由主机管理，双方操作实时同步

## 十五、风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 灾害阶段无聊（只能看） | 玩法空洞 | 已解决：有限行动+废墟回收机制 |
| 升级选择太少 | 重玩性不足 | 每类6~8选项，3轮组合空间足够 |
| 联网同步问题 | 建造冲突、灾害不同步 | 网格化简化同步；灾害用确定性时间轴 |
| 第1轮太难 | 新手劝退 | 第1轮刻意低难度，灾害单一且方向明确 |
| 解谜节点占用过多时间 | 建造时间不足 | 解谜耗时控制在4~8秒，冷却15秒限制产出 |
| EC经济通胀 | 后期材料泛滥 | 散落晶体有限，灾害奖励固定，商店定价控制消耗 |
| 废墟回收太强 | 灾害惩罚不足 | 回收需两人同时到场+材料随机+修整后消失 |
