## 一、游戏概述

### 1.1 游戏名称
《双生迷城》（DualEnigma）

### 1.2 一句话定义
双人联网2D合作建造游戏，水人与火人根据灾害类型合成材料、按蓝图建造防御建筑，保护彼此免受自然灾害的侵袭。

### 1.3 目标平台
PC（键鼠为主），联网双人

### 1.4 核心体验
> **"灾害来了，你还活着吗？"**

三大张力点：
1. **碎片争夺**——碎片从天而降，落地即碎，必须快速接住
2. **环境压迫**——不同环境下角色持续掉血，必须待在队友身边才能存活
3. **蓝图执行**——在指定区域按图建造，速度和配合决定成败

### 1.5 核心乐趣循环

```
灾害预告 → 碎片掉落 → 收集接住 → 合成材料 → 蓝图建造 → 灾害渐入 → 修整升级
    ↓                                                                    ↓
  看到蓝图                                                              下一轮
```

- 单轮时长：**~90秒**
- 章节结构：3章 × 12节
- 任意角色HP归零 = 游戏结束；撑过所有灾害 = 胜利

## 二、角色设计

### 2.1 角色选择

游戏开始前，两名玩家选择水人或火人。**不允许选相同角色**（强制一水一火）。

### 2.2 水人（Aqua）

| 属性 | 数值 | 说明 |
|------|------|------|
| 生命值(HP) | 100 | 可升级提升 |
| 移动速度 | 4.0 格/秒 | 基础值 |
| 跳跃高度 | 2格 | 标准跳跃 |
| 搬运上限 | 3块 | 可升级至4块 |
| 合成偏好 | 水系材料 | 水砖、冰砖合成速度+30% |
| 专属技能 | 冻结 | 可冻结空中碎片改变轨迹 |
| 灾害优势 | 山火中：移动不受影响 | 保护队友 |
| 灾害弱点 | 洪水/暴风雪：移动减速 | 需要火人保护 |

### 2.3 火人（Ignis）

| 属性 | 数值 | 说明 |
|------|------|------|
| 生命值(HP) | 100 | 可升级提升 |
| 移动速度 | 4.0 格/秒 | 基础值 |
| 跳跃高度 | 2格 | 可二段跳至3格 |
| 搬运上限 | 3块 | 可升级至4块 |
| 合成偏好 | 火系材料 | 火砖、岩浆砖合成速度+30% |
| 专属技能 | 灼烧 | 可点燃碎片改变属性 |
| 灾害优势 | 洪水/暴风雪中：移动不受影响 | 保护队友 |
| 灾害弱点 | 山火：移动减速 | 需要水人保护 |

### 2.4 双人关系设计

**核心理念：互相保护，而非各自为战**

```
山火来袭 → 水人建防火墙保护火人 → 火人负责收集碎片支援
洪水来袭 → 火人建防水墙保护水人 → 水人负责修补底层
地震来袭 → 双方必须贴近彼此，共用石砖掩体
```

**设计原则**：每种灾害都会让一方变弱，另一方必须成为保护者。

## 二之二、环境压迫系统

### 2.5 核心概念

**灾害不只是"从外面打进来"的伤害，而是"脚下的土地本身在伤害你"。**

不同环境下，角色会持续掉血，只有队友在身边才能存活。这让合作从"可选"变成"被迫的生存条件"。

### 2.6 五种环境下的压迫机制

#### 火山/山火环境

| 角色 | 处境 | 远离队友时 | 队友在身边时 |
|------|------|------------|--------------|
| 水人 | 高温蒸发 | -3HP/秒（快速蒸发） | 火人提供"热能中和场"，蒸发停止 |
| 火人 | 无影响 | 无 | 无 |

**距离规则：**
- 火人在3格内 → 水人安全
- 火人超过3格 → 水人开始蒸发
- 超过6格 → 蒸发加速

#### 洪水环境

| 角色 | 处境 | 远离队友时 | 队友在身边时 |
|------|------|------------|--------------|
| 火人 | 被水浇灭 | -3HP/秒（逐渐熄灭） | 水人提供"水流护盾"，熄灭停止 |
| 水人 | 无影响 | 无 | 无 |

**距离规则：**
- 水人在3格内 → 火人安全
- 水人超过3格 → 火人开始受潮
- 超过6格 → 受潮加速

#### 暴风雪环境

| 角色 | 处境 | 远离队友时 | 队友在身边时 |
|------|------|------------|--------------|
| 水人 | 被冻结 | 移速-50%，-2HP/秒 | 火人热量融化冰雪，恢复正常 |
| 火人 | 影响较小 | 无 | 无 |

**特殊机制：** 水人在暴风雪中，水砖会强化（冰砖获得加成），但水人本身怕冷。

#### 地震环境

| 角色 | 处境 | 远离队友时 | 队友在身边时 |
|------|------|------------|--------------|
| 双方 | 震动伤害 | 每次冲击波-3HP | 共享"稳定场"，伤害减半 |
| 双方 | 建筑不稳 | 建筑更容易坍塌 | 建筑稳定性+50% |

**距离规则：**
- 1格内 → 双方免疫冲击波伤害
- 3格内 → 伤害减半
- 超过3格 → 全额伤害

#### 陨石环境

| 角色 | 处境 | 远离队友时 | 队友在身边时 |
|------|------|------------|--------------|
| 双方 | 被砸风险 | 被砸概率50% | 被砸概率降至25% |
| 双方 | 掩体保护 | 被砸概率10% | 被砸概率降至0%，掩体承伤翻倍 |

**特殊机制：** 陨石预警圈出现时，可以推队友离开危险区域。

### 2.7 环境压迫的设计意图

1. **合作变成被迫的**：玩家必须时刻考虑"我离开他会死吗"
2. **碎片收集变成风险决策**：捡碎片需要远离队友，远离队友会掉血
3. **建造变成保护性建造**：建造时两人必须靠近，但蓝图可能在危险区域
4. **技能有了生存意义**：技能不只是增强效果，而是救命手段

## 三、碎片系统

### 3.1 碎片类型

只有 **3 种基础碎片**，不分水火：

| 碎片 | 外观 | 掉落规律 | 稀有度 |
|------|------|----------|--------|
| **冰晶碎片** | 蓝白色棱形 | 天空随机掉落，数量最多 | ★ |
| **熔岩碎片** | 橙红色不规则形 | 火焰/高温区域附近掉落 | ★★ |
| **岩石碎片** | 灰色方形 | 地震/陨石区域掉落，数量最少 | ★★★ |

### 3.2 掉落规则

| 规则 | 说明 |
|------|------|
| 掉落位置 | 地图随机位置，有预判轨迹线 |
| 掉落频率 | 预告期稀少，灾害期密集 |
| 掉落来源 | 灾害区域附近掉落对应碎片 |
| 存续时间 | 落地后 **3秒** 未捡起则粉碎消失 |

### 3.3 接住方式

| 方式 | 效果 |
|------|------|
| 走到落点 | 碎片自动吸附，获得 ×1 |
| 跳跃中接住 | 获得 ×2（奖励操作） |
| 两人同时接住 | 获得 ×3（奖励合作） |
| 水人冻结接住 | 碎片冻结，存续时间延长至5秒 |
| 火人灼烧接住 | 碎片点燃，合成时属性增强 |

### 3.4 碎片与灾害的关系

| 灾害类型 | 掉落碎片 | 稀有碎片 |
|----------|----------|----------|
| 山火 | 冰晶×大量 | 熔岩×少量 |
| 洪水 | 熔岩×大量 | 冰晶×少量 |
| 地震 | 岩石×大量 | 冰晶+熔岩×少量 |
| 暴风雪 | 冰晶×大量 | 岩石×少量 |
| 陨石雨 | 岩石×大量 | 熔岩×少量 |

## 四、合成系统

### 4.1 合成规则

**同样的碎片，根据当前灾害类型，合成不同的材料。**

| 当前灾害 | 冰晶碎片 → | 熔岩碎片 → | 岩石碎片 → |
|----------|------------|------------|------------|
| **山火** | 水砖（防火） | 冰砖（强防火） | 石砖 |
| **洪水** | 石砖 | 火砖（防水） | 岩浆砖（强防水） |
| **地震** | 石砖 | 石砖 | 石砖（强化） |
| **暴风雪** | 冰砖 | 火砖（融雪） | 岩浆砖 |
| **陨石雨** | 石砖 | 石砖 | 石砖（防陨） |

### 4.2 合成操作

**站在核心区域的合成台上，按住交互键即可合成。**

| 材料 | 所需碎片 | 合成时间 | 说明 |
|------|----------|----------|------|
| 水砖 | 冰晶 ×2 | 1秒 | 基础水系材料 |
| 火砖 | 熔岩 ×2 | 1秒 | 基础火系材料 |
| 冰砖 | 冰晶 ×3 | 1.5秒 | 高级水系，免疫山火 |
| 岩浆砖 | 熔岩 ×3 | 1.5秒 | 高级火系，免疫洪水 |
| 石砖 | 冰晶+熔岩+岩石 | 2秒 | 通用高级，免疫地震 |

### 4.3 合成加成

| 条件 | 效果 |
|------|------|
| 水人合成水系材料 | 速度+30% |
| 火人合成火系材料 | 速度+30% |
| 两人同时合成 | 速度+50%，产出+1 |
| 火人灼烧过的碎片 | 合成后材料属性+2 |
| 水人冻结过的碎片 | 合成后材料耐久+2 |

## 五、建筑蓝图系统

### 5.1 蓝图显示

**灾害预告阶段，游戏在地图上显示建造蓝图：**

```
灾害预告：山火从左侧来袭

蓝图显示：
┌─────────────────────────────────────┐
│                                     │
│   ████████████  ← 必须建造的位置    │
│   ████████████     需要：水砖×8     │
│   ████████████                      │
│                                     │
│              ◇ ← 玩家位置           │
│                                     │
└─────────────────────────────────────┘
```

**蓝图要素：**
- **绿色高亮区域**：必须建造的位置
- **材料图标**：需要什么材料
- **数量标注**：需要多少块
- **建筑轮廓**：最终建筑的样子

### 5.2 蓝图与灾害对应

| 灾害 | 蓝图形状 | 建造位置 | 所需材料 |
|------|----------|----------|----------|
| 山火 | 竖直墙体（3层高） | 正对火焰方向 | 水砖×8 |
| 洪水 | 水平堤坝（2层高） | 地图底部 | 火砖×10 |
| 地震 | 金字塔（下宽上窄） | 玩家脚下 | 石砖×12 |
| 暴风雪 | 封闭小屋（有顶） | 玩家周围 | 火砖×6+石砖×4 |
| 陨石雨 | 斜向导流板 | 预警圈上方 | 石砖×6 |

### 5.3 建筑类型详解

#### 防火墙（应对山火）

```
    ┃
    ┃  ← 水砖/冰砖
    ┃
━━━━━━━━
```

- 高度至少3层才能有效阻挡火焰
- 水砖接触火焰产生蒸汽减速
- 冰砖融化后完全阻断火焰5秒

#### 防洪堤（应对洪水）

```
━━━━━━━━━━━━
┃┃┃┃┃┃┃┃┃┃┃  ← 火砖/岩浆砖
━━━━━━━━━━━━
```

- 宽度至少3格才能形成堤坝
- 火砖蒸发阻挡水位
- 岩浆砖完全免疫，永久阻挡

#### 加固塔（应对地震）

```
      ┃
    ┃┃┃
  ┃┃┃┃┃
━━━━━━━━━━━━
```

- 下宽上窄的金字塔结构
- 石砖为主，宽基底分散震动
- 只有石砖能免疫地震冲击

#### 避难所（应对暴风雪）

```
━━━━━━━━━━━━  ← 石砖顶
┃          ┃
┃    ◇     ┃  ← 玩家位置
┃          ┃
━━━━━━━━━━━━
```

- 封闭空间，有顶有墙
- 火砖墙发热融化周围冰雪
- 石砖顶防陨石

#### 导流板（应对陨石雨）

```
        ╱
      ╱
    ╱
━━━━━━
```

- 45度角倾斜结构
- 陨石击中后偏转弹开
- 保护下方区域

### 5.4 蓝图升级

| 轮次 | 蓝图复杂度 | 说明 |
|------|------------|------|
| 第1轮 | 单一蓝图 | 只有一种建筑，形状简单 |
| 第2轮 | 双蓝图 | 两种建筑组合，需要更多材料 |
| 第3轮 | 复合蓝图 | 三种建筑叠加，需要精确配合 |

## 六、建造操作

### 6.1 建造流程

```
看到蓝图 → 收集碎片 → 合成材料 → 走到蓝图位置 → 放置材料 → 建筑完成
```

### 6.2 放置规则

| 规则 | 说明 |
|------|------|
| 放置区域 | 必须在蓝图绿色高亮区域内 |
| 放置方式 | 站在区域内，按住放置键 |
| 放置速度 | 0.5秒/块 |
| 吸附效果 | 材料自动飞向蓝图下一个空位 |
| 放置反馈 | 每放置一块，蓝图填充一部分 |

### 6.3 合作建造

| 条件 | 效果 |
|------|------|
| 两人同时在蓝图区域 | 建造速度翻倍 |
| 两人放置不同材料 | 自动组合（如水砖+火砖=蒸汽屏障） |
| 两人同时放置同一位置 | 该位置建筑耐久+50% |

### 6.4 建筑完成

**蓝图填满后，建筑自动成型：**

- 碎片飞舞组合成完整建筑
- 获得完整属性和视觉效果
- 开始发挥防御功能

## 七、灾害系统

### 7.1 灾害来临机制

**核心设计：灾害渐进式入侵，不是突然出现。**

```
预告(8s) → 渐进入侵(40s) → 高潮冲击(15s) → 修整(12s)
              ↓                  ↓
        灾害从边缘逼近      灾害到达中心区域
        玩家边建造边观察    所有建筑承受最大压力
```

### 7.2 五种灾害

#### 山火

| 属性 | 说明 |
|------|------|
| 来源方向 | 地图左侧或右侧 |
| 推进速度 | 1格/秒 |
| 预告信号 | 地平线泛红，烟雾升起 |
| 冲击方式 | 火焰墙缓慢推进 |
| 对材料效果 | 水砖减速，冰砖阻断，火砖燃烧 |
| 对角色效果 | 火人接触受伤，水人不受影响 |
| 正确建筑 | 防火墙（水砖/冰砖） |

#### 洪水

| 属性 | 说明 |
|------|------|
| 来源方向 | 地图底部 |
| 涨速 | 0.5格/秒 |
| 预告信号 | 底部出现水位线，雨声 |
| 冲击方式 | 水位逐渐上涨 |
| 对材料效果 | 火砖蒸发挡水，岩浆砖免疫 |
| 对角色效果 | 火人接触受伤，水人可游泳 |
| 正确建筑 | 防洪堤（火砖/岩浆砖） |

#### 地震

| 属性 | 说明 |
|------|------|
| 来源方向 | 全图震动 |
| 冲击频率 | 每3秒一次冲击波 |
| 预告信号 | 轻微震动，地面裂纹 |
| 冲击方式 | 周期性冲击波 |
| 对材料效果 | 非石砖材料受损，石砖免疫 |
| 对角色效果 | 移动减速，冲击波造成伤害 |
| 正确建筑 | 加固塔（石砖） |

#### 暴风雪

| 属性 | 说明 |
|------|------|
| 来源方向 | 地图顶部 |
| 降速 | 1格/秒 |
| 预告信号 | 天空变暗，开始飘雪 |
| 冲击方式 | 冰晶持续降落 |
| 对材料效果 | 水砖冻裂，冰砖变脆 |
| 对角色效果 | 水人移动减速，火人不受影响 |
| 正确建筑 | 避难所（火砖+石砖） |

#### 陨石雨

| 属性 | 说明 |
|------|------|
| 来源方向 | 天空随机位置 |
| 频率 | 每2秒1颗，共10颗 |
| 预告信号 | 地面出现橙色预警圈 |
| 冲击方式 | 陨石从天而降 |
| 对材料效果 | 砸中-10HP，石砖减伤80% |
| 对角色效果 | 砸中-10HP |
| 正确建筑 | 导流板+避难所（石砖） |

### 7.3 灾害轮次编排

| 轮次 | 灾害 | 难度 | 说明 |
|------|------|------|------|
| 第1轮 | 山火 或 洪水 | ★ | 教学，单一灾害 |
| 第2轮 | 另一基础灾害 或 暴风雪 | ★★ | 角色轮转 |
| 第3轮 | 地震 或 陨石雨 或 双灾害 | ★★★ | 终局考验 |

## 八、游戏流程

### 8.1 单轮流程

```
灾害预告(8s) → 碎片掉落(10s) → 合成建造(25s) → 灾害冲击(35s) → 修整(12s)
```

### 8.2 各阶段详解

#### 灾害预告（8秒）
- 显示灾害类型和方向
- 显示建筑蓝图（位置+材料需求）
- 天空掉落少量碎片（预热）
- 玩家观察并规划

#### 碎片掉落（10秒）
- 碎片从天空密集掉落
- 灾害区域附近掉落对应碎片
- 玩家分头接住碎片
- 碎片落地3秒后消失

#### 合成建造（25秒）
- 玩家在合成台合成材料
- 根据灾害类型选择合成什么
- 走到蓝图区域放置材料
- 两人合作加速建造

#### 灾害冲击（35秒）
- 灾害从边缘渐进入侵
- 建筑开始承受压力
- 玩家修补受损建筑
- 高潮阶段所有建筑承受最大压力

#### 修整（12秒）
- 灾害退去
- 结算本轮表现
- 选择升级选项
- 准备下一轮

### 8.3 章节结构

```
第一章「迷雾觉醒」(12节) → 第二章「裂隙深渊」(12节) → 第三章「双生迷城」(12节)
```

### 8.4 失败条件

- 任意角色HP归零 → 游戏结束
- 失败后可重开当前节

## 九之二、技能系统

### 9.3 技能设计原则

**技能不是"伤害技能"，而是"协作工具"。**

每个技能都应该：
1. 与碎片/合成/建造系统产生交互
2. 创造双人配合的时刻
3. 强化角色的定位
4. 可以通过升级获得成长

### 9.4 水人技能

#### 被动：寒霜体质

水人接住碎片时，30%概率冻结。跳跃接住时概率提升至50%。

**冻结效果：** 碎片存续时间从3秒延长至5秒，合成时材料HP+2。

#### 主动：冻结（E键，冷却12秒）

释放寒霜波，冻结前方区域。

| 目标 | 效果 |
|------|------|
| 空中碎片 | 原地悬停3秒，方便接住 |
| 地面碎片 | 存续时间+10秒 |
| 队友 | 获得"寒霜护盾"，5秒内减伤30% |
| 灾害 | 山火减速50%，持续3秒 |

#### 终极：暴风雪（Q键，需解锁，冷却60秒）

在指定区域召唤暴风雪，区域内所有碎片冻结10秒，己方建筑获得冰霜强化。

### 9.5 火人技能

#### 被动：烈焰体质

火人接住碎片时，30%概率点燃。跳跃接住时概率提升至50%。

**点燃效果：** 合成时材料属性+2，放置后第一次接触灾害伤害翻倍。

#### 主动：灼烧（E键，冷却12秒）

释放火焰波，点燃前方区域。

| 目标 | 效果 |
|------|------|
| 空中碎片 | 掉落速度+50%，合成属性+2 |
| 地面碎片 | 合成时属性+2 |
| 队友 | 获得"烈焰护盾"，5秒内免疫减速 |
| 灾害 | 暴风雪融化区域，持续3秒 |

#### 终极：烈焰风暴（Q键，需解锁，冷却60秒）

在指定区域召唤火焰，区域内所有碎片点燃（合成属性+3），己方建筑获得烈焰强化。

### 9.6 组合技：温砖

**触发条件：** 火人先点燃碎片，水人再冻结同一块碎片。

**温砖属性：**
| 属性 | 数值 |
|------|------|
| HP | 20 |
| 抗性 | 全抗性+20% |
| 特殊效果 | 放置后产生"温差场"，对所有灾害都有一定抗性 |

**温砖是双人配合的最高奖励——只有两人协作才能获得最强材料。**
