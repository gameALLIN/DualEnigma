# 地图设计

> **文档版本**: v2.0  
> **最后更新**: 2026-07-07  
> **对应GDD版本**: v4.0

---

## 一、设计原则

**横板2D视角，地图是地面上方的一个固定矩形区域。**

玩家不需要学习复杂地图布局，每局游戏的区别在于：
- 什么灾害来袭
- 蓝图要求在哪里建什么
- 环境压迫如何影响行动路线

---

## 二、地图结构

### 2.1 整体布局

这是一个横板2D游戏，玩家从侧面观察整个场景。

```
┌────────────────────────────────────────┐
│              天空（碎片掉落）            │
│                                        │
│     ┌──────────────────────────┐       │
│     │                          │       │
│     │      建筑区域            │       │
│     │   （玩家活动范围）        │       │
│     │                          │       │
│     └──────────────────────────┘       │
│━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━│ ← 地面
└────────────────────────────────────────┘
```

### 2.2 三层结构

**天空层（上部）：** 碎片从这里掉落，覆盖整个地图宽度。

**建筑区域（中部）：** 矩形区域，玩家在这里移动、合成、建造。

**地面层（下部）：** 水平地面，建筑必须建立在地面上或已有建筑之上。

### 2.3 建筑区域

地图正中央有一个矩形区域，这是玩家活动的主要场所。

**建筑区域尺寸：** 30格宽 × 12格高（960×384像素）

**建筑区域内包含：**
- 合成台（位于区域左侧边缘）
- 蓝图显示区域（根据关卡动态变化）
- 玩家活动空间

---

## 三、关键位置

### 3.1 合成台

**位置：** 建筑区域内，左侧边缘

**功能：** 玩家在这里将碎片合成为建筑材料

**设计考量：**
- 放在建筑区域内，合成后可以立即建造
- 只有一个合成台，两人需要协调使用时机
- 合成台不会被灾害破坏

### 3.2 玩家出生点

**位置：** 建筑区域中央，地面上方

**功能：** 每轮开始时玩家出现的位置

**设计考量：**
- 出生点在建筑区域中心，方便向左右移动
- 紧邻地面，可以立即开始收集碎片

### 3.3 碎片掉落区

**位置：** 天空层，覆盖整个建筑区域上方

**功能：** 碎片从这里随机掉落

**掉落规律：**
- 碎片在建筑区域上方随机位置出现
- 靠近灾害方向的区域掉落更多对应碎片
- 掉落轨迹线提前显示，方便预判

## 四、蓝图与关卡的关系

### 4.1 蓝图动态生成

蓝图不是固定在地图上的，而是根据当前关卡的灾害类型动态生成。

**蓝图生成规则：**

| 灾害 | 蓝图位置 | 说明 |
|------|----------|------|
| 山火 | 建筑区域左侧 | 火焰从左侧来袭，需要在这里建防火墙 |
| 洪水 | 建筑区域底部 | 水位从底部上涨，需要在这里建防洪堤 |
| 地震 | 建筑区域中心 | 震动来自全图，需要在中心建加固塔 |
| 暴风雪 | 建筑区域上方 | 冰雪从顶部降落，需要建有顶避难所 |
| 陨石雨 | 建筑区域上方 | 陨石从天而降，需要建导流板 |

### 4.2 蓝图与环境压迫的配合

蓝图的位置会影响环境压迫的难度。

**例子：山火来袭**
- 蓝图在左侧（火焰来袭方向）
- 那里温度最高，水人蒸发最快
- 玩家需要火人提供保护才能在那里建造

**例子：洪水来袭**
- 蓝图在底部（水位上涨方向）
- 那里湿度最高，火人熄灭最快
- 玩家需要水人提供保护才能在那里建造

**设计意图：** 蓝图位置本身就是策略挑战——必须在危险区域建造。

## 五、不同灾害下的地图变化

### 5.1 山火来袭

**视觉变化：**
- 左侧出现火焰墙，缓慢向右推进
- 左侧区域泛红，热浪扭曲效果
- 左侧碎片掉落更多冰晶碎片

**安全区：**
- 右侧相对安全
- 左侧危险（火焰+高温）

**玩家行动：** 从右向左建造防火墙

### 5.2 洪水来袭

**视觉变化：**
- 底部出现水位线，水位逐渐上涨
- 底部区域潮湿，水渍效果
- 底部碎片掉落更多熔岩碎片

**安全区：**
- 上部相对安全
- 底部危险（水位上涨）

**玩家行动：** 从上向下建造防洪堤

### 5.3 地震来袭

**视觉变化：**
- 全图震动，地面出现裂纹
- 冲击波周期性出现
- 全图掉落岩石碎片

**安全区：**
- 没有绝对安全区
- 两人靠近时相对安全

**玩家行动：** 在建筑区域中心建造加固塔

### 5.4 暴风雪来袭

**视觉变化：**
- 天空变暗，雪花从顶部降落
- 顶部区域温度最低
- 顶部碎片掉落更多冰晶碎片

**安全区：**
- 底部相对安全
- 顶部危险（冰雪降落）

**玩家行动：** 建造有顶的避难所

### 5.5 陨石雨来袭

**视觉变化：**
- 天空出现橙色预警圈，标记陨石落点
- 预警圈在建筑区域随机分布
- 预警圈区域掉落岩石碎片

**安全区：**
- 没有固定安全区（预警圈随机）
- 躲在掩体内相对安全

**玩家行动：** 建造导流板或避难所

## 六、地图尺寸参数

### 6.1 整体尺寸

| 参数 | 数值 | 说明 |
|------|------|------|
| 地图宽度 | 60格（1920像素） | 左右移动范围 |
| 地图高度 | 20格（640像素） | 从地面到天空 |
| 地面位置 | Y=0 | 地基线 |
| 天空高度 | Y=20 | 碎片掉落起始高度 |

### 6.2 建筑区域尺寸

| 参数 | 数值 | 说明 |
|------|------|------|
| 区域宽度 | 30格（960像素） | 建造横向范围 |
| 区域高度 | 12格（384像素） | 建造纵向范围 |
| 区域位置 | 地图中心偏上 | 地面上方 |
| 合成台位置 | 区域左侧边缘 | 靠近区域边界 |

### 6.3 角色参数

| 参数 | 数值 | 说明 |
|------|------|------|
| 角色宽度 | 1格（32像素） | 碰撞体宽度 |
| 角色高度 | 2格（64像素） | 碰撞体高度 |
| 移动速度 | 4格/秒 | 基础移速 |
| 跳跃高度 | 3格 | 基础跳跃 |

## 七、视觉设计

### 7.1 背景

**默认背景：** 深青灰色（#263238），简约风格

**灾害变化：**
- 山火：背景偏橙红，火焰粒子
- 洪水：背景偏蓝，雨滴粒子
- 地震：背景偏灰，震动效果
- 暴风雪：背景偏白，雪花粒子
- 陨石：背景偏暗，预警圈标记

### 7.2 地面

**默认地面：** 灰色砖块纹理

**灾害变化：**
- 山火：热浪扭曲效果
- 洪水：水渍效果
- 地震：裂纹效果
- 暴风雪：结霜效果
- 陨石：陨石坑效果

### 7.3 建筑区域

**默认区域：** 虚线边框，半透明绿色

**蓝图显示：** 绿色高亮，显示建筑轮廓和材料需求

## 八、关卡与地图的关系

### 8.1 固定地图，变化蓝图

每关使用同一张地图，但蓝图根据灾害类型变化。

**好处：**
- 玩家熟悉地图布局，不需要重新学习
- 变化来自蓝图和环境，而不是地形
- 设计复杂度降低，更容易平衡

### 8.2 关卡难度与蓝图复杂度

| 轮次 | 蓝图复杂度 | 说明 |
|------|------------|------|
| 第1轮 | 单一蓝图 | 只有一种建筑，形状简单 |
| 第2轮 | 双蓝图 | 两种建筑组合 |
| 第3轮 | 复合蓝图 | 三种建筑叠加 |

### 8.3 章节与环境变化

| 章节 | 主题 | 环境特点 |
|------|------|----------|
| 第一章「迷雾觉醒」 | 基础教学 | 灾害单一，环境压迫较轻 |
| 第二章「裂隙深渊」 | 进阶挑战 | 灾害加强，环境压迫加重 |
| 第三章「双生迷城」 | 终极考验 | 双灾害叠加，环境压迫最强 |
