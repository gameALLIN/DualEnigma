# Game Design Workspace

游戏策划工作区，用于存放所有策划相关文档和资源。

## 目录结构

| 目录 | 说明 |
|------|------|
| `DesignDocuments/` | 策划文档 — 游戏设计文档(GDD)、功能规格说明、系统设计等 |
| `NumericalDesign/` | 数值表 — 平衡数值、公式设计、成长曲线等 |
| `LevelDesign/` | 关卡设计 — 关卡布局、地图设计、流程图等 |
| `NarrativeDesign/` | 剧情脚本 — 故事大纲、对白、任务设计等 |
| `ArtRequirements/` | 美术需求 — 美术需求文档、参考图等 |
| `AudioRequirements/` | 音效需求 — 音效/音乐需求文档、参考等 |
| `MeetingNotes/` | 会议纪要 — 策划会议记录、评审纪要等 |
| `VersionHistory/` | 版本记录 — 文档版本变更记录、迭代历史等 |
