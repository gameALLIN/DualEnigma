## v2.1 — 2026-07-06 材料获取系统重构

### 变更原因
与项目方研讨材料获取方式后，将"源点采集"替换为"合作解谜+局内商店+废墟回收"三条途径。

### 核心变更

| 维度 | v2.0 | v2.1 |
|------|------|------|
| 材料获取 | 源点站桩采集（站2秒得1块） | **三条途径：合作解谜产出 + EC商店购买 + 灾害废墟回收** |
| 货币系统 | 无 | **能量晶体(EC)，双方共享** |
| 高级材料获取 | 技能原地升级 | **两人配合激活（站在材料旁同时长按技能键）** |
| 灾害中材料来源 | 纯靠库存 | **库存 + 废墟合作回收** |
| 升级系统 | 6+6+4=16个选项 | **6+6+7=19个选项（新增晶体倍增/回收效率/商店折扣）** |
| 升级+商店时间 | 10秒 | **15秒** |
| 单轮时长 | ~90秒 | **~95秒** |
| 项目周期 | 10周 | **11周** |

### 新增的系统
- **合作解谜节点**：4种节点类型（水火管道/双压板宝箱/元素共鸣/冰火通道），强制双人配合
- **EC经济系统**：散落晶体拾取+灾害奖励+完美解谜奖励，双方共享钱包
- **局内商店**：核心旁交互，5种商品（水砖包/火砖包/石砖包/应急空投/加固涂料）
- **废墟回收**：灾害中被毁建筑掉落碎片，两人同时触碰回收为随机材料
- **合作激活高级材料**：冰砖/岩浆砖/石砖均需两人配合激活

### 删除的系统
- ~~源点采集系统（水源点/火源点）~~
- ~~采集冷却机制~~
- ~~技能原地升级材料（改为双人合作激活）~~

## v2.0 — 2026-07-06 核心方向重构

### 变更原因
与项目方确认游戏核心方向后，对GDD进行大幅重构。

### 核心变更

| 维度 | v1.0 | v2.0 |
|------|------|------|
| 游戏类型 | 合作+对抗+挑战三模式 | **纯合作防灾建造** |
| 威胁来源 | 怪物波次 | **自然灾害（5种）** |
| 游戏目标 | 还原蓝图+评分 | **保护核心水晶不被灾害摧毁** |
| 联机方式 | 本地双人 | **联网双人** |
| 材料体系 | 6种+蒸汽+复杂交互矩阵 | **5种，仅1条交互规则** |
| 建造系统 | 网格+复杂承重物理 | **网格+简化承重** |
| 成长系统 | 无 | **局内Roguelite升级（每轮选1升级）** |
| 关卡结构 | 8关线性关卡 | **单局3轮，灾害递进** |
| 单局时长 | 3~5分钟/回合×3~5回合 | **3轮≈4~5分钟/整局** |
| 项目周期 | 12周 | **10周** |

### 删除的系统
- ~~PVP对抗模式~~
- ~~挑战模式~~
- ~~怪物系统~~
- ~~蓝图建造+评分系统~~
- ~~蒸汽材料~~
- ~~复杂承重物理~~
- ~~多地形系统（水域/岩浆/冰面/陷阱）~~

### 新增的系统
- **灾害系统**：5种自然灾害（山火/洪水/地震/暴风雪/陨石雨），每种考验不同材料
- **灾害有限行动**：灾害中只能修补角色周围3×3格，走位=策略
- **灾害预告机制**：5秒预告让玩家决策建造方向
- **Roguelite升级系统**：每轮后从随机选项中选1升级，材料解锁+属性强化
- **核心水晶保护机制**：建筑是核心的"血条"
