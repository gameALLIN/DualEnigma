### 1.2 音乐风格指引
- 整体基调：轻松愉快，有派对游戏氛围
- 乐器：钢琴、木琴(水主题) + 吉他、铜管(火主题) + 电子合成器(整体)
- 节拍：120~140 BPM，匹配建造节奏
- 水主题段使用水滴/铃铛音色，火主题段使用鼓/铜管音色

## 三、音频技术需求

### 3.1 格式规范

| 用途 | 格式 | 采样率 | 比特率 |
|------|------|--------|--------|
| BGM | OGG | 44100Hz | 192kbps |
| 音效 | WAV | 44100Hz | 16bit |
| UI音效 | WAV | 22050Hz | 16bit |

### 3.2 混音规范

| 类型 | 音量基准 | 说明 |
|------|----------|------|
| BGM | -12dB | 可随场景动态调整 |
| 角色音效 | -6dB | 玩家行为优先级最高 |
| 建造音效 | -9dB | |
| 事件音效 | -3dB | 事件需突出 |
| 怪物音效 | -9dB | |
| UI音效 | -12dB | |
| 倒计时音效 | -6dB | 最后10秒逐渐升高 |

### 3.3 动态混音需求
- 建造阶段：BGM音量100%，环境音70%
- 怪物波次：BGM切换至战斗曲，音量110%，环境音降低
- Boss战：BGM音量120%，低频增强
- 暂停时：所有音频降低至20%
