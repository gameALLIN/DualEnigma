# 地图设计

> **文档版本**: v3.2  
> **最后更新**: 2026-07-08  
> **对应GDD版本**: v6.1  
> **设计原则**: 一切为了合作，地图上的所有设计都应该让两人想待在一起。

---

## 一、地图结构

### 1.1 整体布局

横板2D视角，地图是地面上方的矩形区域。

```
┌─────────────────────────────────────────┐
│              天空（碎片掉落）             │
│                                         │
│          ◇ 碎片掉落区域 ◇               │
│         （建筑区域外，危险区）            │
│                                         │
│     ┌──────────────────────────┐        │
│     │                          │        │
│     │      建筑区域            │        │
│     │    （安全区，不能捡碎片）  │        │
│     │                          │        │
│     │         ◇合成台          │        │
│     │                          │        │
│     └──────────────────────────┘        │
│━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━│ ← 地面
└─────────────────────────────────────────┘
```

### 1.2 建筑区域 = 安全区

**建筑区域从地图中心到地面，大小后续确定。**

**规则（v4.2更新）：**
- 灾难开始前，建筑区域是**完全安全区**
- 建筑区域内不能接取天上掉落的碎片
- **只有两人同时在建筑区域内才能建造**
- 玩家必须跑到建筑区域外才能捡碎片
- 建筑区域外需要双生庇护（能量系统）

**灾害冲击阶段建筑区域安全性（v4.2决策）：**
- 建筑区域内提供**50%伤害减免**（庇护环境伤害不生效，灾难物理伤害减半）
- 建造的建筑（防火墙/避难所等）提供**100%完全保护**
- 建筑区域外**无保护**（0%减免）

**设计意图：**
- 创造"出去捡→回来建"的循环
- 出去捡碎片时需要两人配合（维持庇护能量）
- 回来建造时，两人必须在一起才能建造
- 建造本身就是合作行为
- 灾害冲击阶段，建造的建筑提供完全保护，奖励玩家的建造行为

### 1.3 合成台位置

建筑区域内有**2台合成台**（轮次1-2），轮次3减为1台。

**位置布局：**
- 主合成台：建筑区域中心
- 副合成台：中心偏右3格（对称分布）

```
┌──────────────────────────┐
│                          │
│     ◇主合成台    ◇副合成台│
│      (中心)     (中心+3)  │
│                          │
└──────────────────────────┘
```

**设计理由：**
- 双合成台提升建造效率，减少等待时间
- 对称分布方便两人分工合作
- 轮次3减为1台，增加资源管理压力

## 二、合作导向设计

### 2.1 碎片收集循环

**核心循环：出去捡 → 回来建**

```
建筑区域（安全）→ 跑出去捡碎片（危险）→ 跑回来建造（安全）
      ↑                                         ↓
      └─────────────────────────────────────────┘
```

**建造规则：两人必须同时在建筑区域内才能建造**

**设计意图：**
- 出去捡碎片时，两人必须保持靠近（双生庇护）
- 回来建造时，两人必须在一起才能建造
- 建造本身就是合作行为，不是单人操作

### 2.2 碎片掉落位置

碎片掉落位置分为两类：

| 区域 | 位置 | 能否捡碎片 | 危险度 |
|------|------|------------|--------|
| 建筑区域外 | 地图两侧、上方 | 可以捡 | 需要庇护 |
| 建筑区域内 | 地图中心到地面 | 不能捡 | 安全 |

**掉落规律：**
- 碎片主要掉落在建筑区域外
- 靠近灾害方向掉落更多对应碎片
- 掉落轨迹线提前显示，方便预判

### 2.3 蓝图位置

蓝图出现在建筑区域内。

**为什么这样设计：**
- 建造时两人在安全区内
- 不需要担心建造时被灾害伤害
- 专注于建造，不需要分心躲避

### 2.4 双生庇护的整合

建筑区域外需要双生庇护，建筑区域内安全。

**这意味着：**
- 出去捡碎片时，能量会消耗（远离庇护区）
- 必须在能量耗尽前回到建筑区域
- 建筑区域本身就是"庇护锚点"

## 三、地图细节

### 3.1 地面

地面是水平直线，贯穿整个地图。

**地面特性：**
- 平坦无障碍物（基础状态）
- 建筑必须建立在地面上或已有建筑之上
- 玩家可以在地面上自由移动

**动态地形规则**（灾难可临时改变地形）：

| 灾难 | 地形变化 | 碰撞体 | 持续时间 |
|------|----------|--------|----------|
| V4 地面塌陷 | 坑洞出现 | 临时不可通行区域 | 整轮 |
| P4 地震波 | 地面起伏 | 角色被弹起 | 持续 |
| V3 植物疯长 | 藤蔓障碍 | 临时障碍物 | 可被火砖烧毁 |
| T3 重力反转 | 角色被拉向天空 | 无碰撞体，纯位移 | 周期性 |

### 3.2 背景

简约风格，深青灰色（#263238）。

**背景变化：**
- 根据灾害类型，背景颜色和粒子效果变化
- 不影响 gameplay，纯视觉效果

### 3.3 碎片掉落视觉

碎片从天空掉落时，有轨迹线提前显示落点。

**作用：**
- 帮助玩家预判碎片位置
- 两人可以沟通"那块碎片往你那边掉了"
- 增加合作沟通机会

**变化来自：**

## 六、已敲定参数

### 6.1 建筑区域大小

**15×8格（480×256像素）**

两人在区域内任何位置都能保持3格以内，维持庇护能量。

### 6.2 地图整体尺寸

**40×20格（1280×640像素）**

- 宽度40格：碎片掉落区域足够大
- 高度20格：天空到地面有足够空间
- 建筑区域居中：两侧各12.5格空白

### 6.3 区域边界视觉

- 建筑区域内：地面偏亮绿色
- 建筑区域外：地面偏暗灰色
- 边界处：半透明绿色光柱

### 6.4 碎片掉落密度

每轮 **28-40个碎片**（与章节策划v2.0 §4.5对齐）：
- 预告阶段（5秒）：掉落3-5个（预热）
- 碎片收集阶段（15秒）：掉落25-35个（主要收集）
- 其他阶段：0个
