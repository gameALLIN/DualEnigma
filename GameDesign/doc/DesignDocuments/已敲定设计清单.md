## 一、游戏核心

| 项目 | 敲定内容 |
|------|----------|
| 游戏名称 | 《双生迷城》(DualEnigma) |
| 类型 | 双人联网2D横板合作解密建造 |
| 平台 | PC（键鼠），强制双人联网 |
| 美术风格 | 矢量几何+迷雾废墟+纯特效，零外部美术资源依赖，全程序化生成 |
| PPU | 32（1格=32px=1Unity单位） |
| 核心体验 | "灾害来了，你还活着吗？"——碎片争夺、双生庇护、蓝图执行三大张力点 |
| 核心循环 | 出去捡碎片（危险，需要庇护）→ 回来建造（安全，两人必须在一起）→ 循环 |
| 胜利条件 | 撑过全部36轮灾害 |
| 失败条件 | 任意角色HP归零=游戏立即结束，无倒地等待，无复活 |

## 二、角色

| 项目 | 水人(Aqua) | 火人(Ignis) |
|------|-----------|-------------|
| HP | 100 | 100 |
| 移速 | 4.0格/秒 | 4.0格/秒 |
| 跳跃 | 标准2格 | 2格，可二段跳至3格 |
| 搬运上限 | 3块（天赋可升至4块） | 3块（天赋可升至4块） |
| 被动技能 | 寒霜体质（接住碎片30%冻结，跳跃50%，同时100%） | 烈焰体质（接住碎片30%点燃，跳跃50%，同时100%） |
| 角色选择 | 游戏开始前选择，**不允许相同角色**（强制一水一火） | 同左 |

### 碎片掉落轨迹与跳跃平衡

- 碎片从5-8格高度掉落
- 约30%碎片在3格高度有水平加速段 — 火人可二段跳在此阶段截获(×2奖励)
- 其余70%碎片落至地面(0格)，两人均可正常接住
- 确保不出现"只有火人能接到"的碎片，二段跳提供时间优势而非能力门槛 ⚠️待测试

## 三、双生庇护系统

### 3.1 能量机制

| 项目 | 敲定内容 |
|------|----------|
| 能量最大值 | 100 |
| 恢复速率 | +20/秒（队友在3格内）⚠️待测试 |
| 消耗速率 | -33/秒（队友超过3格）⚠️待测试 |
| 耗尽时间 | 约3秒（100÷33） |
| 耗尽后果 | 开始扣HP |
| HP恢复规则 | 轮次间**不自动恢复**；仅通过天赋(生命回复/急救)、技能(净化+10HP)、温砖(+1HP/秒)恢复 |
| 能量跨轮保留 | 能量值保留不重置 |
| HP跨轮保留 | HP值保留不重置 |

### 3.2 五种庇护环境

| 环境 | 受影响角色 | 能量耗尽后 | 特殊规则 |
|------|------------|------------|----------|
| 火山 | 水人(-3HP/秒) | 火人完全安全 | 火人保护水人 |
| 洪水 | 火人(-3HP/秒) | 水人完全安全 | 水人保护火人 |
| 暴风雪 | 水人(-2HP/秒，移速-50%) | 火人**完全免疫** | 火人保护水人，冰砖HP+50% |
| 地震 | 双方(-3HP/次冲击波) | 1格内免疫，1-3格半伤 | 互相稳定重心 |
| 陨石 | 双方(被砸概率50%) | 3格内25%，1格内10%，掩体内0%(掩体承伤×2) | 互相预警掩护 |

### 3.3 庇护数值成长（通过天赋）

| 天赋 | 修改参数 | 叠加上限 |
|------|----------|----------|
| 能量扩容 | 能量最大值+30/次 | 无上限 |
| 能量恢复 | 恢复速率+30%/次 | ×3上限(+60/秒) |
| 庇护扩展 | 庇护距离+1格/次 | 无上限(受地图限制) |
| 护体类 | 扣血速度×0.5/次 | 封底×0.1(保留10%) |

### 3.4 技能与庇护交互

| 技能类型 | 对庇护影响 |
|----------|-----------|
| 护盾类(寒霜/火焰护盾) | 不改变能量，直接抵消伤害，持续10秒 |
| 净化 | 清除M5庇护削弱效果 |
| 领域类(极寒/烈焰领域) | 区域内不消耗能量(10秒) |
| 无敌类(绝对零度/焚天灭地) | 无敌期间不消耗能量(3秒) |
| 暴风雪/烈焰风暴等 | 不影响能量 |
| 海啸/熔岩喷发 | 不影响能量 |

### 3.5 断线处理

| 阶段 | 时间 | 行为 |
|------|------|------|
| 即时断线 | 0秒 | 游戏暂停，显示等待重连 |
| 重连窗口 | 0-30秒 | 倒计时，游戏暂停 |
| AI接管 | 30秒后 | 跟随队友，保持2格距离，不使用技能/不捡碎片/不建造 |
| 最终超时 | 120秒后 | 游戏结束，判定失败 |
| 重连成功 | 任意时刻 | 恢复完全控制，无惩罚 |

### 6.1 建筑类型

| 建筑 | 形状 | 基础HP | 用途 |
|------|------|--------|------|
| 防火墙 | 竖直墙体 | 50 | 阻挡火焰蔓延 |

| 加固塔 | 金字塔结构 | 60 | 抗震稳定 |

| 导流板 | 倾斜结构 | 35 | 偏转陨石轨迹 |

### 6.2 伤害等级

| 等级 | 符号 | 倍率 |
|------|------|------|
| 免疫 | ★★★ | 0× |
| 强抗性 | ★★ | 0.3× |
| 抗性 | ★ | 0.6× |
| 无加成 | — | 1.0× |
| 弱点 | ✗ | 1.5× |

### 6.3 灾难基础DPS

| 环境 | 基础DPS | 频率 | 20秒总伤害 |
|------|---------|------|-----------|
| 火山 | 5 HP/秒 | 持续 | 100 HP |
| 洪水 | 5 HP/秒 | 持续 | 100 HP |
| 暴风雪 | 3 HP/秒 | 持续 | 60 HP |
| 地震 | 8 HP/次 | 每3秒1次 | 约48 HP |
| 陨石 | 15 HP/次 | 随机 | 约75 HP |

> 伤害公式：实际伤害 = 基础DPS × 材料抗性倍率 × 灾难强度系数 × 灾难渐进强度

### 6.4 建筑操作规则

| 规则 | 内容 |
|------|------|
| 放置 | 不能重叠；必须在地面上或已有建筑之上；防火墙/防洪堤有正反面，导流板有倾斜方向 |
| 拆除 | 建造阶段和修整阶段可拆；拆除不返还材料；耗时1秒/块 |
| 修补 | 仅修整阶段可修补；消耗同类型材料1块恢复50%HP；耗时1秒/块；灾害冲击阶段不可修补 |
| M4特殊 | 已放置方块保持不变，新方块需按新蓝图材料执行；不需要的方块可拆除(不返还) |

### 6.5 蓝图生成规则

| 规则 | 内容 |
|------|------|
| 形状库 | 防火墙=竖线、防洪堤=横线、加固塔=金字塔、避难所=矩形、导流板=斜线 |
| 大小范围 | 轮次1:3-4块 / 轮次2:5-6块 / 轮次3:7-8块 / 最终关:9-10块 |
| 位置约束 | 必须在15×8格建筑区域内；根据灾难入侵方向布置防御建筑 |
| 间距 | 建筑间至少1格，不允许重叠 |
| 随机性 | 约束范围内±2格随机偏移 |
| 显示 | 灾害预告阶段③显示完整蓝图位置和材料需求 |

### 6.6 暴风雪特殊机制

- ★★★强化 = 免疫(0×伤害) + HP+50%
- ★★强化 = 抗性等级 + HP+50%
- HP+50%作用于建筑基础HP（如防火墙50→75HP）

### 6.7 陨石特殊机制

- 躲在同一避难所内被砸概率0%，但掩体承伤×2

### 6.8 建筑HP成长（天赋）

| 天赋 | 效果 | 叠加 |
|------|------|------|
| 结构强化(★) | HP+30% | 线性 |
| 建筑大师(★★★) | 建筑效果+50% | 线性 |

## 十四、网络同步规范

### 14.1 同步架构

| 项目 | 敲定内容 |
|------|----------|
| 同步架构 | 状态同步(State Sync) |
| 网络模式 | Host-Client(房主为Host) |
| Tick Rate | 20Hz(50ms) |
| 插值缓冲 | 100ms |
| 超时判定 | 5秒无心跳 |
| 带宽预估 | <50KB/s |
| 协议 | UDP(可靠+不可靠混合) |

### 14.2 同步分类

| 类型 | 频率 | 可靠性 |
|------|------|--------|
| 角色位置/速度/动画 | 20次/秒 | 不可靠 |
| 能量/HP/碎片位置 | 10次/秒 | 可靠 |
| 关键事件(碎片接住/灾难/建筑/技能) | 事件驱动 | 可靠有序 |
| 阶段切换 | 事件驱动 | 可靠有序 |

### 14.3 关键事件同步策略

| 系统 | 同步策略 |
|------|----------|
| 碎片掉落 | Host生成掉落计划，同步给Client，双方各自模拟物理 |
| 碎片接住 | 接住方发起事件，Host判定同时接住(时间差<100ms) |
| 灾难触发 | Host同步灾难类型和参数，双方各自模拟效果 |
| 随机元素 | Host生成随机种子同步给Client确保一致 |
| 建筑放置 | 操作方发起事件，同步建筑类型/材料/位置 |
| 建筑受损 | 双方各自计算，修整阶段Host同步当前HP |
| 技能释放 | 操作方发起事件，同步技能ID/目标位置 |

### 14.4 延迟补偿

| 机制 | 说明 |
|------|------|
| 客户端预测 | 角色移动使用客户端预测，服务端校正 |
| 插值 | 其他玩家位置使用100ms插值缓冲 |
| 时间戳 | 关键事件附带时间戳，按顺序处理 |
| 冲突回滚 | 碎片接住冲突以Host判定为准，Client回滚 |

### 14.5 断线重连状态恢复

| 恢复内容 | 方式 |
|----------|------|
| 角色状态 | 同步当前HP/能量/位置/携带碎片 |
| 建筑状态 | 同步所有建筑类型/材料/当前HP/位置 |
| 游戏阶段 | 同步当前阶段和剩余时间 |
| 碎片状态 | 同步当前存活碎片位置和类型 |
| 天赋/技能 | 同步已选天赋列表和技能卡牌 |
| 灾难状态 | 同步当前灾难类型和强度 |
