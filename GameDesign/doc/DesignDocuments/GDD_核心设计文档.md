## 一、游戏概述

### 1.1 游戏名称
《双生迷城》（DualEnigma）

### 1.2 一句话定义
双人联网2D横板合作游戏，水人与火人根据灾害类型收集碎片、合成材料、按蓝图建造防御建筑，保护彼此免受自然灾害的侵袭。

### 1.3 目标平台
PC（键鼠为主），联网双人

### 1.4 核心体验
> **"灾害来了，你还活着吗？"**

三大张力点：
1. **碎片争夺**——碎片从天而降，落地即碎，必须快速接住
2. **双生庇护**——不同环境下角色持续掉血，必须待在队友身边才能存活
3. **蓝图执行**——在指定区域按图建造，速度和配合决定成败

### 1.5 核心乐趣循环

```
出去捡碎片（危险，需要庇护）→ 回来建造（安全，两人必须在一起）
      ↑                                    ↓
      └────────────────────────────────────┘
```

- 单轮时长：**90秒**（7阶段）
- 章节结构：3章 × 4节 × 3轮 = 36关
- 35种灾难全部保留，每轮1种灾难
- 天赋选择：每轮结束后1次，全游戏36次
- 任意角色HP归零 = 游戏结束；撑过所有灾害 = 胜利

## 二、角色设计

### 2.1 角色选择

游戏开始前，两名玩家选择水人或火人。**不允许选相同角色**（强制一水一火）。

### 2.2 水人（Aqua）

| 属性 | 数值 | 说明 |
|------|------|------|
| 生命值(HP) | 100 | 可升级提升 |
| 移动速度 | 4.0 格/秒 | 基础值 |
| 跳跃高度 | 2格 | 标准跳跃 |
| 搬运上限 | 3块 | 可升级至4块 |

### 2.3 火人（Ignis）

| 属性 | 数值 | 说明 |
|------|------|------|
| 生命值(HP) | 100 | 可升级提升 |
| 移动速度 | 4.0 格/秒 | 基础值 |
| 跳跃高度 | 2格 | 可二段跳至3格 |
| 搬运上限 | 3块 | 可升级至4块 |

### 2.4 双人关系设计

**核心理念：互相保护，而非各自为战**

**设计原则**：每种灾害都会让一方变弱，另一方必须成为保护者。

**单向庇护逻辑**：在火山环境下，火人是安全的，但必须保护水人不死。因为只要一方死亡，游戏就结束。这是"单向保护责任"，不是"单向依赖"。

## 三、双生庇护系统

### 3.1 核心概念

**灾害不只是"从外面打进来"的伤害，而是"脚下的土地本身在伤害你"。**

不同环境下，角色通过"庇护能量"维持生存。两人靠近时能量恢复，远离时能量耗尽后开始掉血。这让合作从"可选"变成"被迫的生存条件"。

**失败条件：** 任意角色HP归零 → 游戏立即结束。

**HP恢复规则：**
- HP在轮次间**不自动恢复**
- 仅通过以下途径恢复：
  - 天赋"生命回复"（★普通）：修整阶段自动恢复2HP/秒
  - 天赋"急救"（★★稀有）：修整阶段立即恢复15HP
  - 技能"净化"：+10HP（即时使用）
  - 温砖效果：+1HP/秒（3×3区域内持续恢复）

### 3.2 庇护能量系统

**能量机制：**

| 状态 | 能量变化 | 说明 |
|------|----------|------|
| 队友在3格内 | +20/秒 | 持续恢复 |
| 队友超过3格 | -33/秒 | 3秒耗尽（100能量） |
| 能量耗尽后 | 开始扣血 | -3HP/秒（根据环境） |

**能量条参数：**
- 最大值：100
- 恢复速率：+20/秒（队友在3格内）
- 消耗速率：-33/秒（队友超过3格）
- 耗尽时间：约3秒

**碎片收集阶段特殊规则（v4.2决策）：**
- 庇护距离：**5格**（其他阶段为3格）
- 能量消耗速率：**-25/秒**（其他阶段为-33/秒）
- 耗尽时间：约4秒（100÷25）
- 碎片掉落范围：建筑区域外**10格内**

> **设计理由**: 碎片收集阶段扩展庇护距离至5格，给予玩家足够的碎片收集空间，同时保持庇护机制的紧张感。碎片掉落限制在10格内，确保玩家可在5秒内往返。

### 3.3 五种庇护机制

| 环境 | 受影响角色 | 能量耗尽后 |
|------|------------|------------|
| 火山/山火 | 水人 | -3HP/秒 |
| 洪水 | 火人 | -3HP/秒 |
| 暴风雪 | 水人 | -2HP/秒，移速-50% |
| 地震 | 双方 | -3HP/次冲击波 |
| 陨石 | 双方 | 被砸概率50%（3格内25%，1格内10%，掩体内0%） |

## 四、碎片系统

### 4.1 碎片类型

只有 **3 种基础碎片**：

| 碎片 | 外观 | 掉落规律 | 稀有度 |
|------|------|----------|--------|
| **冰晶碎片** | 蓝白色棱形 | 天空随机掉落，数量最多 | ★ |
| **熔岩碎片** | 橙红色不规则形 | 火焰/高温区域附近掉落 | ★★ |
| **岩石碎片** | 灰色方形 | 地震/陨石区域掉落，数量最少 | ★★★ |

### 4.2 掉落规则

| 规则 | 说明 |
|------|------|
| 掉落位置 | 建筑区域外（危险区） |
| 掉落频率 | 预告期稀少，灾害期密集 |
| 存续时间 | 落地后 **3秒** 未捡起则粉碎消失 |

### 4.3 接住方式

| 方式 | 效果 |
|------|------|
| 走到落点 | 碎片自动吸附，获得 ×1 |
| 跳跃中接住 | 获得 ×2（奖励操作） |
| 两人同时接住 | 获得 ×3（奖励合作） |

## 五、合成系统

### 5.1 合成规则

**同样的碎片，根据当前灾害类型，合成不同的材料。**

| 当前灾害 | 冰晶碎片 → | 熔岩碎片 → | 岩石碎片 → |
|----------|------------|------------|------------|
| **山火** | 水砖（防火） | 冰砖（强防火） | 石砖 |
| **洪水** | 石砖 | 火砖（防水） | 岩浆砖（强防水） |
| **地震** | 石砖 | 石砖 | 石砖（强化） |
| **暴风雪** | 冰砖 | 火砖（融雪） | 岩浆砖 |
| **陨石雨** | 石砖 | 石砖 | 石砖（防陨） |

### 5.2 合成操作

**站在合成台上，按住交互键即可合成。**

| 材料 | 所需碎片 | 合成时间 | 说明 |
|------|----------|----------|------|
| 水砖 | 冰晶 ×2 | 1秒 | 基础水系材料 |
| 火砖 | 熔岩 ×2 | 1秒 | 基础火系材料 |
| 冰砖 | 冰晶 ×3 | 1.5秒 | 高级水系，免疫山火 |
| 岩浆砖 | 熔岩 ×3 | 1.5秒 | 高级火系，免疫洪水 |
| 石砖 | 冰晶+熔岩+岩石 | 2秒 | 通用高级，免疫地震 |

## 六、建筑蓝图系统

### 6.1 蓝图显示

**灾害预告阶段，游戏在建筑区域内显示建造蓝图：**

- **绿色高亮区域**：必须建造的位置
- **材料图标**：需要什么材料
- **数量标注**：需要多少块

### 6.2 蓝图规则

- 蓝图位置由关卡系统根据灾害类型动态生成
- 蓝图出现在建筑区域内（安全区）
- 建造时两人必须同时在建筑区域内

### 6.3 建筑类型

| 建筑 | 形状 | 用途 |
|------|------|------|
| 防火墙 | 竖直墙体 | 阻挡火焰蔓延 |
| 防洪堤 | 水平屏障 | 阻挡水位上涨 |
| 加固塔 | 金字塔结构 | 抗震稳定 |
| 避难所 | 封闭空间 | 防风雪/陨石 |
| 导流板 | 倾斜结构 | 偏转陨石轨迹 |

### 6.4 建筑操作规则

| 规则 | 定义 |
|------|------|
| 建筑放置 | 建筑不能重叠放置（同一格只能存在1个建筑）；建筑必须放置在地面上或已有建筑之上；建筑放置有朝向要求（防火墙/防洪堤有正反面，导流板有倾斜方向） |
| 建筑拆除 | 建造阶段和修整阶段可以拆除已放置的建筑；拆除不返还材料；拆除耗时1秒/块 |
| 建筑修补 | 仅修整阶段可修补；修补消耗同类型材料1块，恢复50%基础HP；修补耗时1秒/块；灾害冲击阶段不可修补 |
| 建筑重叠 | 不允许重叠放置（同§放置规则） |
| 灾害中修补 | 灾害冲击阶段不可修补（同上） |
| M4预言干扰特殊规则 | M4关卡中蓝图变化时，已放置的方块保持不变，但新增方块需按新蓝图材料执行；已放置但不再需要的方块可拆除（不返还材料） |

### 6.5 蓝图生成规则

| 规则 | 说明 |
|------|------|
| 蓝图形状库 | 根据建筑类型定义基础形状（防火墙=竖线、防洪堤=横线、加固塔=金字塔、避难所=矩形、导流板=斜线） |
| 蓝图大小范围 | 轮次1: 3-4块 / 轮次2: 5-6块 / 轮次3: 7-8块 / 最终关: 9-10块 |
| 蓝图位置约束 | 必须在15×8格建筑区域内；根据灾难入侵方向布置防御建筑（如火山灾难从左侧来→防火墙布置在左侧） |
| 蓝图组合规则 | 单关蓝图可包含多种建筑类型；推荐材料的建筑类型与当前庇护环境匹配 |
| 蓝图显示 | 灾害预告阶段(③)显示完整蓝图位置和材料需求 |

## 七、灾害系统

### 7.1 灾害来临机制

**核心设计：灾害渐进式入侵，不是突然出现。**

灾害冲击阶段（20秒）内，灾难强度逐步提升：0-5秒30%→5-10秒60%→10-15秒100%→15-20秒80%。

### 7.2 灾难概念库

详见 `GameDesign/DesignDocuments/灾难系统设计.md`

包含6大类**35种**灾难概念：
- 元素类（8种）：熔岩潮、冰封领域、元素风暴、蒸汽领域等
- 环境类（6种）：酸雨腐蚀、沙尘暴、植物疯长等
- 时空类（5种）：时间裂隙、空间折叠、重力反转等
- 感知类（5种）：幻象迷雾、声波干扰、意识混乱等
- 物理类（5种）：磁力吸引、冲击波、漩涡吸引等
- 机制类（6种）：元素枯竭、共振过载、能量反噬等

### 7.3 灾难→庇护环境映射

35种灾难均匀分配到5种庇护环境（每种7种）：

| 庇护环境 | 灾难数量 | 受影响角色 |
|----------|----------|------------|
| 火山 | 7 | 水人 |
| 洪水 | 7 | 火人 |
| 暴风雪 | 7 | 水人 |
| 地震 | 7 | 双方 |
| 陨石 | 7 | 双方 |

### 7.4 灾难→建筑接口

每种灾难对应1种合成表和推荐建筑类型，详见灾难系统设计v2.0 §五。

### 7.5 轮次灾难规则

| 规则 | 说明 |
|------|------|
| 每轮灾难数 | 1种 |
| 难度递进 | 轮次1（×1.0）→轮次2（×1.3）→轮次3（×1.6） |

## 八、技能系统

### 8.1 卡牌选择机制

每局游戏开始时：
- 系统随机发放 **3张E技能卡** + **3张Q技能卡**
- 玩家从E卡中 **选1张**，从Q卡中 **选1张**
- 被动技能固定

### 8.2 水人技能卡池

**E技能卡（8张）：** 冰霜冲击、水流冲击、冰墙、净化、寒霜护盾、冰霜新星、绝对零度、极寒领域

**Q技能卡（6张）：** 暴风雪、海啸、冰封领域、寒冰爆发、绝对冰封、冰河时代

### 8.3 火人技能卡池

**E技能卡（8张）：** 火焰冲击、火焰箭、热浪、点燃、火焰护盾、火焰新星、焚天灭地、烈焰领域

**Q技能卡（6张）：** 烈焰风暴、熔岩喷发、火焰领域、火焰爆发、焚天灭世、烈焰地狱

### 8.4 被动技能（固定）

**水人：寒霜体质**
- 接住碎片时30%概率冻结
- 跳跃接住概率提升至50%
- 与火人同时接住100%概率冻结

**火人：烈焰体质**
- 接住碎片时30%概率点燃
- 跳跃接住概率提升至50%
- 与水人同时接住100%概率点燃

### 8.5 组合技：温砖

**触发条件：** 火人点燃碎片 + 水人冻结同一块碎片 = 温砖

**完整操作链：**
1. 碎片处于"掉落中"状态（未被捡起）
2. 火人走到落点/跳跃接住，触发被动"烈焰体质"点燃碎片
3. 水人**同时**走到落点/跳跃接住，触发被动"寒霜体质"冻结同一碎片
4. 两者作用于同一碎片 → 碎片转化为温砖
5. 温砖不再可拆分，可作为任意蓝图的增强材料使用

**关键规则：**
- 碎片必须处于"掉落中"状态（空中或刚落地）
- 两人必须**同时接住**同一碎片（触发被动技能）
- 点燃/冻结不改变碎片类型属性
- 温砖**不可**用于普通合成，仅用于建造
- 温砖计入蓝图建造材料

**温砖属性：**
- HP：20
- 抗性：全抗性+20%
- 特殊：放置后产生温差场，3×3区域内所有灾害效果减弱

## 九、地图设计

### 9.1 地图布局

横板2D视角，地图是地面上方的矩形区域。

```
┌─────────────────────────────────────────┐
│              天空（碎片掉落）             │
│                                         │
│          ◇ 碎片掉落区域 ◇               │
│         （建筑区域外，危险区）            │
│                                         │
│     ┌──────────────────────────┐        │
│     │                          │        │
│     │      建筑区域            │        │
│     │    （安全区，不能捡碎片）  │        │
│     │                          │        │
│     │         ◇合成台          │        │
│     │                          │        │
│     └──────────────────────────┘        │
│━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━│ ← 地面
└─────────────────────────────────────────┘
```

### 9.2 核心规则

**建筑区域 = 安全区（v4.2更新）：**
- 灾难开始前，建筑区域是**完全安全区**
- 建筑区域内不能接取天上掉落的碎片
- **只有两人同时在建筑区域内才能建造**
- 建筑区域外需要双生庇护

**灾害冲击阶段建筑区域安全性（v4.2决策）：**
- 建筑区域内提供**50%伤害减免**（庇护环境伤害不生效，灾难物理伤害减半）
- 建造的建筑（防火墙/避难所等）提供**100%完全保护**
- 建筑区域外**无保护**（0%减免）

> **设计理由**: 建筑区域在灾害冲击阶段不再是"绝对安全"，但提供基础保护（50%减免）。建造的建筑提供完全保护，奖励玩家完成蓝图。这创造了决策深度：是完成蓝图获得完全保护，还是躲避在建筑区域内获得部分保护。

**核心循环：出去捡 → 回来建**

### 9.3 地图参数

| 参数 | 数值 | 说明 |
|------|------|------|
| 地图整体尺寸 | 40×20格（1280×640像素） | 宽度40格，高度20格，建筑区域居中 |
| 建筑区域大小 | 15×8格（480×256像素） | 两人在区域内任何位置都能保持3格以内 |
| 合成台位置 | 区域内中心 | 两人自然靠近 |
| 碎片掉落区 | 区域外（两侧+上方） | 需要庇护才能捡 |
| 碎片掉落密度 | 每轮28-40个 | 预告5秒3-5个 + 碎片收集20秒25-35个 |
| 区域边界视觉 | 区域内地面偏亮绿，区域外偏暗灰，边界半透明绿色光柱 | 视觉区分安全区与危险区 |

## 十、游戏流程

### 10.1 单轮流程

```
预告 → 碎片收集 → 灾害预告 → 建造 → 灾害冲击 → 修整 → 升级
```

### 10.2 各阶段

| 阶段 | 时长 | 说明 |
|------|------|------|
| 预告 | 5秒 | 显示灾难类型、庇护环境、建筑蓝图 |
| 碎片收集 | 15秒 | 碎片在建筑区域外掉落，玩家出去捡（需庇护） |
| 灾害预告 | 5秒 | 灾害方向指示，玩家应返回建筑区域 |
| 建造 | 20秒 | 在建筑区域内合成+按蓝图建造（两人须同时在区域内） |
| 灾害冲击 | 20秒 | 灾害渐进入侵，建筑承受压力，角色可能受伤 |
| 修整 | 10秒 | 评估损伤、快速修补、恢复状态 |
| 升级 | 15秒 | 天赋选择（3选1），准备下一轮 |
| **合计** | **90秒** | |

> **v6.2变更**: 建造阶段从15秒延长至20秒，碎片收集阶段从20秒缩短至15秒。数学验证证明轮次3的7-8块蓝图在15秒内无法完成，延长建造阶段确保核心玩法可执行。

### 10.3 章节结构

| 层级 | 数量 | 说明 |
|------|------|------|
| 章 | 3 | 第一章「迷雾觉醒」/第二章「裂隙深渊」/第三章「双生迷城」 |
| 节 | 每章4节，共12节 | 每节主题递进 |
| 轮 | 每节3轮，共36轮 | 每轮=1关，对应1种灾难 |
| 天赋选择 | 每轮1次，共36次 | 每轮升级阶段3选1 |

详细结构见 `章节策划文档_v2.0.md`
