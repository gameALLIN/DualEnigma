# 成就系统设计

> **文档版本**: v1.0  
> **最后更新**: 2026-07-10  
> **文档状态**: 设计初稿  
> **对应GDD版本**: v6.1  
> **注意**: 本文档中的数值为初稿值，待原型测试后微调。  
> **v1.0核心内容**: 定义单局成就（5种）与跨局成就（5种）；定义成就奖励为角色皮肤颜色变体；定义成就触发与展示规则。

---

## 一、设计概述

### 1.1 设计目标

1. **正向激励**：为玩家提供额外的挑战目标和成就感
2. **行为引导**：单局成就引导新手学习核心操作（捡碎片/建造/合作）
3. **长期目标**：跨局成就提供通关和收集的长线追求
4. **无游戏性影响**：所有奖励为纯视觉，不影响数值平衡

### 1.2 设计原则

- 成就仅追踪**正向行为**，不设惩罚性成就
- 单局成就可在每局重复获得（提供持续的小目标）
- 跨局成就永久追踪，不可重置
- 成就通知不遮挡游戏画面，不打断操作
- 所有奖励为**角色皮肤颜色变体**，纯视觉装饰

### 1.3 成就分类

| 类别 | 数量 | 追踪方式 | 可重复 | 说明 |
|------|------|----------|--------|------|
| 单局成就 | 5种 | 每局独立追踪 | 是 | 每局可重新获得 |
| 跨局成就 | 5种 | 永久累计追踪 | 否 | 一次性解锁 |
| **合计** | **10种** | | | |

## 二、单局成就

### 2.1 单局成就列表

单局成就在每局游戏中可重复获得，主要用于引导新手学习核心操作和鼓励高效合作。

| 编号 | 成就名称 | 解锁条件 | 说明 | 类型 |
|------|----------|----------|------|------|
| A1 | 首次温砖 | 获得第一块温砖 | 教学引导：引导玩家了解温砖（冰+火合成）的获取方式 | 教学引导 |
| A2 | 完美建造 | 单关蓝图100%完成 | 操作奖励：无遗漏放置所有蓝图格子的正确材料 | 操作奖励 |
| A3 | 零伤害通关 | 单关无HP损失 | 操作奖励：整关（7阶段）未受到任何HP伤害 | 操作奖励 |
| A4 | 极速收集 | 碎片收集阶段接住15+碎片 | 操作奖励：在②碎片收集阶段（15秒）内接住15个或以上碎片 | 操作奖励 |
| A5 | 双人默契 | 单关3次同时接住碎片 | 合作奖励：两人同一时间（0.5秒内）接住碎片，单关达成3次 | 合作奖励 |

### 2.2 单局成就详细说明

#### A1 首次温砖

| 属性 | 说明 |
|------|------|
| 触发条件 | 玩家首次在本局获得温砖（冰碎片+火碎片合成） |
| 触发时机 | 任意阶段（通常为②碎片收集或④建造阶段） |
| 引导目的 | 让玩家了解温砖的存在和合成方式 |
| 可重复 | 每局首次获得温砖时触发 |
| 设计意图 | 温砖是高级材料（+1HP/秒恢复），引导玩家学习合成系统 |

#### A2 完美建造

| 属性 | 说明 |
|------|------|
| 触发条件 | 单关蓝图100%完成（所有格子放置正确材料） |
| 触发时机 | ④建造阶段结束或⑤灾害冲击阶段开始时判定 |
| 判定规则 | 蓝图所有格子均已放置正确类型和数量的材料 |
| 不满足条件 | 蓝图有未完成格子、放置了错误材料、或格子为空 |
| 设计意图 | 鼓励玩家仔细查看蓝图、正确合成材料、高效完成建造 |

#### A3 零伤害通关

| 属性 | 说明 |
|------|------|
| 触发条件 | 单关7阶段全程HP无损失 |
| 触发时机 | ⑥修整阶段结束时判定 |
| 判定规则 | 从①预告到⑥修整结束，HP数值从未下降 |
| 不满足条件 | 能量耗尽扣血、灾害直接伤害、任何HP损失均视为失败 |
| 设计意图 | 奖励高水平操作和默契配合，是操作向成就 |
| 特殊说明 | 温砖恢复HP不阻碍成就（HP不下降即可，恢复是HP上升） |

> **设计说明**：A3零伤害通关的判定为"HP从未下降"，而非"HP净变化为0"。因此即使有温砖恢复HP，只要HP未曾下降就满足条件。这确保恢复类天赋不阻碍成就获取。

#### A4 极速收集

| 属性 | 说明 |
|------|------|
| 触发条件 | ②碎片收集阶段（15秒）内接住15个或以上碎片 |
| 触发时机 | ②碎片收集阶段结束时判定 |
| 判定规则 | 统计该阶段内该玩家接住的碎片总数（含冰/火/温砖） |
| 参考密度 | 每轮碎片掉落28-40个，预告5秒3-5个 + 碎片收集20秒25-35个 |
| 设计意图 | 鼓励高效的碎片收集操作，15个约为标准掉落数量的一半 |

> ⚠️ 待原型测试：碎片收集阶段时长为15秒（GDD v6.1），15个碎片是否为合理阈值。若标准玩家平均接住10-12个，则15个为挑战值；若平均接住15+，则需提升阈值至20。

#### A5 双人默契

| 属性 | 说明 |
|------|------|
| 触发条件 | 单关内两人同时接住碎片3次 |
| 触发时机 | ②碎片收集阶段内实时判定 |
| 判定规则 | 两人同一时间（0.5秒内）各自接住碎片，计为1次"同时接住" |
| 计数方式 | 累计计数，单关达到3次即解锁 |
| 设计意图 | 鼓励两人协同行动，同时收集碎片而非各自分散 |

### 2.3 单局成就通知

| 属性 | 规格 | 说明 |
|------|------|------|
| 通知位置 | 屏幕右侧中部 | 不遮挡游戏画面 |
| 通知样式 | 圆角矩形 + 成就图标 + 成就名称 | 紧凑显示 |
| 通知尺寸 | 240×50px | 固定 |
| 出现动画 | 从右侧滑入（0.3秒） | 不突兀 |
| 持续时间 | 3秒 | 到期自动消失 |
| 消失动画 | 向右滑出+渐隐（0.3秒） | 不打断操作 |
| 多成就叠加 | 同时最多显示2个通知 | 超过时排队等待 |
| 通知颜色 | 金色边框 + 深色背景 | 区别于普通UI |

## 三、跨局成就

### 3.1 跨局成就列表

跨局成就永久追踪，一次性解锁，提供长线游戏目标。

| 编号 | 成就名称 | 解锁条件 | 说明 | 类型 |
|------|----------|----------|------|------|
| B1 | 初次通关 | 通关第一章（1-1-1至1-4-3共12关） | 里程碑：首次完成第一章 | 里程碑 |
| B2 | 深渊探索者 | 通关第二章（2-1-1至2-4-3共12关） | 里程碑：完成第二章 | 里程碑 |
| B3 | 双生迷城征服者 | 通关全游戏（3章×4节×3轮=36关） | 终极成就：完成全部36关 | 终极成就 |
| B4 | 全灾难图鉴 | 遭遇全部35种灾难 | 收集：在任意关卡中遭遇过所有35种灾难类型 | 收集 |
| B5 | 天赋大师 | 累计选择50个天赋 | 成长：全游戏36次选择+多局累计达到50次 | 成长 |

### 3.2 跨局成就详细说明

#### B1 初次通关

| 属性 | 说明 |
|------|------|
| 触发条件 | 通关第一章全部12关（1-1-1至1-4-3） |
| 触发时机 | 第一章最后一关（1-4-3）修整阶段结束时判定 |
| 判定规则 | 第一章12关全部完成且未失败（任意角色HP未归零） |
| 设计意图 | 第一个里程碑成就，给予玩家成就感 |

#### B2 深渊探索者

| 属性 | 说明 |
|------|------|
| 触发条件 | 通关第二章全部12关（2-1-1至2-4-3） |
| 触发时机 | 第二章最后一关（2-4-3）修整阶段结束时判定 |
| 判定规则 | 第二章12关全部完成且未失败 |
| 设计意图 | 中期里程碑，第二章难度显著提升（灾难更复杂） |

#### B3 双生迷城征服者

| 属性 | 说明 |
|------|------|
| 触发条件 | 通关全游戏（3章×4节×3轮=36关） |
| 触发时机 | 第三章最后一关（3-4-3）修整阶段结束时判定 |
| 判定规则 | 全部36关完成且未失败 |
| 设计意图 | 终极成就，代表玩家完全掌握了游戏的所有机制 |

#### B4 全灾难图鉴

| 属性 | 说明 |
|------|------|
| 触发条件 | 在所有游玩的局中累计遭遇过全部35种灾难类型 |
| 触发时机 | 每关灾害预告阶段（③）结束时记录遭遇的灾难类型 |
| 判定规则 | 35种灾难全部被遭遇过至少1次 |
| 追踪方式 | 本地/云端永久存档灾难图鉴 |
| 设计意图 | 鼓励玩家多次游玩，体验所有灾难类型 |
| 进度显示 | 成就界面显示"灾难图鉴: X/35" |

> **设计说明**：全游戏36关每轮1种灾难，一局游戏最多遭遇36种灾难中的36种（可能有重复）。35种灾难在一局内理论可全部遭遇（36关≥35种），但实际因随机性可能需要多局。此成就鼓励重玩。

#### B5 天赋大师

| 属性 | 说明 |
|------|------|
| 触发条件 | 累计选择50个天赋 |
| 触发时机 | 每次天赋选择（升级阶段⑦）时累计计数 |
| 判定规则 | 所有局的天赋选择次数累计达到50次 |
| 追踪方式 | 本地/云端永久存档累计天赋选择次数 |
| 设计意图 | 鼓励多次游玩，体现长期成长 |
| 进度显示 | 成就界面显示"天赋选择: X/50" |
| 计算说明 | 单局最多36次选择，50次需至少2局（36+14） |

## 四、成就奖励

### 4.1 奖励原则

- 所有成就奖励为**角色皮肤颜色变体**
- 皮肤变体为**纯视觉**，不改变任何游戏数值
- 皮肤变体在游戏开始前（角色选择界面）可切换
- 每个成就解锁1种皮肤变体（水人1种+火人1种=2种/成就）

### 4.2 奖励列表

| 成就 | 解锁奖励 | 说明 |
|------|----------|------|
| A1 首次温砖 | 水人/火人基础色变体×1 | 浅色系变体（水人浅蓝/火人浅橙） |
| A2 完美建造 | 水人/火人绿色变体×1 | 建造主题（水人翠绿/火人橄榄绿） |
| A3 零伤害通关 | 水人/火人白色变体×1 | 纯净主题（水人银白/火人象牙白） |
| A4 极速收集 | 水人/火人金色变体×1 | 速度主题（水人金青/火人金橙） |
| A5 双人默契 | 水人/火人紫色变体×1 | 默契主题（水人紫蓝/火人紫红） |
| B1 初次通关 | 水人/火人第一章主题色变体×1 | 章节纪念（水人深蓝/火人深红） |
| B2 深渊探索者 | 水人/火人第二章主题色变体×1 | 章节纪念（水人暗青/火人暗紫） |
| B3 双生迷城征服者 | 水人/火人终极皮肤×1 | 终极皮肤（水人彩虹/火人彩虹） |
| B4 全灾难图鉴 | 水人/火人灾难主题色变体×1 | 收集纪念（水人灰黑/火人灰红） |
| B5 天赋大师 | 水人/火人天赋主题色变体×1 | 成长纪念（水人星蓝/火人星橙） |

### 4.3 皮肤展示

```
角色选择界面：

│  选择你的角色                            │
│                                         │
│  水人皮肤:                              │
│  [默认] [浅蓝] [翠绿] [银白] [金青] ... │
│   ✓使用   🔒      🔒      🔒      🔒   │
│                                         │
│  火人皮肤:                              │
│  [默认] [浅橙] [橄榄] [象牙] [金橙] ... │

```

| 元素 | 规格 | 说明 |
|------|------|------|
| 皮肤预览 | 48×48px色块 | 显示皮肤主色调 |
| 锁定状态 | 🔒图标 + 灰色蒙版 | 未解锁的皮肤 |

> **设计说明**：所有皮肤变体仅改变角色外观颜色（如水人从默认蓝色变为翠绿色），不改变角色形状、大小或任何游戏数值。皮肤选择在游戏开始前进行，本局不可中途更换。🔲 待讨论：是否需要更丰富的皮肤类型（如花纹/特效），还是仅做颜色变体。

## 六、技术实现要点

### 6.1 数据存储

| 数据 | 存储位置 | 说明 |
|------|----------|------|
| 单局成就 | 局内内存 | 每局开始时重置，结束时记录到历史 |
| 跨局成就 | 本地存档/云端存档 | 永久保存 |
| 灾难图鉴 | 本地存档/云端存档 | 记录遭遇过的灾难类型（位图/布尔数组） |
| 天赋选择累计 | 本地存档/云端存档 | 累计计数器 |
| 皮肤解锁状态 | 本地存档/云端存档 | 布尔值数组 |

### 6.2 成就触发流程

```
游戏内事件发生
    ↓
成就系统检查触发条件
    ├── 单局成就 → 局内计数器更新 → 满足条件 → 显示通知
    └── 跨局成就 → 累计数据更新 → 满足条件 → 显示通知 + 解锁皮肤
        ↓
    存档写入（跨局成就）
```

### 6.3 网络同步

| 成就类型 | 网络同步 | 说明 |
|----------|----------|------|
| 单局成就 | 各自本地追踪 | 不需要同步，各自独立判定 |
| 跨局成就 | 各自本地存档 | 成就为个人追踪，不需要双人同步 |
| 双人默契(A5) | 本地判定 | 各自判定"0.5秒内接住碎片"，两人各自满足时各自获得 |

> **设计说明**：成就系统为个人追踪，不要求两人同时解锁。例如A5双人默契，只要该玩家自身满足"单关3次同时接住"即解锁，不要求队友也解锁。这避免了网络同步复杂性。
