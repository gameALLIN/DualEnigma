## 一、设计概述

### 1.1 设计背景

美术需求文档已定义视觉风格（暗色系/元素对比色/2D横板），但缺少UI/UX交互设计。本文档定义游戏内所有UI元素的布局、交互逻辑和视觉规范。

### 1.2 设计原则

1. **信息分层**：HUD始终可见但不遮挡游戏画面；重要信息在边缘，游戏画面居中
2. **双人对称**：水人信息在左、火人信息在右，视觉对称降低认知负荷
3. **阶段驱动**：UI元素随7阶段动态变化，当前阶段相关信息高亮
4. **低视觉噪音**：半透明面板、柔和颜色，不与灾难特效争夺视觉注意力

### 1.3 屏幕分区总览

```
┌─────────────────────────────────────────────────────────┐
│ [水人HUD]          [关卡信息+灾难]          [火人HUD]    │
│                                                         │
│                                                         │
│                    游 戏 画 面                           │
│                                                         │
│                                                         │
│                                                         │
│ [水人技能]        [阶段进度+倒计时]         [火人技能]   │
└─────────────────────────────────────────────────────────┘
```

## 二、游戏HUD布局

### 2.1 HUD分区定义

| 区域 | 位置 | 内容 | 说明 |
|------|------|------|------|
| 左上角 | (0%, 0%) | 水人HP条 + 能量条 + 携带碎片数 | 水人玩家自身信息+火人玩家队友信息 |
| 右上角 | (100%, 0%) | 火人HP条 + 能量条 + 携带碎片数 | 火人玩家自身信息+水人玩家队友信息 |
| 顶部中央 | (50%, 0%) | 当前关卡信息 + 灾难类型图标 | 章节-节-轮 + 灾难名称与图标 |
| 底部中央 | (50%, 100%) | 阶段进度条 + 倒计时 | 当前阶段进度+剩余秒数 |
| 左下角 | (0%, 100%) | 水人技能图标(E+Q) + 冷却显示 | 技能状态 |
| 右下角 | (100%, 100%) | 火人技能图标(E+Q) + 冷却显示 | 技能状态 |

### 2.2 左上角：水人信息面板

```
┌──────────────────────────┐
│  💧 水人                  │
│  HP ████████████████ 100  │
│  EN ████████████████ 100  │
│  📦 携带: 2/3  🔵🔵⚪     │
└──────────────────────────┘
```

| 元素 | 规格 | 说明 |
|------|------|------|
| 角色头像 | 32×32px | 水人图标（蓝色水滴） |
| HP条 | 宽180px × 高12px | 红色填充，带数字显示 |
| 能量条(EN) | 宽180px × 高8px | 蓝色填充，带数字显示 |
| 携带碎片数 | 宽180px × 高16px | 显示"携带: X/3" + 碎片图标（蓝色圆点=冰/橙色圆点=火/金色圆点=温砖） |
| 面板背景 | rgba(20,20,30,0.7) | 半透明深色底 |
| 面板尺寸 | 200×80px | 固定尺寸 |

**HP条特殊状态**：

| 状态 | 视觉表现 | 触发条件 |
|------|----------|----------|
| 正常 | 红色填充 | HP > 30% |
| 低血量警告 | 红色填充 + 脉冲闪烁 | HP ≤ 30% |
| 濒死保护 | 红色填充 + 蓝色边框 | HP ≤ 30% 且保底机制触发（见天赋系统设计 §2.7） |

**能量条特殊状态**：

| 状态 | 视觉表现 | 触发条件 |
|------|----------|----------|
| 正常（恢复中） | 蓝色填充 | 队友在3格内，+20/秒 |
| 消耗中 | 蓝色填充 + 橙色边框闪烁 | 队友超过3格，-33/秒 |
| 耗尽 | 灰色空条 + 红色边框 | 能量=0，开始扣血 |

### 2.3 右上角：火人信息面板

与水人面板镜像对称，颜色对应火人主题色（橙色）：

```
┌──────────────────────────┐
│  火人 🔥                  │
│  HP ████████████████ 100  │
│  EN ████████████████ 100  │
│  📦 携带: 1/3  🔴⚪⚪     │
└──────────────────────────┘
```

| 元素 | 规格 | 说明 |
|------|------|------|
| 角色头像 | 32×32px | 火人图标（橙色火焰） |
| HP条 | 宽180px × 高12px | 红色填充，同水人 |
| 能量条(EN) | 宽180px × 高8px | 橙色填充 |
| 携带碎片数 | 同水人 | 图标颜色同水人规则 |
| 面板背景 | rgba(20,20,30,0.7) | 半透明深色底 |

> **设计说明**：两位玩家的HUD均始终可见（自身信息+队友信息）。自身面板高亮（边框更亮），队友面板略暗（透明度更高），帮助玩家快速定位自身状态。

**阶段动态变化**：

| 阶段 | 顶部中央显示内容 | 说明 |

### 3.3 天赋卡片规格

| 元素 | 规格 | 说明 |
|------|------|------|
| 卡片尺寸 | 180×260px | 固定尺寸 |
| 卡片间距 | 40px | 三卡水平居中排列 |
| 稀有度边框 | 普通=白 / 稀有=蓝 / 史诗=紫 | 边框颜色对应稀有度 |
| 稀有度星级 | 12px | 卡片顶部居中显示★/★★/★★★ |
| 天赋图标 | 64×64px | 卡片上半部分居中 |
| 天赋名称 | 16px白色加粗 | 图标下方 |
| 效果描述 | 12px灰色 | 名称下方，可换行 |
| 选择按键 | 数字键1/2/3 | 卡片底部显示"[按X]" |
| 背景 | rgba(10,10,20,0.9) | 高不透明度遮罩，聚焦选择 |

### 3.4 倒计时压力设计

| 时间段 | 视觉表现 | 说明 |
|--------|----------|------|
| 15-10秒 | 正常显示倒计时 | 充足思考时间 |
| 10-5秒 | 倒计时变橙色 | 提醒时间流逝 |
| 5-0秒 | 倒计时变红色 + 脉冲闪烁 | 紧迫感 |
| 0秒（未选择） | 自动选择最左侧天赋 | 强制选择，避免卡关 |

### 3.5 选中确认

| 操作 | 反馈 | 说明 |
|------|------|------|
| 按数字键1/2/3 | 卡片放大1.1倍 + 边框发光 + 确认音效 | 即时反馈 |
| 确认后 | 未选中卡片渐隐消失，选中卡片居中放大2秒 | 过渡动画 |
| 过渡完成 | 界面消失，进入下一轮预告阶段 | 0.5秒淡出 |

> **设计说明**：天赋选择为3选1不可撤销（见天赋系统设计 §2.5）。15秒倒计时创造紧迫感但不过分压迫。超时自动选择最左侧防止卡关。⚠️ 待原型测试：15秒是否足够阅读3张天赋卡片的效果描述。

## 六、碎片掉落预览

### 6.1 触发时机

碎片掉落前1秒显示落点指示线。

### 6.2 视觉表现

```
                    ↓ ↓ ↓        ← 虚线轨迹（碎片颜色对应）
                   ↓ ↓ ↓
                  ↓ ↓ ↓
                 ↓ ↓ ↓
    ════════════════════════════ ← 地面
         ↑        ↑     ↑
       落点1    落点2  落点3
```

| 元素 | 规格 | 说明 |
|------|------|------|
| 落点指示线 | 虚线，宽2px | 从掉落起始点到落点的垂直虚线 |
| 虚线颜色 | 碎片对应颜色 | 冰=蓝色/火=橙色/温砖=金色 |
| 落点标记 | 半透明圆圈，半径8px | 落点位置标记 |
| 预览持续时间 | 1秒 | 碎片掉落前1秒出现，掉落时消失 |
| 虚线透明度 | rgba(R,G,B,0.4) | 半透明，不遮挡画面 |

### 6.3 碎片掉落预览与灾难联动

| 灾难 | 预览是否受影响 | 说明 |
|------|---------------|------|
| V2 沙尘暴 | 预览被遮挡 | 沙尘遮挡虚线轨迹，无法预览落点（灾难特性） |
| V5 雾海入侵 | 预览部分可见 | 雾气浓度高时预览虚线模糊，但仍可辨认 |
| 其他灾难 | 正常显示 | 预览不受影响 |

> **设计说明**：碎片掉落预览是标准游戏体验的一部分，仅在特定灾难（V2沙尘暴/V5雾海入侵）下被干扰。这种干扰是灾难的设计特性，增加挑战性。玩家可通过沟通系统的碎片Ping（见沟通系统设计 §2.1.2）来弥补预览缺失。

### 7.2 快捷消息气泡

快捷消息显示在角色头顶气泡中：

```
              ┌─────────────────┐
              │   快捡碎片！     │  ← 气泡：18px白色，黑色描边
```

|------|------|------|

> **详细规范参见**: 沟通系统设计 v1.0 §五（视觉表现规范）。

## 八、UI动效规范

### 8.1 通用动效原则

| 动效类型 | 时长 | 缓动函数 | 说明 |
|----------|------|----------|------|
| 出现 | 0.3秒 | EaseOut | 从透明/偏移渐入 |
| 消失 | 0.3秒 | EaseIn | 渐出/偏移渐出 |
| 状态切换 | 0.2秒 | EaseInOut | 颜色/尺寸过渡 |
| 警告脉冲 | 0.5秒/次 | 无限循环 | 低血量/倒计时紧迫 |

### 8.2 阶段切换动效

| 阶段切换 | 动效 | 说明 |
|----------|------|------|
| ①→② | 顶部灾害预告面板滑出，碎片掉落预览出现 | 平滑过渡 |
| ②→③ | 灾害预告面板从上方滑入，蓝图高亮出现 | 警示性强调 |
| ③→④ | 灾害预告面板滑出，蓝图信息面板出现 | 进入建造 |
| ④→⑤ | 蓝图面板淡出，强度条出现 | 进入灾害冲击 |
| ⑤→⑥ | 强度条淡出，"修整中"文字出现 | 放松 |
| ⑥→⑦ | HUD淡出，天赋选择界面覆盖 | 聚焦选择 |
| ⑦→①(下一轮) | 天赋界面消失，HUD淡入 | 新轮开始 |
