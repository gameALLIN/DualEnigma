# 音频需求文档

> **文档版本**: v2.0  
> **最后更新**: 2026-07-08  
> **文档状态**: 设计定稿  
> **对应GDD版本**: v6.1  
> **音频风格**: 程序化音效 + 氛围BGM（零外部音频依赖）

---

## 一、音频设计总则

### 1.1 核心原则

**所有音效100%程序化生成或使用Unity内置音频合成，零外部音频文件依赖。**

- BGM：Unity AudioSource + 程序化音乐序列
- SFX：Unity AudioSource + 程序化音效合成
- 环境音：循环AudioClip + 程序化参数调节

### 1.2 音频分类

| 类型 | 数量 | 说明 |
|------|------|------|
| BGM（背景音乐） | 4首 | 标题/第一章/第二章/第三章 |
| 环境音 | 5种 | 5种庇护环境循环音 |
| SFX（音效） | 40+ | 角色/碎片/建筑/灾害/UI音效 |

## 二、BGM设计

### 2.1 章节BGM

| BGM | 章节 | 风格 | 节奏 | 情绪 | 音色 |
|-----|------|------|------|------|------|
| 标题BGM | 标题画面 | 空灵/神秘 | 60BPM | 期待/好奇 | 钢琴+弦乐pad |
| 第一章BGM | 迷雾觉醒 | 轻柔/探索 | 80BPM | 谨慎/学习 | 钢琴+轻打击 |
| 第二章BGM | 裂隙深渊 | 紧张/压迫 | 100BPM | 危机/挑战 | 弦乐+合成器 |
| 第三章BGM | 双生迷城 | 史诗/决绝 | 120BPM | 绝境/希望 | 全交响乐+电子 |

### 2.2 BGM动态切换规则

| 触发 | 行为 | 过渡时间 |
|------|------|----------|
| 章节切换 | 旧BGM淡出→新BGM淡入 | 3秒交叉淡入 |
| 灾害冲击阶段 | BGM音量降低20% | 1秒淡出 |
| 灾害冲击结束 | BGM音量恢复 | 1秒淡入 |
| 天赋选择阶段 | BGM音量降低30% | 0.5秒淡出 |
| 游戏结束(失败) | BGM停止→失败音效 | 即时 |
| 通关 | BGM停止→通关音乐 | 2秒淡入 |

### 2.3 BGM技术参数

| 参数 | 数值 |
|------|------|
| 格式 | WAV (44100Hz, 16bit) |
| 声道 | 立体声 |
| 循环 | 是（标题BGM和章节BGM均循环播放） |
| 音量基准 | 0.6 (归一化) |
| 优先级 | 0 (最高) |

## 三、环境音设计

### 3.1 五种庇护环境音

| 环境 | 音效描述 | 循环 | 音量 |
|------|----------|------|------|
| 火山 | 低频隆隆声+噼啪爆裂声 | 是 | 0.4 |
| 洪水 | 水流涌动声+水滴声 | 是 | 0.4 |
| 暴风雪 | 呼啸风声+冰裂声 | 是 | 0.4 |
| 地震 | 地面震动低频+碎石声 | 是 | 0.4 |
| 陨石 | 大气层呼啸+远处撞击声 | 是 | 0.4 |

### 3.2 环境音动态参数

| 参数 | 规则 |
|------|------|
| 音量随灾害强度变化 | 30%强度→0.2音量, 100%强度→0.4音量 |
| 频率随灾难渐进变化 | 强度越高，低频成分越重 |
| 空间音效 | 根据灾难方向调整左右声道平衡 |

## 五、特殊灾难音频规则

### 5.1 S2 声波干扰

| 规则 | 说明 |
|------|------|
| 效果 | **所有音效静音**，仅保留BGM(音量降低至0.1) |
| 持续 | 整个灾害冲击阶段(20秒) |
| 视觉替代 | 屏幕显示"无声波"图标，玩家只能靠视觉沟通 |
| 设计意图 | 剥夺听觉信息，考验纯视觉合作 |

### 5.2 M3 能量反噬

| 规则 | 说明 |
|------|------|
| 效果 | 技能音效替换为HP消耗音效(心跳声) |
| 持续 | 整个灾害冲击阶段 |
| 设计意图 | 听觉反馈提醒玩家技能正在消耗HP |

## 六、音频技术参数

### 6.1 AudioSource配置

| 参数 | 数值 |
|------|------|
| 最大同时播放AudioSource | 32 |
| BGM AudioMixer Group | Music |
| SFX AudioMixer Group | SFX |
| 环境音 AudioMixer Group | Ambient |
| 主音量 | 1.0 (可调节) |
| BGM音量 | 0.6 (可调节) |
| SFX音量 | 0.8 (可调节) |
| 环境音音量 | 0.4 (可调节) |

### 6.2 3D音效规则

| 类型 | 空间混合 | 说明 |
|------|----------|------|
| BGM | 2D | 全屏均匀 |
| 环境音 | 2D | 全屏均匀 |
| 角色SFX | 2D(局部) | 不分左右声道 |
| 灾害SFX | 2D+方向偏移 | 根据灾害方向调整左右声道 |
| 碎片SFX | 2D+方向偏移 | 根据碎片位置调整左右声道 |

### 6.3 音频优先级

| 优先级 | 类型 | 说明 |
|--------|------|------|
| 0 | BGM | 最高，永不中断 |
| 1 | 死亡音效/通关音效 | 关键事件 |
| 2 | 灾害冲击/警报 | 重要事件 |
| 3 | 技能释放/建筑完成 | 游戏事件 |
| 4 | 拾取/建造/受伤 | 常规事件 |
| 5 | 脚步/UI悬停 | 低优先级 |
