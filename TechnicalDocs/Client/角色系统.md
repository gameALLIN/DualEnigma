## 一、系统概述

### 1.1 系统职责

角色系统负责：
- 水人（Aqua）与火人（Ignis）的移动控制
- 角色属性管理（HP、庇护能量、携带碎片）
- 碎片交互（接住、被动技能触发）
- 角色精灵的程序化生成

### 1.2 在整体架构中的位置

```
Core（Singleton / EventBus / ServiceLocator）
         │
    CharacterSystem
    │         │
    ├── 移动控制（Rigidbody2D + Input System）
    ├── 属性管理（HP / Energy / 携带碎片）
    ├── 碎片交互（碰撞检测 → 接住判定 → 被动触发）
    └── 程序化生成（Sprite 生成）
              │
     依赖：FragmentSystem / ShelterSystem / SkillSystem
```

### 1.3 依赖关系

| 依赖方向 | 说明 |
|----------|------|
| Character → Core | 继承 `Singleton<T>`，使用 `EventBus` / `ServiceLocator` |
| Character → Fragment | 接住碎片时调用 FragmentSystem |
| Character → Shelter | 庇护能量值由 ShelterSystem 管理 |
| Character → Skill | 被动技能（寒霜体质/烈焰体质）触发 |
| Network → Character | 高频状态同步（位置/速度/动画） |

## 二、数据结构

### 2.1 角色类型枚举

```csharp
namespace DualEnigma.Character
{
    /// <summary>
    /// 角色类型。强制一水一火，不允许选相同角色。
    /// 引用：GDD v6.1 §2.1
    /// </summary>
    public enum CharacterType
    {
        /// <summary>水人 Aqua</summary>
        Aqua,
        /// <summary>火人 Ignis</summary>
        Ignis,
    }

    /// <summary>
    /// 动画状态枚举，用于网络同步。
    /// 引用：网络通信.md §3.2 高频状态同步
    /// </summary>
    public enum AnimState : byte
    {
        Idle,
        Run,
        Jump,
        Fall,
        Hurt,
    }
}
```

### 2.2 角色基础属性

```csharp
namespace DualEnigma.Character
{
    /// <summary>
    /// 角色基础属性配置。
    /// 引用：GDD v6.1 §2.2 水人 / §2.3 火人
    /// </summary>
    [System.Serializable]
    public class CharacterStats
    {
        /// <summary>角色类型</summary>
        public CharacterType Type;
        /// <summary>最大生命值</summary>
        public int MaxHP = 100;
        /// <summary>当前生命值</summary>
        public int CurrentHP = 100;
        /// <summary>移动速度（格/秒，1格=1单位，PPU=32）</summary>
        public float MoveSpeed = 4f;
        /// <summary>跳跃高度（格），水人=2，火人=2（二段跳至3）</summary>
        public float JumpHeight = 2f;
        /// <summary>是否可二段跳（火人=true）</summary>
        public bool CanDoubleJump;
        /// <summary>搬运上限</summary>
        public int CarryLimit = 3;
        /// <summary>当前携带的碎片列表</summary>
        public List<int> CarriedFragmentIds = new List<int>();

        /// <summary>携带的材料及数量（合成产出后携带，建造/修补时消耗）</summary>
        public Dictionary<MaterialType, int> CarriedMaterials = new Dictionary<MaterialType, int>();
    }
}
```

## 三、核心接口与类设计

### 3.1 CharacterSystem

```csharp
namespace DualEnigma.Character
{
    /// <summary>
    /// 角色系统管理器。继承 Singleton<T>，注册 ICharacterSystem 到 ServiceLocator。
    /// </summary>
    public class CharacterSystem : Singleton<CharacterSystem>, ICharacterSystem
    {
        /// <summary>水人角色实例</summary>
        public CharacterController Aqua { get; }
        /// <summary>火人角色实例</summary>
        public CharacterController Ignis { get; }

        /// <summary>初始化角色系统</summary>
        public void Initialize();

        /// <summary>获取指定类型的角色</summary>
        public CharacterController GetCharacter(CharacterType type);
    }

    public interface ICharacterSystem
    {
        CharacterController GetCharacter(CharacterType type);
    }
}
```

### 3.2 CharacterController

```csharp
namespace DualEnigma.Character
{
    /// <summary>
    /// 角色控制器，挂载在角色 GameObject 上。
    /// 负责移动、跳跃、碎片交互、朝向管理。
    /// </summary>
    [RequireComponent(typeof(Rigidbody2D))]
    public class CharacterController : MonoBehaviour
    {
        /// <summary>角色属性</summary>
        public CharacterStats Stats { get; }

        /// <summary>朝向（左/右）</summary>
        public bool FacingRight { get; private set; }

        /// <summary>是否在地面上</summary>
        public bool IsGrounded { get; private set; }

        /// <summary>移动</summary>
        /// <param name="direction">-1（左）到 1（右）</param>
        public void Move(float direction);

        /// <summary>跳跃</summary>
        public void Jump();

        /// <summary>添加携带碎片</summary>
        public bool AddFragment(int fragmentId);

        /// <summary>移除携带碎片</summary>
        public void RemoveFragment(int fragmentId);

        /// <summary>受伤害</summary>
        public void TakeDamage(int damage);

        /// <summary>治疗</summary>
        public void Heal(int amount);

        /// <summary>设置移动速度乘数（暴风雪等环境效果调用）</summary>
        /// <param name="multiplier">乘数（1.0=正常，0.5=50%移速）</param>
        public void SetMoveSpeedMultiplier(float multiplier);

        /// <summary>尝试消耗携带的材料</summary>
        /// <param name="type">材料类型</param>
        /// <param name="count">消耗数量</param>
        /// <returns>数量足够且扣除成功返回 true，否则 false</returns>
        public bool TryConsumeMaterial(MaterialType type, int count = 1);

        /// <summary>添加携带材料（合成产出时调用）</summary>
        /// <param name="type">材料类型</param>
        /// <param name="count">添加数量</param>
        public void AddMaterial(MaterialType type, int count = 1);
    }
}
```

## 四、详细逻辑

### 4.1 移动控制

**物理模型**：使用 `Rigidbody2D`（Dynamic Body）进行 2D 物理移动。

| 参数 | 值 | 说明 |
|------|-----|------|
| 移速 | 4格/s = 4单位/s | PPU=32，1格=1单位 |
| 跳跃力 | 按跳跃高度反算 | 水人2格，火人3格（二段跳） |
| 重力 | Unity 默认 | 可调，需确保跳跃高度符合设计 |
| 地面检测 | Ground 层（Layer 7） | Raycast 向下检测 |

**移动流程**：

```
输入（Input System）
    → CharacterController.Move(direction)
        → Rigidbody2D.velocityX = direction * MoveSpeed * PPU
        → 更新 FacingRight
        → 更新 AnimState（Idle ↔ Run）
```

**跳跃逻辑**：

```
输入（跳跃键）
    → CharacterController.Jump()
        → 检查 IsGrounded
            ├── 是 → 第一段跳，施加向上力
            │       └── 火人：记录已用一段跳
            └── 否 → 检查可二段跳
                        ├── 火人且未用二段跳 → 二段跳，施加向上力（略弱）
                        └── 其他 → 忽略
        → 更新 AnimState = Jump
```

### 4.2 属性系统

| 属性 | 范围 | 说明 |
|------|------|------|
| HP | 0-100 | 不自动恢复，归零=游戏结束 |
| 庇护能量 | 0-100 | 由 ShelterSystem 管理，引用庇护系统文档 |
| 携带碎片数 | 0-3（可升至4） | 通过天赋"搬运强化"提升上限 |
| 已选E技能 | 0-1 | 游戏开始时选定 |
| 已选Q技能 | 0-1 | 游戏开始时选定 |
| 已选天赋列表 | — | 每轮升级阶段3选1 |

### 4.3 碎片交互

**接住方式与倍率**：

| 方式 | 倍率 | 判定条件 |
|------|------|----------|
| 走到落点 | ×1 | 角色在地面，碎片进入吸附范围 |
| 跳跃中接住 | ×2 | 角色不在地面（跳跃状态） |
| 两人同时接住 | ×3 | 两人接住事件时间差 < 100ms |

**被动技能触发**：

| 角色 | 被动 | 触发概率 | 跳跃触发概率 | 同时接住概率 |
|------|------|----------|-------------|-------------|
| 水人 | 寒霜体质（冻结） | 30% | 50% | 100% |
| 火人 | 烈焰体质（点燃） | 30% | 50% | 100% |

**碎片交互流程**：

```
碎片进入角色 Trigger2D 范围
    → FragmentSystem.OnFragmentCollected(fragmentId, playerId, isJumping)
        → 判定接住方式（×1 / ×2 / ×3）
        → 判定是否同时接住（时间差 < 100ms）
        → 触发被动技能判定（寒霜体质/烈焰体质）
        → 检查温砖触发条件（火人点燃 + 水人冻结同一碎片）
        → 添加碎片到角色携带列表
        → EventBus.Publish(new FragmentCollectedEvent { ... })
```

### 4.4 角色程序化生成

**精灵生成规范**：

| 属性 | 水人 | 火人 |
|------|------|------|
| 风格 | 森林冰火人风格，Q版大头小身 | 同左 |
| 头身比 | 头占75% | 同左 |
| 描边 | 3px 粗黑描边 #050505 | 同左 |
| 渐变 | 径向渐变 | 同左 |
| 中心色 | #E1F5FE | #FFE082 |
| 中段色 | #4FC3F7 | #FF6F00 |
| 边缘色 | #0277BD | #BF360C |

**Sprite 生成约定**（引用 CODELY.md）：
- `SpriteMeshType.FullRect`
- `filterMode = FilterMode.Point`
- PPU = 32
- 零外部美术资源依赖，全部程序化生成

**Ground 层**: Layer 7 = Ground（TagManager.asset 已定义）
**Player 标签**: Tag = Player（TagManager.asset 已定义）
