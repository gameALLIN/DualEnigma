## 一、系统概述

### 1.1 系统职责

技能系统负责：
- 游戏开始时卡牌抽取（3E选1 + 3Q选1）
- 被动技能固定触发（寒霜体质/烈焰体质）
- 技能释放逻辑与冷却管理
- Q技能跨轮冷却
- 技能视觉效果本地播放 + 机制效果 Host 判定

### 1.2 在整体架构中的位置

```
Core（EventBus / ServiceLocator）
         │
    SkillSystem
    │          │
    ├── 卡牌抽取（权重 50%/35%/15%，3张不重复）
    ├── 被动技能触发（寒霜体质/烈焰体质）
    ├── 技能释放（E技能 20-45s / Q技能 60-90s）
    ├── 冷却管理（含跨轮冷却）
    └── 技能效果执行（视觉本地 / 机制Host）
              │
     依赖：CharacterSystem / FragmentSystem / ShelterSystem
```

### 1.3 依赖关系

| 依赖方向 | 说明 |
|----------|------|
| Skill → Core | EventBus / ServiceLocator |
| Skill → Character | 技能释放需要角色位置 |
| Skill → Fragment | 被动技能影响碎片 |
| Skill → Shelter | 技能影响庇护系统（护盾/净化/领域） |
| Network → Skill | 技能释放事件同步 / 机制判定结果 |

### 2.2 技能数据结构

```csharp
namespace DualEnigma.Skill
{
    /// <summary>
    /// 技能卡牌数据。
    /// </summary>
    [System.Serializable]
    public class SkillData
    {
        /// <summary>技能ID</summary>
        public int SkillId;
        /// <summary>技能名称</summary>
        public string Name;
        /// <summary>技能类型</summary>
        public SkillType Type;
        /// <summary>稀有度</summary>
        public Rarity Rarity;
        /// <summary>效果系数（×1.0/×1.5/×2.0）</summary>
        public float EffectMultiplier;
        /// <summary>冷却时间（秒）</summary>
        public float Cooldown;
        /// <summary>持续时间（秒）</summary>
        public float Duration;
        /// <summary>效果范围</summary>
        public float Range;
        /// <summary>描述</summary>
        public string Description;
        /// <summary>所属角色（Aqua/Ignis）</summary>
        public CharacterType Owner;
    }

    /// <summary>
    /// 技能运行时状态
    /// </summary>
    [System.Serializable]
    public class SkillState
    {
        /// <summary>技能数据</summary>
        public SkillData Data;
        /// <summary>当前冷却剩余时间（秒）</summary>
        public float CooldownRemaining;
        /// <summary>是否可用</summary>
        public bool IsReady => CooldownRemaining <= 0f;
    }
}
```

### 2.3 卡牌池稀有度分布

**水人 E 技能卡池（8张）**：普通3 / 稀有3 / 史诗2
**水人 Q 技能卡池（6张）**：普通1 / 稀有3 / 史诗2
**火人 E 技能卡池（8张）**：普通3 / 稀有3 / 史诗2
**火人 Q 技能卡池（6张）**：普通1 / 稀有3 / 史诗2

### 2.4 稀有度效果系数

| 稀有度 | 效果系数 | 冷却影响 | 说明 |
|--------|----------|----------|------|
| 普通 | ×1.0 | 标准 | 基础效果数值，标准冷却 |
| 稀有 | ×1.5 | ×1.2 | 效果增强50%或附加次要效果 |
| 史诗 | ×2.0 | ×1.5 | 效果翻倍或改变游戏规则 |

## 三、核心接口与类设计

### 3.1 SkillSystem

```csharp
namespace DualEnigma.Skill
{
    /// <summary>
    /// 技能系统管理器。继承 Singleton<T>，注册 ISkillSystem 到 ServiceLocator。
    /// </summary>
    public class SkillSystem : Singleton<SkillSystem>, ISkillSystem
    {
        /// <summary>水人已选E技能</summary>
        public SkillState AquaESkill { get; }
        /// <summary>水人已选Q技能</summary>
        public SkillState AquaQSkill { get; }
        /// <summary>火人已选E技能</summary>
        public SkillState IgnisESkill { get; }
        /// <summary>火人已选Q技能</summary>
        public SkillState IgnisQSkill { get; }

        /// <summary>抽取卡牌（游戏开始时调用）</summary>
        /// <param name="owner">角色类型</param>
        /// <param name="type">技能类型（E/Q）</param>
        /// <returns>3张不重复的卡牌</returns>
        public List<SkillData> DrawCards(CharacterType owner, SkillType type);

        /// <summary>选择卡牌</summary>
        public void SelectCard(CharacterType owner, SkillType type, int skillId);

        /// <summary>释放技能</summary>
        /// <param name="owner">角色类型</param>
        /// <param name="type">技能类型（E/Q）</param>
        /// <param name="targetPosition">目标位置</param>
        public void ActivateSkill(CharacterType owner, SkillType type, Vector2 targetPosition);

        /// <summary>每帧更新（冷却倒计时）</summary>
        public void OnUpdate(float deltaTime);
    }

    public interface ISkillSystem
    {
        void ActivateSkill(CharacterType owner, SkillType type, Vector2 targetPosition);
    }
}
```

## 四、详细逻辑

### 4.1 卡牌抽取

**抽取权重**：普通50% / 稀有35% / 史诗15%

**抽取流程**：

```
1. 为3张卡牌分别按权重随机确定稀有度
2. 从对应稀有度的卡池中等概率随机选取1张卡牌
3. 去重检查：若该卡牌已被抽取，则从同稀有度剩余卡牌中重新选取
4. 容错处理：若该稀有度卡牌已全部用完，则从其他稀有度的可用卡牌中选取
5. 返回3张不重复的卡牌
```

> 引用：技能系统设计.md §1.4 卡牌抽取流程伪代码

### 4.2 被动技能

| 角色 | 被动 | 基础概率 | 跳跃概率 | 同时接住概率 |
|------|------|----------|----------|-------------|
| 水人 | 寒霜体质（冻结） | 30% | 50% | 100% |
| 火人 | 烈焰体质（点燃） | 30% | 50% | 100% |

**被动技能触发时机**：碎片被接住时判定。

**E3元素风暴叠加规则**：E3碎片极化在生成时判定，被动在接住时判定，两者独立运行，效果不叠加。

### 4.3 技能释放

**释放流程**：

```
玩家按下技能释放键
    → 本地立即播放技能视觉特效（减少延迟感）
    → 发送技能释放事件（技能ID + 目标位置 + 时间戳）给对方
    → 等待 Host 的机制判定结果

对方端:
    → 接收技能释放事件
    → 本地播放技能视觉特效
    → 等待 Host 的机制判定结果

Host 端（若 Host 非操作方）:
    → 接收技能释放事件
    → 执行机制判定（伤害计算、冻结判定等）
    → 同步判定结果给双方
```

### 4.4 冷却管理

**E技能冷却**：20-45秒

| 冷却时间 | 技能 | 使用频率 |
|----------|------|----------|
| 10-12秒 | 冰霜冲击、水流冲击、火焰冲击、火焰箭 | 每轮2-3次 |
| 15-18秒 | 冰墙、净化、寒霜护盾、冰霜新星、热浪、点燃、火焰护盾、火焰新星 | 每轮1-2次 |
| 40-45秒 | 绝对零度、极寒领域、焚天灭地、烈焰领域 | 每轮1次+ |

**Q技能冷却**：60-90秒

| 冷却时间 | 技能 | 跨轮需求 |
|----------|------|----------|
| 60秒 | 暴风雪、海啸、冰封领域、寒冰爆发、烈焰风暴、熔岩喷发、火焰领域、火焰爆发 | 无需跨轮 |
| 90秒 | 绝对冰封、冰河时代、焚天灭世、烈焰地狱 | **需要跨轮** |

**Q技能跨轮冷却规则**：
- 修整阶段(10秒) + 升级阶段(15秒) = 25秒冷却时间继续计算
- 下一轮预告阶段显示剩余冷却时间
- 冷却不重置，跨轮后继续累积

### 4.5 技能与庇护系统交互

> 引用：双生庇护系统设计.md §5.1

| 技能 | 对庇护的影响 | 持续时间 |
|------|-------------|----------|
| 寒霜护盾/火焰护盾 | 不改变能量值，直接抵消环境伤害 | 10秒 |
| 净化 | 清除M5庇护削弱效果，恢复正常能量参数 | 即时 |
| 极寒领域/烈焰领域 | 区域内角色不消耗庇护能量 | 10秒 |
| 绝对零度/焚天灭地 | 无敌期间不消耗能量 | 3秒 |
| 暴风雪/烈焰风暴 | 不影响能量，仅改变区域内灾害效果 | 10秒 |

### 4.6 天赋对技能的影响

> 引用：技能系统设计.md §6.1

| 天赋 | 影响范围 | 效果 | 叠加方式 |
|------|----------|------|----------|
| 冷却缩短 | E + Q技能 | 冷却-20% | 线性叠加（封顶-80%） |
| 范围扩大 | E技能 | 范围+30% | 线性叠加 |
| 护盾强化 | 护盾类技能 | 持续时间+50% | 线性叠加 |
| 双重释放 | E技能 | 连续释放2次（第二次效果×0.5） | 不叠加（最多1次） |
| 被动强化 | 被动技能 | 触发概率+20% | 线性叠加 |

### 4.7 温砖组合技

> 引用：GDD v6.1 §8.5 / 碎片系统文档 §4.4

触发条件：火人点燃碎片 + 水人冻结同一碎片 = 温砖

温砖属性：HP=20，全抗性+20%，3×3温差场，不可用于合成仅用于建造。

## 五、网络同步

### 5.1 同步内容

> 引用：网络通信.md §4.4 技能系统同步

| 事件 | 发起方 | 同步内容 | 处理方式 |
|------|--------|----------|----------|
| 技能释放 | 操作玩家 | 技能ID、目标位置、释放时间戳 | 同步给对方 |
| 技能效果（视觉） | 各端独立 | 无需同步 | 双方各自模拟 |
| 技能效果（机制） | **Host** | 伤害/冻结等判定结果 | Host权威判定，同步结果 |

### 5.2 设计原则

技能视觉效果立即本地播放（不等待网络确认），机制效果等待 Host 判定。确保视觉响应即时性，同时保证机制判定的权威性。
