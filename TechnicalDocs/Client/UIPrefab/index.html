UI 页面设计稿索引

📐 工作流：先 HTML 后代码 — ① 在本目录新建/迭代 <页面>.html（视觉稿 + 层级树 + 内嵌 <script id="ui-spec"> 的 JSON 规格） → ② 设计定稿 → ③ 由生成工具解析 ui-spec JSON 产出 预制体生成器与 View/Ctrl 代码 → ④ Unity 菜单生成预制体入库。
每个页面 HTML 内嵌完整节点规格（名称/组件/锚点/尺寸/颜色/文案），即后续代码生成的唯一数据源。 预览与层级树由 viewer.js 在浏览器端实时渲染，直接编辑页面内嵌的 ui-spec JSON 后刷新即可看到效果，无需任何转换脚本。
