UI 页面设计稿索引

📐 工作流：先 HTML 后代码，设计稿（页面内嵌 ui-spec JSON）为唯一数据源 —
① UIPanelGenerator 生成 MVC 三件套骨架（新面板一次性） → ② 手写 JSON 起稿（可选，只写结构不做布局）
③ python tools/ui_editor.py → 可视化编辑器 调布局 （拖拽 / 手柄 / 锚点补偿，Ctrl+S 直写回页面内嵌 ui-spec）
④ Unity 菜单 DualEnigma > UI > 校验设计稿 干跑 → DualEnigma > UI > 从设计稿生成预制体 入库（原地覆盖，GUID 不变，场景/AB 引用不断）
⑤ Ctrl/Model 逻辑实现（View 字段已按命名规范自动绑定）
⑥ 迭代：编辑器调整 → 保存 → 重新生成 → ⑦ （可选）python tools/gen_ui_html.py --out <临时目录> 反向导出，与源设计稿 diff 对账。
