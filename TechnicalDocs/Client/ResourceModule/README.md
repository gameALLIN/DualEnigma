## 模块概述

资源管理模块负责游戏中所有资源的加载、缓存和生命周期管理。

## 架构

```
┌──────────────────────────────────────────────┐
│              ResMgr (对外接口)                │
│    Load<T>() / LoadPrefab / LoadAsync        │
└──────────────────┬───────────────────────────┘
                   │
┌──────────────────▼───────────────────────────┐
│          AssetBundleMgr (内部实现)            │
│  AB加载/卸载 · 依赖解析 · 引用计数 · 延迟卸载  │
│  多平台适配 · 缓存策略 · 同步/异步双模式       │
└──────────────────┬───────────────────────────┘
                   │
┌──────────────────▼───────────────────────────┐
│          AssetGraph (打包配置层)              │
│    配置 AB 分组规则 → 产出 .bundle 文件        │
└──────────────────────────────────────────────┘
```
