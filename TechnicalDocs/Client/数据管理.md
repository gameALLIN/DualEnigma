## 一、系统概述

数据管理负责项目中所有资源的加载、缓存和生命周期管理。设计目标：

- **开发期**：AssetDatabase 直接加载，零配置
- **生产期**：切换为 AssetBundle / AssetGraph 打包方案，外部接口不变
- **核心机制**：引用计数 + 延迟卸载，避免资源抖动

## 二、模块划分

| 模块 | 类 | 职责 |
|------|-----|------|
| **资源管理器** | `ResMgr` | 单例，统一资源加载入口，生命周期管理 |
| **引用追踪** | `AssetHoldRefItem` | 记录哪个对象引用了哪个 AB 的资源 |

| **图集引用计数** | `SpRefCount` | 跟踪图集被引用次数 |

## 三、ResMgr 设计

### 3.1 单例
继承 `Singleton<ResMgr>`，全局唯一入口。

### 3.2 双模式加载

```
                    ┌─ Editor 模式 ─→ AssetDatabase.LoadAssetAtPath
ResMgr.Load<T>() ──┤
                    └─ Runtime 模式 ─→ AssetBundle (后续接入 AssetGraph)
```

### 3.3 核心接口

| 方法 | 说明 |
|------|------|
| `Load<T>(path)` | 同步加载任意资源 |
| `LoadPrefab(path)` | 加载预制体（自动补 .prefab） |
| `LoadAsync<T>(path, callback)` | 协程异步加载 |
| `UnloadAsset(bundleName)` | 引用计数减 1，归零后卸载 |
| `UnloadUnusedAssets()` | 主动 GC + 卸载未使用资源 |

### 3.4 引用计数机制

```
                  ┌─────────────────┐
  对象A（UI Image）──引用→ AB "ui_common"
  对象B（SpriteRenderer）──引用→ AB "ui_common"
                  └─────────────────┘
                          ↓
    AB "ui_common" 引用计数 = 2
                          ↓
    对象A 销毁 → 引用计数 = 1（不卸载）
    对象B 销毁 → 引用计数 = 0 → 卸载 AB
```

### 3.5 延迟卸载

```
资源引用归零
    → 不立即卸载
    → 加入 WaitUnloadItem 队列
    → 延迟 2 秒
    → 执行 CheckUnload → 真正卸载
```

**目的**：避免同一 AB 在短时间内反复加载/卸载（如滚动列表频繁复用图片）。

### 3.6 强制清理

`ForceClearAssetHolder(object)` — 用于 UI 控件频繁更换资源时，立即释放旧引用。如一个 Image 控件反复换图，每次换图前清理上一次的引用。

### 3.7 Update 轮询

每秒检查一次引用持有者是否已被销毁（GameObject 为 null），自动清理无效引用。

## 四、SpriteAtlas 管理

### 4.1 自动绑定
`AddSpriteatlasBind()` 注册 `SpriteAtlasManager.atlasRequested` 回调，UI 引用图集时自动按需加载。

### 4.2 Sprite 缓存
从图集提取的 Sprite 存入 `mCachedSprites` 字典，后续同名的直接返回缓存，避免重复 `GetSprite()`。

### 4.3 图集热替换
`AddSpriteatlas(key, atlas)` 替换已加载的图集，自动清理旧图集的缓存 Sprite 并卸载旧图集资源。

### 4.4 接口

| 方法 | 说明 |
|------|------|
| `AddSpriteatlasBind()` | 注册全局图集请求回调 |
| `AddSpriteatlas(key, atlas)` | 注册/替换图集 |
| `RemoveSpriteatlas(key)` | 移除图集，清理缓存 Sprite + 卸载资源 |
| `GetSprite(name)` | 从所有已注册图集中查找 Sprite |
| `GetSprite(name, preferAtlases)` | 指定优先图集查找 Sprite |

## 五、异步加载体系

### 5.1 回调委托

```csharp
delegate void AssetObjectCallback<T>(string name, T obj, params object[] args);
```

### 5.2 支持的资源类型

| 类型 | 加载方法 |
|------|----------|
| GameObject | `GetGameObjectFromBundle` → `LoadGameObjectAsync` |
| UI GameObject（实例化） | `GetUIGameObjectFromBundle` → `LoadUIGameObjectAsync` |
| Texture2D | `LoadTextureAsync` |
| SpriteAtlas | `GetSpriteAtlasFromBundle` |
| Tile | `GetTilemapsFromBundle` |
| RenderTexture | `GetRenderTextureFromBundle` |
| VideoClip | `GetVideoClipFromBundle` |
| TextAsset | `GetTextFromBundle` |

### 5.3 加载流程

```
GetXxxFromBundle(bundleName, assetName, callback)
    → TryGetAsset() 检查已加载的 AB 缓存
        → 命中：直接回调
        → 未命中：StartCoroutine(LoadXxxAsync)
            → AssetBundleManager.LoadAssetAsync
            → 等待完成
            → callback(assetName, obj, args)
```

## 六、AB 依赖检查

### 6.1 完整性校验
`IsAllLoadedAssets(bundleName)` — 检查目标 AB 及其所有依赖 AB 是否已全部加载，未加载的加入下载队列。

### 6.2 已加载判断
`IsLoadedAssets(bundleName)` — 判断单个 AB 是否已加载到内存。

## 八、数据加载路径

### 8.1 资源根路径
```
AssetPackage/                    # 所有资源根目录
├── Prefabs/                     # 预制体
│   ├── UI/                      # UI 预制体
│   ├── Characters/              # 角色预制体
│   └── Effects/                 # 特效预制体
├── Sprites/                     # 精灵图
├── Atlases/                     # SpriteAtlas 图集
├── Materials/                   # 材质
├── Animations/                  # 动画
├── Audio/                       # 音频
└── Data/                        # 配置数据（ScriptableObject）
```

### 8.2 路径约定
- 加载路径相对于 `AssetPackage/`，如 `"Prefabs/UI/UITest/UITest"`
- Editor 模式：`AssetDatabase.LoadAssetAtPath("Assets/AssetPackage/" + path)`
- Runtime 模式：`AssetBundle.LoadAsset(assetName)`（后续接入）

## 九、与现有系统的对接

### 9.1 UIManager
UIManager 通过 `ResMgr.Instance.LoadPrefab("Prefabs/UI/{name}/{name}")` 加载面板预制体。

### 9.2 GameLaunch
GameLaunch.Awake() 中初始化 `ResMgr.Instance`。

### 9.3 后续扩展
- **SpriteAtlas**：美术接入后注册图集
- **异步加载**：面板切换时预加载下一页
- **引用计数**：配合对象池管理资源生命周期

---

> **附注**: 本文档定义框架接口，具体实现随开发进度逐步完善。当前阶段 ResMgr 使用 AssetDatabase 同步加载，引用计数和延迟卸载在接入 AssetGraph/AB 打包后启用。
