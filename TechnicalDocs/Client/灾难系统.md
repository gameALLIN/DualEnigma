## 一、系统概述

### 1.1 系统职责

灾难系统负责：
- 35种灾难的生成与管理
- 灾难渐进入侵强度计算（30%→60%→100%→80%）
- 灾难对角色和建筑的伤害计算
- 程序化视觉特效（纯 Particle System + Shader，零贴图依赖）
- 随机种子同步（确保双方视觉一致）

### 1.2 在整体架构中的位置

```
Core（EventBus / ServiceLocator）
         │
    DisasterSystem
    │            │
    ├── 灾难基类 DisasterBase
    │   ├── OnStart → OnUpdate(渐进强度) → OnEnd
    │   └── 35个子类（E1-E8 / V1-V6 / T1-T5 / S1-S5 / P1-P5 / M1-M6）
    ├── 渐进强度计算（确定性时间轴）
    ├── 伤害计算（DPS × 抗性系数 × 当前强度）
    ├── 程序化视觉（Particle System + Shader）
    └── 随机种子管理（Host 生成 → 同步给 Client）
              │
     依赖：BuildingSystem / ShelterSystem / FragmentSystem
```

### 1.3 依赖关系

| 依赖方向 | 说明 |
|----------|------|
| Disaster → Core | EventBus / ServiceLocator |
| Disaster → Building | 灾难对建筑造成伤害 |
| Disaster → Shelter | 灾难环境影响角色扣血 |
| Disaster → Fragment | 部分灾难影响碎片（T1存续减半、M6碎片逃逸等） |
| Network → Disaster | 灾难参数+种子同步 |

## 三、核心接口与类设计

### 3.1 DisasterBase 抽象类

```csharp
namespace DualEnigma.Disaster
{
    /// <summary>
    /// 灾难基类。所有35种灾难继承此类。
    /// 生命周期：OnStart → OnUpdate(渐进强度) → OnEnd
    /// </summary>
    public abstract class DisasterBase
    {
        /// <summary>灾难参数</summary>
        public DisasterParams Params { get; protected set; }

        /// <summary>当前强度（0-1）</summary>
        public float CurrentIntensity { get; protected set; }

        /// <summary>是否正在运行</summary>
        public bool IsRunning { get; protected set; }

        /// <summary>初始化灾难参数</summary>
        public virtual void Initialize(DisasterParams parameters)
        {
            Params = parameters;
            CurrentIntensity = 0f;
            IsRunning = false;
        }

        /// <summary>灾难开始</summary>
        public abstract void OnStart();

        /// <summary>每帧更新（渐进强度计算 + 效果执行）</summary>
        /// <param name="deltaTime">帧间隔</param>
        /// <param name="elapsedTime">已运行时间</param>
        public abstract void OnUpdate(float deltaTime, float elapsedTime);

        /// <summary>灾难结束</summary>
        public abstract void OnEnd();

        /// <summary>计算当前渐进强度</summary>
        /// <param name="elapsedTime">已运行时间（秒）</param>
        /// <returns>0-1 的强度值</returns>
        protected virtual float CalculateIntensity(float elapsedTime)
        {
            // 线性插值，每秒平滑过渡
            if (elapsedTime < 5f) return Mathf.Lerp(0f, 0.3f, elapsedTime / 5f);
            if (elapsedTime < 10f) return Mathf.Lerp(0.3f, 0.6f, (elapsedTime - 5f) / 5f);
            if (elapsedTime < 15f) return Mathf.Lerp(0.6f, 1.0f, (elapsedTime - 10f) / 5f);
            return Mathf.Lerp(1.0f, 0.8f, (elapsedTime - 15f) / 5f);
        }
    }
}
```

### 3.2 DisasterSystem

```csharp
namespace DualEnigma.Disaster
{
    /// <summary>
    /// 灾难系统管理器。继承 Singleton<T>，注册 IDisasterSystem 到 ServiceLocator。
    /// </summary>
    public class DisasterSystem : Singleton<DisasterSystem>, IDisasterSystem
    {
        /// <summary>当前运行的灾难</summary>
        public DisasterBase CurrentDisaster { get; private set; }

        /// <summary>启动灾难（灾害冲击阶段开始时由 Host 调用）</summary>
        /// <param name="disasterId">灾难ID</param>
        /// <param name="difficultyMultiplier">综合难度倍率</param>
        /// <param name="seed">随机种子</param>
        public void StartDisaster(DisasterId disasterId, float difficultyMultiplier, uint seed);

        /// <summary>停止灾难（灾害冲击阶段结束时调用）</summary>
        public void StopDisaster();

        /// <summary>每帧更新</summary>
        public void OnUpdate(float deltaTime);
    }

    public interface IDisasterSystem
    {
        DisasterBase CurrentDisaster { get; }
        void StartDisaster(DisasterId disasterId, float difficultyMultiplier, uint seed);

        /// <summary>停止灾难（灾害冲击阶段结束时调用）</summary>
        void StopDisaster();

        /// <summary>每帧更新</summary>
        void OnUpdate(float deltaTime);

        /// <summary>获取当前灾难的实际位置（世界坐标）。若无运行中的灾难，返回 Vector2.zero</summary>
        Vector2 GetDisasterPosition();
    }
}
```

## 四、详细逻辑

### 4.1 灾难总览

35种灾难，6大类，每轮1种，分配到36轮（E3出现2次，含强化版）。

| 类别 | 数量 | 编号范围 |
|------|------|----------|
| 元素类（E） | 8 | E1-E8 |
| 环境类（V） | 6 | V1-V6 |
| 时空类（T） | 5 | T1-T5 |
| 感知类（S） | 5 | S1-S5 |
| 物理类（P） | 5 | P1-P5 |
| 机制类（M） | 6 | M1-M6 |

**灾难→庇护环境映射**：35种灾难均匀分配到5种庇护环境（每种7种）。

### 4.2 渐进强度

**实现方式**：线性插值，每秒平滑过渡。

```
当前强度 = CalculateIntensity(elapsedTime)
    0-5s:  线性升至 30%
    5-10s: 线性升至 60%
    10-15s:线性升至 100%
    15-20s:线性降至 80%
```

**双方独立计算**：该时间轴为确定性计算（基于灾难开始时间戳），双方各自按时间轴推算当前强度，无需实时同步。

### 4.3 灾难伤害计算

```
建筑伤害 = 基础DPS × 建筑抗性系数 × 当前强度 × 难度倍率

角色伤害：
    环境扣血 = 环境扣血速率 × DamageMultiplier(天赋) × 濒死保护(0.7 if HP≤30%)
    灾难直接伤害 = 灾难特定机制（如E8吸入、P3漩涡等）
```

**建筑抗性系数**：

| 等级 | 符号 | 系数 |
|------|------|------|
| 免疫 | ★★★ | 0× |
| 强抗性 | ★★ | 0.3× |
| 抗性 | ★ | 0.6× |
| 无加成 | — | 1.0× |
| 弱点 | ✗ | 1.5× |

### 4.6 随机种子同步

```
Host 端:
    1. 灾难开始时生成随机种子（uint32）
    2. 将种子随灾难参数一起同步给 Client
    3. Host 使用该种子初始化本地随机数生成器

Client 端:
    1. 接收灾难参数和随机种子
    2. 使用相同种子初始化本地随机数生成器
    3. 双方随机序列一致（火焰龙卷路径、陨石落点等）
```

> 引用：网络通信.md §4.2 灾难系统同步 — 随机性处理

## 五、网络同步

### 5.1 同步内容

> 引用：网络通信.md §4.2 灾难系统同步

| 事件 | 发起方 | 同步内容 | 处理方式 |
|------|--------|----------|----------|
| 灾难开始 | **Host** | 灾难类型、参数（DPS/范围/持续时间）、随机种子 | Host 同步，双方各自模拟 |
| 灾难强度变化 | 各端独立 | 无需实时同步 | 双方按确定性时间轴计算 |
| 灾难结束 | **Host** | 灾难结束事件 | Host 同步，双方停止模拟 |

### 5.2 种子同步确保视觉一致

种子同步确保双方灾难效果视觉一致。随机元素的实际伤害判定由 Host 权威执行。
