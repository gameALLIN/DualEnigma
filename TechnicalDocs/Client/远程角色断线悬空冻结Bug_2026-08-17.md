# Bug：对方卡顿/掉线时远程角色悬空冻结，局内无任何断线提示

> 发现日期：2026-08-17 · 影响模块：RemoteCharacterDriver / 局内 HUD · 严重级别：中高（强制双人联网游戏的核心体验受损，非崩溃级）

---

## 一、现象

对战中对方面向本端的远程角色渲染完全依赖高频状态包（20Hz 快照插值）。对方一旦卡顿或掉线：

1. 远程角色**冻结在最后一个快照位置不动**，动画停在最后一帧状态
2. 若对方断线瞬间正处于空中（跳跃中/二段跳/下落中），远程角色**悬停在空中永不落地**（"飘在空中"）
3. 局内（对战中）**无任何"对方卡顿/断线"提示**——`OpponentDisconnectEvent` 仅房间场景 `UIRoomCtrl` 订阅
4. 无自愈手段：只能等对方重连收到快照后瞬移恢复，或本端主动退出

## 二、复现步骤

1. 双端进入对局（正常联机状态）
2. 玩家1 跳跃至空中最高点附近时，瞬间切断其网络（禁用网卡 / 防火墙规则 / 拔网线）
3. 玩家2 视角：玩家1 的角色停滞后**悬空冻结**，落不下来
4. 等待服务器心跳清扫确认掉线（`HeartbeatManager`）→ 玩家2 局内**依然无提示**，角色继续悬空
5. 玩家1 恢复网络重连 → 玩家2 端角色从悬空位置直接瞬移到快照位置

## 三、根因分析（三层叠加）

### 3.1 插值缓冲枯竭后冻结

`RemoteCharacterDriver.Update()` 仅做两样本线性插值，包流停止后 `renderTime` 追上最新样本，`t` 被 `Clamp01` 恒为 1，位置永久钉死在 `b.Position`：

```csharp
float t = span > 0f ? Mathf.Clamp01((renderTime - a.Time) / span) : 1f;
_rb.position = Vector2.Lerp(a.Position, b.Position, t);
```

### 3.2 Kinematic 刚体 + 直接赋值 → 重力不生效

远程角色为 Kinematic 刚体（设计如此：不参与本地物理模拟），每帧由 `_rb.position` 直接驱动。物理引擎不会对其施加重力，**空中断线必然悬空**，无落地兜底。

### 3.3 文档承诺的外推未实现（文档与代码不一致）

`TechnicalDocs/Server/同步策略.md` §2.3 明确写着：

> 外推限制 100ms —— 超过缓冲区最新包时最多外推 100ms

但 `RemoteCharacterDriver` **没有任何外推逻辑**。`NetworkCharacterReporter` 上报的 `velocity` 字段被驱动器完全丢弃，只消费了 position。

### 3.4 断线通知局内无人消费

链路本身是通的：服务器检测掉线 → 下发 `S2C_OpponentDisconnect` → `GameServerClient` 解析并发布 `OpponentDisconnectEvent`。但全项目仅 `UIRoomCtrl`（房间场景）订阅；**局内（UIGameHud / RemoteCharacterDriver）无任何监听**，对战中感知不到对方已掉线。

## 四、定性结论：方案固有代价 vs 实现 Bug

| 部分 | 定性 | 说明 |
|---|---|---|
| 对方一卡，位置就不准/有停顿 | **快照插值方案固有代价** | 断流后无法得知对方真实位置，任何 netcode（含客户端预测回滚）都有不可知的窗口期 |
| 悬空冻结、永不落地 | **实现 Bug** | Kinematic 无重力兜底 + 无失联后的模拟下落，属可修缺口 |
| 外推 100ms 未实现 | **实现 Bug** | 文档已承诺、上报字段已具备，代码未落地 |
| 局内无断线提示 | **实现 Bug** | 事件已发布，仅缺局内订阅与 UI 表现 |

> 结论：**以实现缺口为主，非同步方案缺陷**。重连基础设施（重连快照、心跳检测、OpponentDisconnectEvent）均已就绪，缺的是局内表现层的消费与兜底表现。

## 六、修复建议（推荐组合方案）

1. **停滞检测 + 限速外推**（`RemoteCharacterDriver`）：
   - >500ms（约 10 个 20Hz 包间隔）未收到新样本 → 进入外推模式：用最后收到的 `velocity` 外推位置，上限 100ms（对齐同步策略.md §2.3）
2. **失联标记 + 模拟落地**：
   - 外推耗尽仍无包 → 标记失联：角色半透明（如 α=0.5）+ 头顶失联图标
   - Kinematic 下手动积分重力做模拟下落，检测 Ground 层落地即停——**根治悬空**
3. **局内断线提示**：
   - `UIGameHud` 订阅 `OpponentDisconnectEvent`，顶部横幅"对方断线，等待重连…"（复用 UIRoomCtrl 文案模式）
4. **重连平滑恢复**：
   - 恢复收包/收到重连快照后，从当前渲染位置约 0.2s 内 Lerp 吸附到权威位置，避免瞬移闪烁

**参数建议**（可挂 `NetworkConfig`）：停滞阈值 500ms · 外推上限 100ms · 失联透明度 0.5 · 吸附时长 0.2s

## 七、验证清单

- [ ] 玩家1 空中断网 → 玩家2 端对方角色短暂外推后自然落地（或半透明失联态），不悬空"漂浮"
- [ ] 局内出现"对方断线，等待重连…"横幅提示
- [ ] 玩家1 恢复网络重连 → 玩家2 端角色平滑吸附恢复，无瞬移闪烁
- [ ] 短时卡顿（<500ms）不触发失联标记，插值表现无肉眼可见异常
- [ ] 回归：正常对局（无断线）行为与现状一致
