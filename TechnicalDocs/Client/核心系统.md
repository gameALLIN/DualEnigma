## 一、系统概述

核心系统是所有其他系统的基础，提供：
- 游戏状态管理
- 模块间通信
- 对象复用

---

## 二、游戏状态机

### 2.1 状态定义

| 状态 | 说明 |
|------|------|
| Prepare | 准备阶段 |
| FragmentCollect | 碎片收集阶段 |
| SynthesisBuild | 合成建造阶段 |
| DisasterImpact | 灾害冲击阶段 |
| Rest | 修整阶段 |
| GameOver | 游戏结束 |

### 2.2 状态流转

```
准备 → 预告 → 碎片收集 → 合成建造 → 灾害冲击 → 修整 → 下一轮/结束
```
