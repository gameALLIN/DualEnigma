## 三、架构设计

### 3.1 架构模式

**轻量级组件化 + 事件驱动 + 数据驱动 + 服务定位器**

- **组件化**：每个系统是一个 Manager，继承 `Singleton<T>`
- **事件驱动**：模块间通过 `EventBus` 通信，降低耦合
- **数据驱动**：ScriptableObject + JSON 导表配置，策划可调数值
- **服务定位器**：`ServiceLocator` 注册接口，系统间通过接口获取服务

## 五、代码约定

### 5.1 命名空间

- 根命名空间: `DualEnigma`（asmdef 定义）
- 模块命名空间: `DualEnigma.{Module}`（如 `DualEnigma.Core`, `DualEnigma.UI`, `DualEnigma.Character`）

### 5.2 字段命名

- 私有序列化字段: `_camelCase`（如 `_entryPanelName`）
- 公开属性: `PascalCase`（如 `CurrentPhase`）
- 常量: `UPPER_SNAKE_CASE`（如 `ASSET_ROOT`）

### 5.3 单例模式

```csharp
public class EventBus : Singleton<EventBus>
{
    protected override void OnSingletonInitialized()
    {
        // 初始化逻辑
    }
}
```

- 继承 `Singleton<T>`，重写 `OnSingletonInitialized()`
- 自动 `DontDestroyOnLoad`，场景切换不销毁

### 5.4 事件总线

```csharp
// 订阅
EventBus.Instance.Subscribe<PhaseChangedEvent>(OnPhaseChanged);

// 发布
EventBus.Instance.Publish(new PhaseChangedEvent { phase = GamePhase.DisasterImpact });

// 取消订阅（OnDestroy 中调用）
EventBus.Instance.Unsubscribe<PhaseChangedEvent>(OnPhaseChanged);
```

- 事件命名规范: `{系统名}{动作}Event`（如 `FragmentCollectedEvent`, `BuildingPlacedEvent`）
- 事件采用结构体（struct），实现 `IEventData` 接口

### 5.5 服务定位器

```csharp
// 注册（初始化时）
ServiceLocator.Register<IBuildSystem>(this);

// 获取（使用时）
var buildSystem = ServiceLocator.Get<IBuildSystem>();
buildSystem.PlaceBuilding(...);
```

### 5.6 Sprite 生成

- `SpriteMeshType.FullRect`
- `filterMode = FilterMode.Point`
- PPU = 32

### 5.7 层级与标签

- Ground 层: Layer 7 = Ground（TagManager.asset 已定义）
- Player 标签: Tag = Player（TagManager.asset 已定义）
