```

├── Core/          # 核心系统（GameManager、状态机、事件系统）
```

## 三、架构设计

### 3.1 架构模式

**轻量级组件化 + 事件驱动 + 数据驱动**

- **组件化**：每个系统是一个Manager，Unity原生组件模式
- **事件驱动**：模块间通过EventSystem通信，降低耦合
- **数据驱动**：ScriptableObject配置，策划可调数值

### 3.2 整体架构图

```
┌─────────────────────────────────────────────────┐
│                 客户端 (Unity C#)                │
├─────────────────────────────────────────────────┤
│  Core │ Character │ Fragment │ Synthesis │ Building │
│  Disaster │ Shelter │ Skill │ Talent │ Data │ Network │ UI │
└─────────────────────────────────────────────────┘
                        │
                        │ TCP/UDP + Protobuf
                        ▼
┌─────────────────────────────────────────────────┐
│                 服务端 (C++)                     │
└─────────────────────────────────────────────────┘
```
