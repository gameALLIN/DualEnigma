## 三、P1 级别问题（影响完整性，建议原型阶段处理）

### 3.1 Character 模块
- 程序化精灵生成未实现（文档要求径向渐变Sprite）
- Input System 未集成（Move/Jump方法无外部调用者）
- 动画状态机未实现（AnimState枚举存在但无动画播放）
- 网络同步字段未就绪
- TakeDamage 直接调用 ShelterSystem.Instance 而非 ServiceLocator（松耦合违规）

### 3.2 Fragment 模块
- 被动技能触发概率未区分接住方式（文档要求：地面30%/跳跃50%/同时100%）
- 温砖触发仅支持"先点燃后冻结"单向时序
- Ignited/Frozen状态碎片停止存续倒计时，可能对象池泄露
- 掉落位置硬编码，未参考建筑区域
- 掉落计划网络同步缺失

### 3.3 Building 模块
- M4预言干扰实现不完整（仅初始生成时随机化，缺运行时动态变化）
- SyncBuildingHPs仅做本地Clamp，无网络同步
- 修补建筑未消耗材料
- 拆除建筑未检查阶段限制
- 蓝图形状与文档不完全匹配（避难所应为矩形非拱形，导流板应为斜线非分散）
- GetBuildingHP硬编码未使用BuildingConfig
- BuildingConfig的_minBlocks/_maxBlocks数组仅3元素，round=4越界

### 3.4 Skill 模块
- 机制Host判定未实现
- 视觉本地播放未实现
- 卡牌抽取使用非确定性随机（UnityEngine.Random）
- 被动强化天赋未接入SkillSystem
- Q技能效果系数×1.5未在文档中定义
- ExecuteFreezeEffect使用FindObjectsOfType（性能问题）
- ExecuteDamageEffect假设灾难在原点
- 稀有度冷却系数未应用

### 3.5 Disaster 模块
- IntensityCurve配置未被使用（CalculateIntensity硬编码）
- 抗性矩阵硬编码（未使用ScriptableObject）
- 地震环境伤害方式不正确（按次冲击波vs按帧DPS）
- GenericDisaster定义位置不当（应独立文件）
- 配置延迟加载（应在OnSingletonInitialized中预加载）

### 3.6 Data 模块
- LoadConfig缓存键设计缺陷（typeof(T)忽略configName）
- JsonUtility反序列化限制（不支持Dictionary/嵌套数组）
- 缺少配置完整性校验
- 存档系统未实现
- 导表产出JSON文件不存在

### 3.7 Talent 模块
- DamageReduction天赋效果混用（同时用于护盾强化和扣血减缓）
- BoostRates实现与文档不符
- DrawFromPool的boost参数未使用
- TalentConfig延迟加载时机问题

### 3.8 Network 模块
- MidFrequencyState缺少fragments字段
- ConnectionState枚举未使用
- 房间管理不完整
- 无带宽监控
