## 一、系统概述

### 1.1 系统职责

庇护系统负责：
- 庇护能量管理（恢复/消耗/耗尽）
- 双生庇护距离检测（队友3格/5格内）
- 环境扣血机制（能量耗尽后按环境类型扣HP）
- 建筑区域安全规则
- HP管理与恢复途径
- M5庇护削弱特殊规则

### 1.2 在整体架构中的位置

```
Core（EventBus / ServiceLocator）
         │
    ShelterSystem
    │           │
    ├── 能量管理（恢复 +20/s / 消耗 -33/s）
    ├── 距离检测（3格 / 碎片收集阶段5格）
    ├── 环境扣血（火山-3HP/s / 暴风雪-2HP/s / ...）
    ├── 建筑区域安全规则（50%减免 / 建筑完全保护）
    └── HP管理（不自动恢复 / 天赋恢复 / 章节恢复）
              │
     依赖：CharacterSystem / DisasterSystem / BuildingSystem / SkillSystem
```

### 1.3 依赖关系

| 依赖方向 | 说明 |
|----------|------|
| Shelter → Core | EventBus / ServiceLocator |
| Shelter → Character | 读取角色位置计算距离 |
| Shelter → Disaster | 当前庇护环境类型 |
| Shelter → Building | 建筑区域安全判定 |
| Shelter → Skill | 技能影响庇护（护盾/净化/领域） |
| Network → Shelter | 庇护能量值 / HP 同步 |

### 2.2 庇护能量参数

```csharp
namespace DualEnigma.Shelter
{
    /// <summary>
    /// 庇护能量参数。可通过天赋修改。
    /// 引用：双生庇护系统设计.md §二 能量系统 / §5.2 天赋修改
    /// </summary>
    [System.Serializable]
    public class ShelterParams
    {
        /// <summary>能量最大值（默认100，天赋"能量扩容"+30/次）</summary>
        public float MaxEnergy = 100f;
        /// <summary>恢复速率（默认+20/s，天赋"能量恢复"+30%/次）</summary>
        public float RecoveryRate = 20f;
        /// <summary>消耗速率（默认-33/s）</summary>
        public float ConsumptionRate = 33f;
        /// <summary>庇护距离（默认3格，碎片收集阶段5格，天赋"庇护扩展"+1格/次）</summary>
        public float ShelterDistance = 3f;
        /// <summary>碎片收集阶段庇护距离</summary>
        public float FragmentCollectDistance = 5f;
        /// <summary>碎片收集阶段消耗速率</summary>
        public float FragmentCollectConsumptionRate = 25f;
        /// <summary>耗尽后扣血速率乘数（天赋"护体"×0.5/次，封底×0.1）</summary>
        public float DamageMultiplier = 1f;
        /// <summary>3秒缓冲（能量耗尽后3秒才开始扣血）</summary>
        public float BufferTime = 3f;
    }
}
```

| 洪水 | 火人 | -3HP/秒 | 水人免疫 |
| 暴风雪 | 水人 | -2HP/秒 | 移速-50%，火人完全免疫 |
| 地震 | 双方 | -3HP/次冲击波 | 1格内免疫 |
| 陨石 | 双方 | 被砸概率50% | 3格内降至25%，1格内10%，掩体内0% |

### 2.4 HP恢复途径

| 途径 | 来源 | 数值 | 说明 |
|------|------|------|------|
| 天赋"生命回复" | ★普通 | 2HP/秒（修整阶段） | 可叠加 |
| 天赋"急救" | ★★稀有 | 立即恢复15HP | 保底至少出现2次 |
| 技能"净化" | E技能 | +10HP（即时） | 需选到该技能 |
| 温砖效果 | 建筑材料 | +1HP/秒（3×3区域） | 需合成温砖并放置 |
| 章节恢复 | 系统保底 | +15HP（每章） | 固定3次，共45HP |
| 濒死保护 | 系统保底 | 环境扣血-30% | HP≤30%时触发 |

## 三、核心接口与类设计

### 3.1 ShelterSystem

```csharp
namespace DualEnigma.Shelter
{
    /// <summary>
    /// 庇护系统管理器。继承 Singleton<T>，注册 IShelterSystem 到 ServiceLocator。
    /// </summary>
    public class ShelterSystem : Singleton<ShelterSystem>, IShelterSystem
    {
        /// <summary>水人庇护能量值 (0-100)</summary>
        public float AquaEnergy { get; }
        /// <summary>火人庇护能量值 (0-100)</summary>
        public float IgnisEnergy { get; }
        /// <summary>水人HP</summary>
        public int AquaHP { get; }
        /// <summary>火人HP</summary>
        public int IgnisHP { get; }
        /// <summary>当前庇护环境</summary>
        public ShelterEnvironment CurrentEnvironment { get; }

        /// <summary>设置当前庇护环境（阶段切换时调用）</summary>
        public void SetEnvironment(ShelterEnvironment environment);

        /// <summary>每帧更新（由 GameManager 调用）</summary>
        public void OnUpdate(float deltaTime);

        /// <summary>修改庇护参数（天赋系统调用）</summary>
        public void ModifyParams(ShelterParams modifications);

        /// <summary>角色受伤</summary>
        public void DealDamage(CharacterType target, int damage);

        /// <summary>角色治疗</summary>
        public void Heal(CharacterType target, int amount);
    }

    public interface IShelterSystem
    {
        float AquaEnergy { get; }
        float IgnisEnergy { get; }
        int AquaHP { get; }
        int IgnisHP { get; }
        void SetEnvironment(ShelterEnvironment environment);
        void DealDamage(CharacterType target, int damage);
    }
}
```

## 四、详细逻辑

### 4.1 能量机制

**默认参数**：

| 状态 | 能量变化 | 说明 |
|------|----------|------|
| 队友在3格内 | +20/秒 | 持续恢复 |
| 队友超过3格 | -33/秒 | 3秒耗尽（100÷33≈3秒） |
| 能量耗尽后 | 3秒缓冲 → 开始扣血 | 缓冲期不扣血 |

**碎片收集阶段特殊规则**：

| 参数 | 碎片收集阶段 | 其他阶段 |
|------|-------------|----------|
| 庇护距离 | **5格** | 3格 |
| 能量消耗速率 | **-25/秒** | -33/秒 |
| 耗尽时间 | **约4秒** | 约3秒 |

**能量循环**：

```
两人靠近(3格内) → 能量恢复(+20/s)
     ↓
一人离开(>3格) → 能量消耗(-33/s)
     ↓
3秒内返回 → 能量恢复，安全
     ↓
3秒后未返回 → 能量耗尽 → 3秒缓冲
     ↓
缓冲结束 → 开始扣血(-3HP/s)
     ↓
继续远离 → 持续扣血直到死亡
```

### 4.2 扣血机制

**扣血计算流程**：

```
OnUpdate(deltaTime):
    1. 计算两人距离
    2. 判断是否在庇护距离内
        ├── 在距离内 → 能量恢复(+20/s)
        └── 超出距离 → 能量消耗(-33/s 或 -25/s)
    3. 能量是否耗尽？
        ├── 未耗尽 → 不扣血
        └── 已耗尽 → 启动3秒缓冲计时器
            ├── 缓冲中 → 不扣血
            └── 缓冲结束 → 按当前环境扣血
                ├── 火山环境 → 水人扣血(-3HP/s)，火人免疫
                ├── 洪水环境 → 火人扣血(-3HP/s)，水人免疫
                ├── 暴风雪环境 → 水人扣血(-2HP/s, 移速-50%)，火人完全免疫
                ├── 地震环境 → 双方扣血(-3HP/次冲击波)
                └── 陨石环境 → 按概率判定被砸
    4. HP ≤ 0 → EventBus.Publish(new PlayerDiedEvent { playerId })
```

### 4.3 建筑区域安全规则

| 阶段 | 建筑区域内 | 建筑区域外 |
|------|-----------|-----------|
| 碎片收集阶段 | 环境伤害激活，但5格距离缓冲 | 正常庇护 |
| 建造阶段 | 不消耗庇护能量（灾害尚未开始） | — |
| 灾害冲击阶段 | **50%伤害减免**，建筑完全保护 | 0%减免（无保护） |
| 修整阶段 | 不消耗庇护能量（灾害已消退） | — |

**灾害冲击阶段安全规则**：
- 建筑区域内提供50%环境伤害减免（庇护环境伤害不生效，灾难物理伤害减半）
- 建造的建筑（防火墙/避难所等）提供100%完全保护
- 建筑区域外无保护（0%减免）

### 4.4 M5庇护削弱特殊规则

> 引用：灾难系统设计.md §2.6 M5 庇护削弱

| 参数 | 正常值 | M5影响 |
|------|--------|--------|
| 能量恢复速率 | +20/s | ×0.5 = +10/s |
| 能量消耗速率 | -33/s | ×1.5 = -49.5/s |

**净化技能交互**：使用"净化"技能可清除M5庇护削弱效果，恢复正常能量参数。

### 4.5 濒死保护机制

- 触发条件：任意角色 HP ≤ 30%（即 HP ≤ 30）
- 效果：环境扣血速率临时降低30%（如 -3HP/s → -2.1HP/s）
- 解除条件：HP 恢复至30%以上
- 限制：仅降低环境扣血，灾害直接伤害不受影响

### 4.6 与灾难系统交互

| 阶段 | 庇护行为 | 灾难行为 |
|------|----------|----------|
| ① 预告 | 旧环境效果消退，新环境效果未开始 | 无 |
| ② 碎片收集 | 环境伤害激活（5格距离缓冲） | 无 |
| ③ 灾害预告 | 环境伤害持续 | 无 |
| ④ 建造 | 不消耗能量 | 无 |
| ⑤ 灾害冲击 | 环境伤害+灾难特殊机制同时生效 | 渐进强度30%→60%→100%→80% |
| ⑥ 修整 | 能量恢复（灾害已消退） | 无 |
| ⑦ 升级 | 能量恢复 | 无 |

> 灾难特殊机制仅在灾害冲击阶段(⑤)生效，其他阶段仅庇护环境持续生效。

### 4.7 天赋对庇护数值的影响

> 引用：双生庇护系统设计.md §5.2 天赋对庇护数值的修改

| 天赋 | 修改参数 | 基础值 | 修改后 | 叠加上限 |
|------|----------|--------|--------|----------|
| 能量扩容 | 能量最大值 | 100 | +30/次 | 无上限 |
| 能量恢复 | 恢复速率 | +20/s | +30%/次 | 恢复速率×3上限 |
| 庇护扩展 | 庇护距离 | 3格 | +1格/次 | 无上限 |
| 冰霜护体/烈焰护体/坚固庇护 | 扣血速率 | ×1.0 | ×0.5/次 | 保留10%基础扣血 |

> 引用：双生庇护系统设计.md §6.5

| 行为 | 说明 |
|------|------|
| 跟随 | 跟随存活玩家，保持2格距离（庇护距离内） |
