## v3.2 — 2026-08-20 通用 JSON 预制体生成器 + HTML 可视化编辑器设计

### 变更原因

UI 制作流程「先 HTML 后代码」未闭环：`index.html` 声称 ui-spec JSON 为唯一数据源，但 HTML → 预制体的转写实际由 10 个手写 Editor 生成器（约 4000 行）人工完成，且布局调整依赖「手改 JSON → 刷新 → 目测」循环，存在双份维护、重复代码与设计稿/预制体漂移风险。设计两件配套工具闭合数据链路：HTML 可视化编辑器（布局生产）+ 通用 JSON 解释器（预制体落地）。

### 核心变更

| 维度 | 说明 |
|------|------|
| 工具定位 | Editor 工具读取任意 `<页面>.html` 内嵌 ui-spec JSON，递归解释节点树构建 UGUI 预制体 |
| 布局生产环节 | 新增 HTML 可视化编辑器：editor.html 三栏编辑器（拖拽/8 手柄/9 宫格锚点补偿/属性面板/撤销重做），`tools/ui_editor.py` 本地服务直写回 HTML 内嵌 JSON（原子写 + .bak 备份） |
| ui-spec schema v1.2 | 新增 `scale`/`rotation` 字段（编辑器写入、生成器解释 localScale/localRotation、viewer/gen_ui_html.py 同步渲染导出）；另有 ref/sprite/note/fontStyle 扩展提案 |
| 组件覆盖 | 26 种现有规格组件全覆盖（13 种内置 + 脚本组件），复合组件按子节点名约定自动接线 |
| 绑定复用 | 沿用 m_Xxx/mi_Xxx 命名规范与 UIAutoBinder.ViewTypeName 约定，View 代码零改动 |
| 保存策略改进 | SaveAsPrefabAsset 原地覆盖保 GUID（现手写生成器先删后存，GUID 每次变化） |
| 退役计划 | P2 阶段删除 10 个手写生成器（Generate{Panel}Prefab.cs × 9 + GenerateFriendItemPrefab.cs）与 UIPrefabCreator.cs |
